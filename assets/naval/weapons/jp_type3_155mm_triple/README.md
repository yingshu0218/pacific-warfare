# Type 3 15.5 cm triple turret housing

The reusable scene is `turret_housing.tscn`. Its root is the train-axis origin and its geometry is generated by the shared `scripts/naval/weapons/turret_housing_module.gd` script. It is installed below `Foundation_<station_id>/WeaponInstance_<station_id>/TrainPivot_<station_id>` and remains a separate resource from the main turret so its shape can be refined independently.

The housing currently uses the shared approximate eight-face shell template at the secondary profile's estimated scale. This is an interim shape, not evidence that the 15.5 cm turret shares the Type 94 shell contour. The 8 m rangefinder baseline is in `data/weapon_profiles.json`; hull silhouette, roof equipment, armor outline, and barrel length remain estimated.

Geometry is generated from project code; no external mesh or texture assets are included. No third-party asset license applies to this procedural mesh.
