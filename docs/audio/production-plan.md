## 1. 推荐路线与首轮范围

采用**本地原创合成与离线加工**。用不同声学结构生成活塞／螺旋桨动力、舰艇机械质感、重炮瞬态与低频衰减、短促轻武器、空爆、海水／陆地／金属命中及风浪底层，保留源代码、种子和参数。不是给同一白噪声改音高或包络凑齐类别。当前 17 个代表音全部原创，不依赖外部录音；旧程序音仍是运行版本的占位对照，直到统筹安排接入。

不按每艘舰、每种枪分别生产。A6M5a、F6F-5 先共享动力家族，四舰共享舰艇近景动力，406／460 mm 共用重炮，127／155 mm 共用中炮，20–40 mm 共用机关炮。所有 AU01 素材标为**原创通用设计音**，不称历史型号实录，不默认新增对外开放许可，不改变项目整体授权。听感不够时改进合成配方与混音，不转成采购／注册任务。

顺序：17 个代表文件与四段短试听 → 统筹审核整体质量 → 有界音频接口接入 → 通过方向审查后补齐 36 个 P0 文件 → 最新集成版本 Chrome 验收。本聊天只完成 AU01，不创建下级会话或自动接入。

## 4. P0／P1／后置素材与格式

表中长度为单文件上限建议，版本数是实际导出文件数，不包含剪辑工程、母带和备份。除环境底层外均为**单声道定位声**。声音可辨特征是制作验收目标，不是历史声学测量值。

| P0 家族 ID | 类型／上限时长 × 文件数 | 辨识目标与用途 |
| --- | --- | --- |
| `fighter_radial_power` | 循环 4 s × 3（low/cruise/high） | 连续螺旋桨节律和发动机质感，功率层可平滑切换，不能像单一正弦蜂鸣；两型机共用起点。 |
| `ship_propulsion` | 循环 4 s × 2（idle/run） | 舰艇近景低频机械／排气质感；不是汽车柴油音。仅作外部近景设计音，不宣称四舰轮机实录。 |
| `gun_heavy` | 单次 3.5 s × 3 | 主炮清楚起音、低频身体与海上短尾；同一真实炮座多管归并，不预烘焙整场齐射。 |
| `gun_medium` | 单次 1.5 s × 3 | 127／155 mm 主副炮，起音较短且与重炮可分；兼任防空时仍属这一家族。 |
| `autocannon` | 单次 0.4 s × 3 | 20–40 mm 清脆机械／爆裂感，近距有节奏，避免持续白噪声；每发真实事件或事件分组触发。 |
| `machinegun` | 单次 0.12 s × 3 | 7.7／12.7／13 mm 轻脉冲，与机关炮可区分；机载多枪归并，射速由真实事件决定。 |
| `airburst` | 单次 1 s × 3 | 空中干爆，与枪口及落水可分；不能每个受伤目标再重复爆一次。 |
| `impact_water` | 单次 1.8 s × 3 | 弹着冲击＋水体回落；口径调有限增益／滤波，轻弹不发巨型水爆。 |
| `impact_land` | 单次 1.5 s × 3 | 地面冲击／砂土碎屑；`ground/building` 的 P0 共同底层，可承接岸防。 |
| `impact_metal` | 单次 1 s × 3 | 舰体／金属设备短冲击与共鸣，不将每发轻弹都演成主炮爆炸。 |
| `unit_impact_water` | 单次 2.5 s × 2 | 飞机坠海／迫降真实接触，水冲击比炮弹更宽；轻迫降减弱，不叠加虚假爆炸。 |
| `unit_impact_land` | 单次 2.5 s × 2 | 飞机撞地／建筑实际接触的结构冲击；不由失能事件提前播放。 |
| `burning` | 循环 4 s × 1 | 近景低火势，不支配远景；受真实 `damage.fire` 驱动。 |
| `ambient_wind` | 循环 12 s × 1，双声道 | 轻背景风，不能包含预录枪炮／鸟群／对白或贴耳麦克风风噪。 |
| `ambient_coast` | 循环 16 s × 1，双声道 | 岸边才出现的轻浪层，远离海岸淡出；开放海面只留很低的 wind。 |

P0 合计 **15 家族、36 文件**；单声道文件累计上限 66.46 s，双声道 28 s。所有上限并不要求填满；尾音无意义时应缩短。首轮只制作其中 17 文件：发动机 3、舰艇 2、重炮 2、中炮／机关炮／机枪／空爆／三种弹着各 1、火／风／岸浪各 1；两种飞机撞击与其余变体留待方向审听后。

P1（P0 通过后，**不是首版阻塞条件**）：`ship_wake` 6 s 循环 × 1，`fighter_cutoff` 1 s × 2，`near_flyby` 1.2 s × 2，`heavy_far_tail` 3 s × 2，`material_detail` 1.5 s × 2，`harbor_environment` 16 s 双声道循环 × 1，`ui_soft` 0.1 s × 2；合计 7 家族、12 文件。仅在真实近距经过、停机、海上行进、建筑材质或 UI 操作能提供输入时启用。港口无人员／车辆模拟，不预录繁忙装卸或警报暗示不存在的事件。

后置：逐型号独立录音、炮弹近失／超声速弹道激波、舰内空间／精细反射与声传播、航母起降与甲板作业、鱼雷／炸弹声族、音乐、无线电和配音。首版以指挥 UI 呈现真实命令，不用预写语音替代。音乐会遮蔽战斗辨识且需额外授权，当前不列主线；语音须有真实指令、语言和触发契约后再单独规划。

格式建议：AU01 原始生成 WAV 与编辑母带均为无损 PCM 48 kHz／24 bit；配方与源脚本一并保留。P0 定位短声／动力环用 48 kHz／16 bit mono WAV，避免大量并发有损解码；环境长环用 48 kHz 双声道 Ogg Vorbis，保留 WAV 对照，最多两条环境解码。AU01 使用本机已有 native Vorbis、quality 6（该编码器标 experimental），按实际字节核预算，不假定 96–128 kb/s 或安装 libvorbis；编码后实际解码／循环／峰值检查和主观听感分别记录。原始立体声转 mono 先核相位；不凭双声道空间印象给移动物体重复定位。Godot 的 [格式取舍](https://docs.godotengine.org/en/stable/tutorials/assets_pipeline/importing_audio_samples.html)支持 WAV／Vorbis，但网页解码成本仍要在固定引擎实测；不凭文档中的通用并发描述承诺本项目性能。

## 5. 制作目录、流程与小样审听

AU01 实际输出分层如下，后续台账记录每一层格式与哈希。AU01 整包放根 `.gdignore`，source／masters 另有标记，避免其他板块的 Godot 导入顺带准入未审素材。试听不放运行资产目录，AU02 再明确准入所选 runtime 文件。

```text
assets/audio/au01/source/                 原创生成源 WAV、recipe.json、.gdignore
assets/audio/au01/masters/                无损编辑母带 WAV、.gdignore
assets/audio/au01/runtime/                17 个候选运行导出（尚未接入）
assets/audio/au01/SOURCES.md              原创来源与授权边界
tools/audio/build_au01.py                标准库生成／混音／编码，确定种子
tools/audio/check_au01.py                独立读实际文件检查
docs/audio/au01-asset-manifest.json       AU01 实际生产台账
docs/audio/au01-checks.json               实测格式／峰值／接缝／大小
docs/audio/au01/preview/                  四段 WAV 与 Ogg 试听、编排时间线
docs/audio/AU01-delivery.md               完成情况与听感待审记录
```

命名仍按家族／状态／变体，不用历史型号实录名。来源记录至少含作者方式、脚本和 recipe SHA-256、种子、参数、源 WAV／母带／运行文件的格式与哈希、循环点、自动检查、审听及接入状态。没有外部文件或许可凭据可伪造。

本轮流程：

1. 为 17 个文件分别定义频率／谐波／噪声带／颗粒／共鸣／包络结构，全部本地确定性合成；运行输出与原始源、母带分层。
2. 去直流、控制峰值、整理由原算法产生的瞬态和衰减；动力／环境环使用周期边界处理，避免以长静音遮掩接缝。
3. 导出 mono WAV 短声／动力环；环境用现有 FFmpeg 离线 Vorbis，并实际解码检查循环长度与边界。保留 WAV 母带；不安装新依赖。
4. 编排四段可直接播放的短混音，附每个音符／循环层的时间、增益、声像与意图。这是离线审听编排，不是游戏真实射击或性能证据。
5. 用独立检查脚本读取实际文件，核对格式、峰值、直流、尾部、循环接缝、哈希、体积；重建到隔离目录比较内容。编码通过共享 `verify.py exec` 有界运行。
6. 若没有实际听音能力，明确标注“文件与自动检查已完成，听感待统筹审听”；不以频谱／波形／峰值代替主观听觉。统筹整体审核后才安排扩量和接入，不要求用户逐文件批准。

四个审听场景各 30–45 秒，总计约 2–3 分钟，先提供 AU01 独立试听；如后续对照旧程序音，应另行做等响比较，不把本轮单版本混音标为 A/B。不是逐文件等用户确认。第一轮可以用清楚标注的离线制作时间线评估音色，它**不是实战接入证据**；接入后四组均用真实模拟事件重放／现场记录复验。

| 场景 | 必含对比／通过条件 |
| --- | --- |
| 主炮齐射 → 海面与舰体命中 | 近／中／远三个距离；单座多管有重量但不三重削波；枪口和数秒后真实弹着不混成一次爆炸；远景仍留主要低频，近景有明确起音。 |
| 舰队防空火网 | 中口径炮、机关炮、机枪、空爆各可辨；短时密集仍能听到前景重点，不是一整条无变化噪声；停火后不继续自动发射声。 |
| 近距狗斗 | 巡航、拉升高功率、低油／动力失效和点射；俯冲加速不等于持续拉高转速；接近／远离有空间变化，自动切镜无尖锐音高跳变。 |
| 港口／岸炮与海陆弹着 | 海、地面／建筑、金属命中区别；岸边才有浪；S10 未就绪时只作离线混音例，不能声称陆基实际交战。S10 接入后替换为同地图真实岸炮／防空事件。 |

审听表按“事件可辨、距离层次、动力跟随、重复疲劳、削波／click”逐项判定，记录缺陷与具体时间点。短小样确定方向只需一轮整体反馈，不要求用户掌握 DAW 或手工录音。

## 6. 接入契约：读真实事件与动力，不生成战果

保留 `CombatEffects.consume(events, generation)` 的表现入口；后续可将音频池和混音抽为独立 `CombatAudioController`（计划名），视觉仍由原消费者负责。建议只读上下文包含单位视图、定义／炮位索引、当前监听变换、镜头主体 ID、地形字典、generation、仿真时间／倍率／暂停／结束／启声／可见性。每帧 drain 一次，再把同一事件批次交给视觉和音频；音频不能再次 drain 世界、回写命令、使用世界 RNG 或从表现反向修改模拟。

| 真实输入 | 声音映射与去重规则 |
| --- | --- |
| `fired` | 使用 event 的枪口 `position_m`；由 `ammo_id/caliber_m`＋武器定义与炮位角色选重炮／中炮／机关炮／机枪。用 `weapon_id`（实例 ID）查炮位；不是把 definition ID 当实例。默认按台账显式映射，口径回退只报警记录、避免静默配错。 |
| 多管／高射速 `fired` | generation、entity、炮位、家族及 40 ms 仿真窗口归并；从真实成员枪口选一个代表位置。仅有真实 fired 才形成组，不用计时器补枪声。多管增益至多 +3 dB；高倍率时再按 50 ms 墙钟最小可听起音间隔删减，记 grouped／culled，弹药／射击／曳光不受影响。 |
| `salvo` | 可给优先级和相机标签，**不另播一次齐射**；枪口声已由 fired 触发。 |
| `airburst` | 在实际爆点播 `airburst`，同一 projectile 终结只播一次。由此给多个目标的 damaged 不再生成多次爆炸。 |
| `surface_impact` | `surface=sea` → water；`ground/building` → land；位置来自事件首次交点。P1 才细分混凝土／木材；不从镜头下方地形猜该弹着介质。 |
| `hit` | 位置与 projectile_id 来自事件；按 target_id 的域／受击部位选 metal（舰／机／金属武器）或 land（已明确的地面设施）。未知目标材质用低增益通用冲击并记缺映射；不能默认为海水。 |
| `damaged`（不是 `damage`） | 只更新动力／火势读模型，默认无额外 bang；target_id 是受害者。火势取快照 `damage.fire`，不把每条伤害通知播放成爆炸。 |
| `disabled / damage_phase` | 依据真实 phase／推进能力关闭或减弱动力、保留必要燃烧；控制失效不等于引擎已停。`sinking/crashing/wreck/removed` 不凭空加爆炸。沉没过程没有已核事件的结构破裂声，先后置。 |
| `unit_surface_contact / unit_impact` | 接触通知只供因果链；最终 `unit_impact` 的 sea／ground／building 播对应撞击一次，用 destroyed／velocity 调强弱。不能 contact、impact、disabled 三次叠播。 |
| `projectile_expired` | 无碰撞的自然到期不播命中／爆炸，只清理可能的表现跟踪。 |
| `aircraft_exit / ship_exit`、active／present | 正常撤离淡出并清单位循环，记录 departed，防止旧快照重启；不是失能或坠毁音。active=false 的燃烧残骸仍可按 phase／fire 有限发声，removed／exited 必须归零。 |

音频去重键为 `(generation, sequence)`，每批更新游标；即使静音、满池、听不见也推进游标，不在恢复时补放历史事件。projectile 终结和分组缓存用有上限环表（候选 1024 项、2 仿真秒 TTL），不是永久增长集合。重开一律清游标、分组、延时、departed、主体缓存、循环所有权和所有播放；共享只读 AudioStream 可保留，不重复构建母带。随机变体用独立呈现 RNG 或事件哈希，不消耗 `SimulationWorld.rng`；同一变体不连续重复，单次音高 ±3%、增益 ±1 dB 起步。

动力映射：

- 飞机读取 `module_data.aircraft_motion.throttle`，以 0／0.5／1 的低／巡航／高功率层交叉淡化，200–400 ms 平滑。`fuel_kg<=0` 或 `damage.propulsion_factor<=0` 关闭燃烧动力层；空转螺旋桨／气动声仅有合格素材时另列 P1，不将发动机燃烧音继续保留。中间损伤减弱层权重、不给每帧随机卡顿。零节流但有油／有动力可保留 low 层，不等于停机。
- 目前 `propeller_phase_rad` 是视觉用近似相位，禁止差分成“真实 RPM”。没有独立调速器／桨距模型；油门主要改变层权重、音高只在约 0.94–1.06 内作设计修饰。速度只决定相对运动、风／尾迹层，不直接决定飞机发动机音高。缺 throttle 时退到固定巡航层并诊断，不能接触敌情或改 S04 控制器补字段。
- 舰艇以 `ship_motion.speed_mps` 和定义的巡航速度、`ship_control.speed_mps`、`fuel_fraction`、推进损伤作**负荷近似**，不标成轴 RPM；有油和推进能力时才有 idle/run。`disabled_coasting` 撤去 run 推力层，仍有油和推进能力时可保留 idle；不能仅因控制损坏就判定引擎已停。动力为零才淡出机组层，尾迹 P1 可随真实残余航速保留。近景共享家族先试听再判断是否需区分舰别。
- ground 域无船机动力环；S10 发布后加定义映射和炮位／材质标签，复用 fired／hit／surface_impact。即使新域尚不可用，也不伪装成 ship 或回写其状态。

## 7. 距离、镜头、暂停与倍率

监听点使用当前观战相机（第三人称外部声音），不跟随某阵营，也不自动切成飞机座舱。音频只消费观众读模型，绝不将声源选择、听到的敌方事件或全知坐标回传指挥官。

P0 先采用内置 3D 方向／距离衰减和简单远距高频衰减，以下是**审听初值**，不是实测声压／真实最大听距。初值宜按物理距离统一，主体优先级只影响有限声源分配，不能让超出硬截止距离的声音突然变得近响。

| 类别 | 参考近距 r（m） | 硬截止 d（m） | 听感目标 |
| --- | ---: | ---: | --- |
| 飞机发动机 | 35 | 1800 | 近距读出功率，远机让位，不全机群同响 |
| 舰艇动力／火 | 25／15 | 600／250 | 只为近景提供质感，不能覆盖全景 |
| 重炮 | 180 | 10000 | 远处保留低频轮廓，不能把 8 km 当 80 m |
| 中炮 | 80 | 6000 | 前景有起音，远处明显退后 |
| 机关炮／机枪 | 35／20 | 2200／1000 | 近景节奏清楚，远景不占满火网 |
| 空爆／炮弹弹着／飞机撞击 | 50／60／100 | 4000／5000／5000 | 依据口径／能量和镜头距离有限调节 |

衰减建议以近距内限幅、远处约每倍距 -6 dB 为起点，再在截止前 20% 距离平滑归零；只实现一次距离曲线，不能自算增益后又叠同等内置衰减。远距高频少、尾层比例高；远层并不另开无限播放器。外部 3D 声、监听与 Doppler 的官方能力参考 [AudioStreamPlayer3D](https://docs.godotengine.org/en/stable/classes/class_audiostreamplayer3d.html)，最终 API／效果仍须按固定 4.7.2 导出验证。

P0 不做传播延时和逐声线遮挡，避免为 10 km 远炮积压长队和切镜错觉，明确是电影化距离近似。P1 如有价值，才考虑连续固定监听下的限长传播队列和山体／建筑低通：只查询 S09 `TerrainQueries.hit_data(terrain, source, listener, false)`，最多 4 个重点声源、每源 2 Hz，短缓存；遮挡 -6 至 -12 dB＋低通候选，不能当成精确声学。任何传播队列最多 32 项、最多 2 s，超期丢弃，切镜／重开／退出清理；这属于截断近似，不称真实声速仿真。

自动硬切镜时监听直接落在新相机，不沿岛屿之间插值移动；80–150 ms 类别增益交叉过渡，200 ms 平滑选源。连续自由／跟随移动则平滑增益和层权重。P0 关闭 Doppler；P1 只在连续运动且 1× 时试用一套基于模拟 m/s 的有限 Doppler（约 0.85–1.15），不与 Godot 内置再叠一次；切镜／瞬移／倍率变化重置速度历史并抑制约 0.3 s，避免摄影机跳转被听成高速飞越。

| 生命周期／控制 | 统一规则 |
| --- | --- |
| 初次启声 | 保留正常 UI 的明确点击；声音默认关闭。用同一次用户手势解锁 Web Audio，再以当前快照进入循环，绝不补放开局以来所有炮声。Chrome 对用户手势的要求见 [官方 autoplay 说明](https://developer.chrome.com/blog/autoplay/)。 |
| 暂停／恢复 | 暂停总线在 20–40 ms 墙钟内淡到静音，播放器 `stream_paused=true` 仅写一次，冻结未来队列；恢复先同步当前快照／监听，再设置 false 一次并短淡入。暂停时点击启声不能短暂响一帧；启声和暂停交叉顺序都必须测。 |
| 0.5／1／2／4× | 不把 AudioServer 全局播放速率乘模拟倍率；保留音色，按真实仿真事件到达节奏触发。0.5× 不是整条录音降八度；2／4× 只合并或裁掉次要表现并计数，动力状态仍由当下快照读取。有限声源规则在墙钟时间运行，不能以 4× 造四倍播放器。 |
| 静音／声音关闭 | 停单次与循环、清未来音频队列，仍消费 sequence；重新启声只恢复当前在场循环。总音量首版默认低、用户可关；不自动推高系统音量。 |
| 战斗结束／手动结束 | 结束优先于普通暂停，150–300 ms 淡出并 stop，未播放事件取消；战报期间不能被每帧快照重新启动发动机。 |
| 单位离场／失效 | 以 present／exited／phase 与实际推进能力分别处理。正常退出立即撤销所有权；控制损坏只停不适用的动作声；燃烧残骸仅在预算与范围内保留。 |
| 重开／加载失败／退出场景 | generation 更新，stop 并清所有音频运行缓存；启动后每单位最多一份循环所有权。加载失败不无限重试解码；缺音源退到已标注的占位或静音并记录诊断。 |
| 标签隐藏／返回 | 音频淡出并挂起，返回按当前快照重建，不追赶后台积存事件；模拟是否继续由 session 现有规则决定，音频不擅自控制世界。 |

**S08 的两项保护不可回退**：所有 Web 单次／循环／环境播放器显式 `AudioServer.PLAYBACK_TYPE_STREAM`；所有暂停属性只有实际变化才设置。Stream 是播放后端，不等于源文件必须 Ogg；可用它播放 WAV。官方 [Web audio 路径说明](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html#audio-playback)指出 Stream 的特性与延迟取舍；当前不升级引擎、改模板或为音频主动切换线程导出。S09 已报告修复声音按钮焦点＋Space 路径，接入须保留该修复，并在最新 Chrome 版本复验，不能把历史 S08 问题当成仍未实现的功能。

## 8. 有限声源、总线与网页预算

不为每架飞机、每个炮管或每发弹丸常驻播放器。循环候选每 100 ms 读取轻量单位视图，按预测到达音量、镜头主体和类别评分，稳定 ID 打破平分；候选需比占位者高约 3 dB 并持续 200 ms 才抢占，旧声源最短保持约 0.5 s，失效／静音立即退出。主体加权候选为 +6 dB 的评分权重，**不直接加到输出增益**。远处循环虚拟化只保留状态，不解码／不 play；恢复时重选循环相位并短淡入，不能从零制造新引擎启动态。

瞬时声先按真实事件、距离和主体相关性筛选，再分配池。默认最多重／中炮 3、机关炮／空爆火网 4、近景机枪 2、命中／撞击 3，共 12 个候选槽，跨类别可借空位；重点命中和最近重炮可替换最低分轻声。抢占先 10–20 ms 淡出再复用同一节点，不能为交叉过渡暗增节点。保留 dropped、grouped、stolen、inaudible、解码失败和最大队列统计，正常观战 UI 不显示这些内部字段。

循环 8 声道含所有功率交叉层与燃烧，示例上限为 3 架重点机 × 2 层＋1 艘近景舰＋1 处火；不是 8 架机各开三层。首轮 4 个循环声道时选择更少主体；跨层不能超池。环境 2 声道单列，全局只一份风与一份岸浪，无来源的泛战场炮火底噪禁用。

总线建议：`Master <- Combat(Guns, Impacts) / Machinery / Ambience / UI`；未来 Music／Voice 后置。初始 Master 留约 6 dB 余量，高潮只用轻压限，最终实录峰值目标不超过 -1 dBTP。重炮／近景命中发生时环境最多回避 3–6 dB、约 20 ms attack／300–600 ms release，禁止每发机枪都泵动全部声场。远景可很静，不用固定 loudness 将整场低音量强行拉满；短单发不以 LUFS-I 单独判合格。四组审听记录短时响度、峰值和主观可辨性。

以下均为**待测预算**；只有“当前实现”一列是代码上限。接入首轮保持小池，听感或实测确有需要才升到候选上限，不承诺数字已验证。

| 项目 | 当前实现／历史证据 | 接入首轮（4 舰 8 机） | 审听通过后的候选上限 | 未来每方 20–30 舰、100 机 |
| --- | --- | --- | --- | --- |
| 物理声音槽（max_polyphony=1） | 8 单次＋4 循环＝12 | 8＋4＋1 环境＝13 | 12＋8＋2＝22 | 仍以 22 为上限；先增强筛选／虚拟化，不随单位数增长 |
| 循环选择 | 排序前四，不按镜头 | 10 Hz、只选可听主体 | 稳定评分／迟滞，交叉层也计槽 | 扫约 240–260 单位的轻量视图，禁止复制全弹丸快照 |
| 音频资源／下载 | 四个程序 WAV，很小；未有正式素材测量 | 17 文件小样 | P0 36 文件，音频增量下载目标 ≤8 MiB | 不因实例多而复制 AudioStream；新声族另记预算 |
| 音频驻留 | 未独立测量 | 测相对关闭声音的增量 | 资源驻留候选 ≤32 MiB，暖机后 WASM 增量候选 ≤48 MiB | 保持同资源池；必须另外做大编制证据，不沿用 Showcase 通过状态 |
| 音频表现调度 CPU | 未独立测量 | 记录计时／有无声对照 | 4＋8 场景 p95 候选 ≤0.5 ms／帧 | 大编制 p95 候选 ≤1 ms／帧；总体稳定 30 FPS 门槛不变 |
| 延迟／缓存 | 当前无声传播队列 | P0 传播队列 0 | 启声后的近距事件声画差候选 p95 ≤150 ms，先测 Stream 输出延迟 | P1 最多 32 条／2 s 的传播候选；有界退化 |

估算方法：`样本数 × 声道 × 字节数`。P0 mono WAV 上限 66.46 × 48000 × 2 ≈ **6.08 MiB**；两段环境若全解码为 16 bit PCM 约 5.13 MiB；全部以 float32 留存约 22.4 MiB。实际还可能有解码缓冲、重采样、导入和临时复制，因此 32／48 MiB 是待测目标，不能把压缩下载字节当作驻留。超限先缩短无效尾音、共享资源、减少环境解码／层数和虚拟化，不降低真实射速／弹数或改 sample 后端规避统计。1280×720 是当前 Showcase 验收口径；未来 G6 满编制仍须按总体规划另测 1440×900 目标与 200 架同时在空峰值，不以本轮 720p 小规模成绩替代。

## 10. 实施后的检查与 Chrome 完成条件

以下是未来验收，**本轮没有执行**：

1. 素材：台账中运行文件都有来源链、许可快照、哈希和导出参数；运行包不含原始录音、购买凭据、剪辑工程或大包。检查循环点和首尾无爆音；盲听能区分主炮／防空／机枪、海／陆／金属命中。缺失或未知许可不能改成 verified 过关。
2. 受控机制：同 generation 重复事件不二次响；新 generation 同 sequence 可正常响；salvo＋fired、airburst＋多目标 damaged、surface_contact＋unit_impact＋disabled 均不重复爆炸。静音后恢复无补放；退场旧快照不重启；满池、高倍率、暂停／结束／重开后节点与缓存始终有界。速度高但节流低、燃油零而仍滑翔、控制失能但推进尚在分别核动力。对同一种子／命令，有无音频、不同镜头的世界摘要、射击／弹药／损伤一致。
3. 原生装配：模块和场景组装后，短时自退出验证枪口／爆点位置与当前镜头监听；P0 和占位回退路径都可运行。不得先反复开浏览器。固定版本及模板由后续验收会话实查，本轮未启动版本命令。
4. Chrome 仅使用 Apple M5／16 GB，记录实际版本／UA、DPR、1280×720 drawing buffer、音频设备与 AudioContext 采样率、音频 hash、种子／镜头路径、仿真和墙钟时间。从最新根源码构建；旧 S08 包只作对照。默认无声 → 明确点击启声，真实输出旁路录制 30–60 秒覆盖四组关键段；按钮亮起或单个源文件可解码不算可听证据。
5. 操作矩阵：有声与静音分别测暂停／恢复，0.5／1／2／4×、倍率改变中切镜、自由移动／跟随／自动切镜、声音按钮持焦点时 Space、暂停中开关声音、结束／战报、标签隐藏／恢复、退出与三次重开。持续按键和重复点击不能重复恢复 source；暂停时无声漏出，恢复无旧枪声洪峰，结束／重开无旧引擎残留。
6. 至少累计 **10 分钟实际有声且可见的有效战斗墙钟**，暂停／后台等待不计；含至少一段连续 5 分钟，场景自然结束则保存原结果并按标准种子重开累计，不伪造伤害来延长。三次重开各记录重开前后 generation、真实世界状态、物理／活动声源与缓存。若当前场景无法覆盖某状态，另用清楚标识的受控预设，不能冒称默认实战。
7. 每秒记录 allocated／active／virtualized、分组／裁掉／抢占、缓存长度、音频调度耗时、Web source 创建、AudioContext／worklet、WASM、JS heap、页面 Renderer 物理内存和整浏览器口径说明。保留全时序并剔除热身作比较；单次切换允许初始化分配，静止／暂停时不能持续重建 native sample source，循环切镜／重开后必须回到有界平台。WASM 固定不等于进程无泄漏，不能仅凭两个端点作结论。
8. 对相同种子、分辨率和镜头路径比较开／关声音的持续交战窗口，保存 rAF 帧时 p50／p95／p99、>33.33 ms 比例、模拟积欠、真实弹丸／单位负载；音频开销候选预算与全项目稳定 30 FPS 同时判断。压限后无削波／持续泵动；近距声画差实测 p95，超出 150 ms 候选目标则记录问题，不切回已知有风险的 sample 后端或偷改阈值。未来满编制另验，不用 4＋8 证明 200 架飞机。
9. 所有本轮临时 Chrome 标签、引擎／预览进程和 HTTP 服务在成功／失败／超时后关闭并有归属／退出证据，不动用户原有窗口。由统筹独立审查，文档状态与实际证据一致后再认定实施通过。
