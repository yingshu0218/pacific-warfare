OP1667为1946美国海军原始弹药识别汇编，本地完整扫描272页来自[可直接读取的免费副本](https://stephentaylorhistorian.com/wp-content/uploads/2020/09/op-1667-japanese-explosive-ordnance-volume-1.pdf)。PDF51/53/54/163页均已打开图像检查，不能仅凭OCR或索引页算核过。

炸弹的有限时间/距离保险、AN-M64的0.1秒接触延时、阻力系数、统一4.184MJ/kg能量换算、45/75m伤害半径、16/28m视觉半径及结构伤害系数均是游戏近似。日本九八式装药未声称等同TNT。模型完整弹体/尾翼/挂耳的保守离架包络经过实际顶点检查；其目的为验证完全清离，不冒充历史气动外形或精细刚体碰撞。

四型不沿用F6F狗斗参数。新双发机保留更小的滚转/俯仰/坡度与载荷限制；模型原点是各自几何基准，未测重心。现有力积分没有完整升阻极线、弹性、旋转释放速度、逐发动机扭矩或量化俯冲减速板曲线。上述缺口作为验收边界保留，不能把“可以飞并实际投弹”写成历史性能认证。
