# 美国 40-mm M1，Carriage M2A1，1944-01-17

S10 资料阶段。**身份与大形参考可用，模型尚未制作/验收。** 唯一主体是美国陆用单管 M1 安装于四轮 M2A1 炮架，展开支腿、降低底盘、四脚接地，M3 开放瞄具。依据 War Department《TM 9-252》（17 January 1944），不以舰用四联或英国炮架替换。[原文 §1–4](https://legacy.maritime.org/doc/boforstm252/index.php)。

## 需要解决的大形

1. 单根细长炮管、喇叭状消焰器、炮尾/进弹口与两侧瞄具支架的比例。
2. 低底盘、四轮、两侧展开支腿和四个落地脚，且上炮架/双操作座位可独立回转。
3. 炮耳处俯仰、后坐炮管、座位与固定底盘的分组，不能把轮架或座位跟着炮管一起仰起。

## 弹药与射击配置

选择1944手册表 I/II 第9类 HE-T (SD, No.12) Mk.II，P.D. M64A1；弹丸1.96 lb（0.8890 kg），初速2,870 ft/s（874.776 m/s），TNT装药0.14 lb（0.0635 kg）。触发碰炸，曳光约7–10秒燃尽自毁；本轮若采用固定8.5秒，标为取区间中值的游戏近似，绝不能按目标飞行时间定时空爆。防空有效射程取2,743.2m（3,000yd），快速连发周期0.5s（120rpm），每弹夹4发。库存和供弹持续性另列场景近似。[TM 9-252 §109–112](https://legacy.maritime.org/doc/boforstm252/part4a.php)，[§2](https://legacy.maritime.org/doc/boforstm252/index.php)。

首版可把连续上弹简化为有限弹仓状态，不制作人员/弹夹搬运。若要实现4发连射后的装填间隔，单独记录为游戏操作近似，不能把不存在的长弹匣添加到外形。只有真实碰撞或固定曳光自毁才能触发后果。

## 装配与核对清单

- 原点：四脚承载平面与回转轴交点；-Z为零位射向，+X右，+Y上，默认缩放1。
- 固定底盘：前后轴/四轮、两支腿、四脚、牵引杆。射击状态轮组不承担主要落地支撑，脚盘可见接地；无额外舰用圆柱。
- 上炮架：座圈、炮耳支架、左右操作座位/手轮，随train回转。
- 俯仰：摇架、炮尾、管、瞄具支撑按参考分组；炮管单独做短后坐。
- `weapon_seat`、炮耳、唯一 `muzzle_0` 与 WeaponState 对应；炮口朝向和纯数据变换一一核对。
- 后续从同一个Godot场景输出AA-02近侧、AA-01斜前、AA-03后侧及俯视，先查轮距/支腿/轴线，再查安装和独立运动。

未知：精确底盘展开尺寸、炮耳高度、少量不影响大形的制造批次差异和战时涂装。可据互补照片估计简化外壳；不得把图中M2共通局部据为已核的M2A1专有齿轮结构。当前没有模型截图或AI目标图，未进行引擎/浏览器验证。
