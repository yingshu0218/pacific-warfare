# SB2C Helldiver

当前模型机型：**Curtiss SB2C-4 Helldiver（1944–1945）**。历史资料以穿孔式分裂减速板作为 -4 特征；当前模型阶段按用户要求使用无孔实体面板，优先完成整体轮廓。不把 SB2C-5 的座舱、油箱或机身改进套用到本模型。

2026-11-11 状态：本轮整体外形、必要装配与现有飞行接口已由统筹确认准入通过，见[准入复核](../../../showcase/acceptance/SB2C-admission-review.md)和[交付](../../../showcase/deliveries/SB2C-admission.md)。整场景 Chrome 与起降、投弹行为另行验收。建模交接请先读[参考任务卡](modeling-brief.md)：资料角度与精度仍有限，准入不代表精确测绘复原。

## 子型与尺寸依据

- [美国海军历史与遗产司令部（NHHC）：Dictionary of American Naval Aviation Squadrons, Vol. I，附录 1–3](https://www.history.navy.mil/content/dam/nhhc/research/histories/naval-aviation/dictionary-of-american-naval-aviation-squadrons-volume-1/pdfs/app1-3.pdf) — SB2C-3 资料列出 Wright R-2600-20、两门翼内 20 mm 炮和后座双联 .30 in 活动机枪；SB2C-4 以 -3 为基础并增加穿孔式减速板。模型只沿用 -3 至 -4 的明确共通配置。
- [美国海军陆战队：Marine Corps Aircraft 1913–2000](https://www.usmcu.edu/Portals/218/Marine%20Corps%20Aircraft%201913-2000%20PCN%2019000411600.pdf) — SB2C-4 的机长 36 ft 3 in、翼展 49 ft 9 in，用于机长与翼展换算。
- [Wright State University：Curtiss SB2C-4 左侧视照片](https://corescholar.libraries.wright.edu/special_ms223_photographs/130/) — 本轮仅保存并实际查看网页提供的低分辨率公开预览；高清复制件受馆方复制政策约束，未获取。
- [Hobby Master 1:72 SB2C-4 顶/腹视模型参考](https://www.carousell.sg/p/hobby-master-1-72-sb2c-4-helldiver-white-80-of-vb-85-uss-shangri-la-tokyo-raids-1945-1151814261/) — 第三方收藏品页面，仅作顶视、腹视挂载位置补充，不作为尺寸或结构权威来源。
- [Smithsonian National Air and Space Museum：Curtiss SB2C-5 Helldiver](https://airandspace.si.edu/collection-objects/curtiss-sb2c-5-helldiver/nasm_A19610118000) — 只用于同系列发动机罩、起落架等家族轮廓背景；未把 -5 专有特征当成 -4 数据。

模型尺寸采用长 11.049 m、翼展 15.164 m；机高 4.496 m 参考同系列 -5 资料并标为估值，不宣称是 SB2C-4 的测绘值。HVAR 与 500 lb 炸弹是可视化示例挂载；其站位/数量没有作为 SB2C-4 的标准作战载荷断言。驾驶舱内部、炮架、翼型厚度、面板线和活动减速板的安装位置包含照片估算。
