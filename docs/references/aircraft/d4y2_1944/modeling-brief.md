# AV02：D4Y2 彗星一二型参考卡

2026-11-11，状态：资料已查阅，独立模型/静态装配由统筹通过，参考缺口继续保留。目标锁为 **1944-10 生产构型的 D4Y2 一二型**：アツタ三二型液冷倒V12、三叶桨、非甲型、非夜战/侦察型。月份采用A-11表II的“Date adopted”，不是宣称首架生产或首次出击日期。与翔鹤1941-08-23并置是架空跨年静态检查。

本轮三个大形问题：连续狭长液冷机头及下颏散热器；长而低的分段曲面座舱盖；主轮/短尾轮与尾低停放姿态。保留正确主翼/尾翼外形与连接，省略发动机内部、铆钉、复杂轮舱、传动和密集面板线。

## 原始约束

已实际打开 USNTMJ **A-11 PDF p18 / 印刷p16 Table II** 的原扫描，选读SUISEI-12行：[完整报告](../../ships/shokaku_1941_08_23/original/P02.pdf)、[本轮表页](original/P01-A11-table-II.png)。表记翼展11.497m、长10.22m、高3.740m、面积23.6m²，采用日期Oct44。建模使用名义翼展11.50m与长10.22m，不采用冲突的11.22m。表未注明高度的姿态、桨相位、轮胎压缩或测量方法；**3.740m是资料栏值，不是模型停机实测值或强行达成的支柱长度**。

发动机交叉核对：[Smithsonian馆藏Atsuta32条目](https://airandspace.si.edu/collection-objects/aichi-atsuta-32-ha-60-model-32-inverted-v-12-engine/nasm_A19731575000)搜索可读，正文访问403，未假称看过其原物图。武装构型采用机头两挺九七式7.7mm、后座单挺一式7.92mm（MG15）、内部一枚250kg显示挂载。不把修复机九二式平盘枪或D4Y2a的13mm枪混入。[FineMolds自家说明](https://finemolds.co.jp/www/newAA.bak)明确一式7.9mm/MG15用于彗星；[G01产品原图](original/G01.jpg)已打开，用于双鼓弹仓与枪体轮廓。[Profile241](https://www.gruppofalchi.com/files/Profile-Publications-Aircraft-241---Aichi-D3A-Yokosuka-D4Y.pdf)型号段为交叉线索，非本轮取得的厂图。具体安装点、枪架幅度与弹药量未得到原厂表，本轮均标照片估计/未来模拟参数，不能据此宣称火控通过。

## 缺口与允许范围

缺少同一生产批的严格正顶/正侧厂图、完整战时机腹/尾钩放下照、后座一式枪实机近照与轮胎测绘表。完整外形以互补成品＋原物照片＋A-11尺寸约束；轮径/轮站/尾钩、弹舱/弹架和枪架站位须明确估计，不能标“全部历史精确”。模型可实现必要动作和真实承载验证，不扩展复杂细节来掩盖缺图。

不新生成AI几何：按任务允许的可选AI目标，采用[全项目已认可SB2C v04](../../bombers/sb2c/target/sb2c4-outer-form-candidate-v04.png)的` simplified-historical-v0.2 `材质/细节预算，结构完全回查本型原图。所有可靠多视图由同一个Godot模型导出，记录于AV02证据目录。

最终机身圆标按统筹授权省略，保留完整翼面标志与干净机身；属于首版涂装简化，不声称特定战时飞机无机身日章。模型的原机外形、武器配置与轮组约束不因此放宽。
