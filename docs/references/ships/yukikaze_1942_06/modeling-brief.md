# 雪風 Yukikaze：1942-06-04

S03 提交验收资料，2026-11-10。选择阳炎级八号舰、佐世保建造的雪风，锁定中途岛护航时期的早期三座双联装主炮状态。**不是把 1940、1943、1947 装备混合成一天的照片**；采用同舰早期照片加改装边界作有据重建，交付保留这种证据等级。最终由统筹独立验收。

### 1942 状态的推断链

Y01/Y02 是同舰改装前大形，不是目标日期的原地照。J02 记载 1943 年 5 月才在舰桥前加小炮、后烟囱双联改三联，8–9 月移除 X 炮并增加雷达；本模型选择这些改动前的早期结构。J01 和早期照片共同限定 3×2 C 型主炮。1947 图中的雷达、增设平台、解除武装状态全部排除。尚缺同时精确覆盖 1942 两舷细小附件的照片，因此不把其各个隐藏小件标为已核实。

## 未完成 / 接入边界

- 主炮与船体大形是有来源的简化重建，实际偏移没有船厂测绘精度；提交统筹复验，不由自测宣称史实全部通过。

- 保留 2×2 Type96 的历史基准与游戏清单。射速、转速、库存和代表弹药参数暂为 `provisional`，待 S05 校准，不能把本板块视作射击系统或防空效果已集成。
- 模型无时钟、自动瞄准、弹药扣除或鱼雷发射。完整射界遮挡和发射许可在 S05；本板块验证炮管在若干有用姿态下不穿自身其他模块，不承诺所有机械角度都可开火。
