# USS Fletcher DD-445：1942-07-18

S03 提交验收资料，2026-11-10。原始图已实际打开；本型采用早期圆舰桥、单杆前桅。不是 1943 年改装状态，更不是战后 DDE。模型和安装可用性由机制检查证明，史实和外形由本页原图对照单独检查；整板块由统筹验收。

### 位置重建方法

先用 F01/F02 核整舰、前后关系及真实宿主，再用 F06 的侧/俯比例去除明显透视误差，最后回看 F03–F05 的安装面。早期仅凭照片初估的后半舰位置偏后，已按辅助布置视图和原图回查修正。主炮纵向重建容差约 ±0.6–1 m，建筑与甲板标高约 ±0.3–0.5 m；不是未经核对的任意摆放，也不是船厂测绘坐标。

`data/ships/fletcher_dd445/assembly.json` 保存来源编号和真实承载面；正式单位 JSON 保存世界使用的炮位和炮口。固定底座下端位于宿主 Marker，武器原点位于座圈上端。测试另外以实际三角网格检查 Marker 所在表面，不只比较两份元数据。
