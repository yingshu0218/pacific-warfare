# S13 云层与海面复核

2026-11-11。**简化云海表现、原生装配/机制和当前场景的 Chrome 短测通过。** 不包含 S08 最终十分钟、完整编制与有声验收。[独立审计](S13-root-audit.json)记录实际读取的证据和限制。

云层有柔和的大块层次与缓慢风移；近景海面保留多尺度波纹，远处细节和颜色平顺衰减。统筹查看了舰侧、高空飞机、云景、海天远景、连续帧拼图及 Chrome 实拍；现有简化画面的辨识度可接受。实现不改变海面模拟高度、地图、弹道、单位运动或 UI。

原生 264 帧的前后 20 份冻结源哈希一致，暂停像素冻结，19 项机制检查通过。Chrome 最终控制轮 16 项通过，实际操作暂停/恢复、4 倍速和三次重开；节点数量稳定且复用同一对材质。四轮 Chrome 均有清理记录，统筹独立确认 52 个已记录验证进程组已退出。

当前四舰八机、M5/16 GB、1280×720 的舰侧 15 秒与高空 10 秒样本，统筹从原始 rAF 重算 p95 分别为 **14.8 / 13.8 ms**，采样时页面均 visible/focused。性能来自 `chrome-attempt2/run.json`；该轮在采样完成后因测试按键未切换倍率失败，不能宣称整轮通过。最终 `chrome/run.json` 使用实际菜单项点击，补完控制检查；两包只有测试夹具变化，运行源一致。旧/新环境暂停对照 p95 为 11.1 / 12.2 ms，仅作本次短样本，不当作独立 GPU 成本。

验证包曾拷入未被运行使用的 AU01 `source/recipe.json`；并行音频任务随后更新了这份元数据。该差异已明确保留，未修改冻结包哈希或伪称全仓相同。除验证配置/生成侧车文件与该来源元数据外，所比较的运行源与当前工作区匹配。

本版不含体积云、天气模拟、流体/逐浪浮力或真实舰影反射。连续画面按固定模拟步长导出，不能用其视频帧率替代浏览器性能；S08 仍需按后续集成版验收。
