统筹实际读取最终机制/逐帧数据和关键原生帧。真实三轮圆面支承、停机9.6453°、原点高1.203077m；滑跑抬尾和落地落尾连续。速度航迹角与物理机体姿态分离，进近约−2.2°航迹/+9°机体；同一原飞行积分推进位移，碰撞使用该真实机体姿态。正常清洁任务的1200tick位置/速度/姿态与原执行器差为零，起降构型限速没有永久影响空战。

触舰同时考虑轮胎、完整旋转桨盘、实际机腹/翼/尾/襟翼；钩鞋端与边缘扫掠实际三维索段，wire01事件最近距约1.25mm，上偏约23.64°，不使用固定机身后偏移或静态钩角。触舰、挂索、减速、清场、整备及第二波由真实状态推进；有限油弹、取消/改派/损失/占用复飞/母舰转向均有回归。

r10残骸曾只有Y方向下落、前部桨尖单点支承并锁死机身俯仰，统筹根据实际帧退回。r11按剩余mesh点云、声明的粗略部件质量/油料中心与重力投影连续倾倒；最终约3.9°俯仰/21.4°侧倾，支承跨度5.348m，投影误差1.17cm在1.5cm简化容差内。最大角速0.350001rad/s、单tick高度变动5.38cm，全过程穿透仅约1.53微米浮点误差。原断件、失效、阻塞及无补给不变，母舰失效后回到原DM坠落。统筹实际查看138/175/299帧确认悬空问题解除，不再扩展精细残骸刚体。
