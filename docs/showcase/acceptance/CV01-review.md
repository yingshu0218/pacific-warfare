# CV01 统筹验收

2026-11-11。**Essex CV-9（1944-04-15）的独立简化模型、武器装配、甲板接口与静态舰载机安装通过专项验收。** 航母作战注册、航空作业和 S14 扩展集成尚未通过，当前 19 单位基线继续排除此开发目录。

统筹实际查看了同舰原始照片、同级异期图纸及局部原始像素，并逐项核对模型侧视、俯视、艏艉斜视、前后炮组、炮架模块、升降机与 F6F／SB2C 安装。固定四座双联、四座单装 5in/38 的分组和层级保留；专用轻防空最终为五座四联 40mm、十二座单装 20mm，历史和游戏数量明确分开。CV17 的 1946 年图纸只作同级结构依据，不能据此声称本舰船厂测绘精度。

复核中要求修正的后 Mk37 悬空、甲板／机库标高、水线与全长混用、升降机孔口，以及法线修正后暴露的机库共面闪纹，均已在对应源码与修后机位检查。最终共同承载面不再重叠，后指挥仪使用实体塔；SB2C 低侧视能看清三轮落在甲板上。达到当前正常观战所需的轮廓、装配和活动接口后停止增加小细节。

独立检查了纯模型状态接口和实际三角面检查脚本；403 项机制检查通过。升降机当前高度、完整固定甲板、孔口和实际承载面相符，武器及升降机实例状态相互独立。飞机使用真实比例；展开 SB2C 不能被认证为可放入中线升降机，后续作业必须使用真实包络。F6F 当前可见高度与 spec 的差异及折翼接口缺口按交付记录带入 OPS01。

实际查看最终 Chrome 的侧视、后炮组、SB2C 低侧视和下降升降机画面，修复与原生一致。独立静态 Chrome 共 34 项检查、13 个视图通过，M5／16GB、实际 1440×900；六秒帧间隔 p95 11.3ms。采样镜头没有显示三架静态飞机，不将此结果当成全舰队、实战或航空作业性能。独立检视页的箭头字体缺字已记录，左右键功能正常。

核对 35 项运行依赖、63 项拥有文件、159 项证据、35 项冻结 Web 输入和 9 项构建输出，哈希全部一致。26 份验证记录含历史失败；最终指定的机制、原生、导入、导出和 Chrome 运行通过，43 个登记进程组与 26 个包装进程已不存在。见 [独立审计](CV01-root-audit.json)、[视觉复核过程](CV01-native-root-observations.json)与[交付](../deliveries/CV01.md)。

后续允许 CV02 消费共同甲板契约，OPS01 消费本舰局部表面、障碍和安装接口。不能把静态甲板摆放等同于起飞、回收、补给、排队或舰载火控完成。
