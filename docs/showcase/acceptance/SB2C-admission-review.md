# SB2C-4 Showcase 模型准入复核

2026-11-11。**本轮外形、必要装配与现有飞行适配准入通过。** 最终全场景/Chrome 仍由 S14/S08 接续；不把模型通过等同于投弹、自卫火控或航母起降通过。

统筹实际查看了本轮 baseline、r1、r2 同机位侧视与斜视，并对照本地 Wright State 在空侧面预览及 extra_09、extra_10、05 三张成品模型照片。r1 后腹线过平、尾端偏低与风挡圆弧过强已退回；r2 改为后腹逐步收起、与尾翼连贯的尾端及明确后倾风挡。简化后的连续机头、机身/翼尾、座舱罩与基本武器轮廓满足当前观战用途，不追加发动机内部、细框条、铆钉和复杂起落架。

最终实际查看侧面、斜前、正前、顶面、闭合机腹、后座枪架、尾轮、展示挂载及正常观战距离图。飞行形态收轮、闭舱、减速板闭合、展示挂载隐藏；展示形态有8个HVAR和1枚弹舱模型，但这是检视装配，不是已核实作战载荷。当前无明显孤立悬空件，座舱/后座、翼根及尾部可见连接达到本版标准。

模型接口保留+Y上、−Z前和米制1倍比例，飞行参考仍为[0,2.38,0]，S14适配平移[0,−2.38,0]；该点是表现参考，未冒称实测重心。原适配冒烟检查通过，桨相位/五个控制面能消费已有状态，实例状态独立。停放姿态由轮接触推导，未写入真实飞行根姿态。名义长度11.049m、翼展15.164m；高度和局部安装仍含照片估计，不宣称测绘精度。

独立核对9份源码/依赖、6份参考和14组最终PNG/元数据，全部hash相符；48份验证记录中的75个已登记进程组均已不存在，权限不明项为0。失败和锁等待记录保留，未当作成功次数。共享builder在两次侧视间因DM轮舱盖修正改变；SB2C使用自己的起落架构建函数，不调用该被修正的F6F/A6M主轮盖分支，最终图与当前builder对应。详见 [独立审计](SB2C-admission-root-audit.json)。
