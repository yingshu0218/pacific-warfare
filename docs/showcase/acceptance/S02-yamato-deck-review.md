# 大和甲板轮廓修正：统筹复核

2026-11-11：本次局部甲板轮廓、炮座接触与 Chrome 对应视角范围通过。用户指出的高低过渡不顺来自分段直线的斜率突变和较疏的截面采样。现在保留原有标高与高低结构，连续插值并按曲率补足截面；未扩大成整舰细节制作。

统筹实际看过正侧、前炮和后航空甲板的前后同机位原生截图、Chrome 正侧及对照图，并重新打开田宫整舰侧/俯和既有干舷/承载来源。前低甲板和后甲板接平处的硬折线已改善。原来源的日期限制、图像比例标高与程序横剖面近似仍然存在，网格误差小不代表历史尺寸精确至毫米。

39 座武器 socket 前后逐项一致，七个相机的坐标/目标/正交尺寸一致；三座三联主炮、两座三联副炮的座面、炮口和运动接口保持。主炮固定炮座下缘贴合实际甲板，不增加通用垫高件。几何检查覆盖共享边界、无过冲、切线连续和实际宿主接触；最大曲线到网格误差 3.83 mm，主炮下缘接触最大误差约 0.048 mm。

[独立审计](S02-deck-root-audit.json)核对冻结输入、证据索引与构建产物，无校验值不符；本轮 25 个自建验证进程已退出，两个 HTTP 端口关闭。首次几何误差、锁超时、打包及页面标题断言失败都保留。已通过项未重复启动引擎或浏览器。

实际 Chrome 七视角、键盘切换、硬件 ANGLE 与无页面/控制台错误的记录通过。M5/16GB、1600×1000、6 秒单舰检视样本 P95 为 10.1 ms；该结果只说明本局部检视，不替代最终战场性能或 S08 长测。完整模型 216 个网格不变，三角形约增加 3.47%。

用户随后框选舰中段，询问连续隆起是否正常。统筹重看完整侧视资料及干舷来源：中段相对前主炮区/后航空甲板的高差有依据，上层建筑侧壁也叠加在同一侧视轮廓中；不能据“出现隆起”判断为错误，也不能据这次平滑/接触检查把估算的所有中间高度、起止范围提升为完全还原。已向用户明确区分这两点。本轮没有据此任意拉平甲板，也未新增模型细节。
