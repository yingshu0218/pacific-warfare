# S14 场景安排与当前接口

2026-11-11，最终集成自验。正常入口 `showcase/all_units.tscn`，四型舰、三型机、三座两型陆基炮组共19个单位，使用冻结岛港地图/S13云海。五项港口兵器检视另计。模型、性能、装备/炮位与真实毁伤沿各专项准入。

连续导览先双机、SB2C，再四舰和两型地面炮，随后四机/交战/集结/护航、兵器检视及自动观战。16项菜单包括原6段和两型各5项实际训练；“重新演示”重置整场并增长generation，兵器检视不重置。所有单位保持稳定ID，选择器加“跟随”直接查看九型。

导演只提交统一BattleOrder。双机/四机导航、实际接敌/射击/毁伤仍由生产执行器和飞控决定；四机52秒下达重组，必须两方实际订单完成才标注结束。护航威胁在58秒收到撤离命令；护航机回到2500米内、实际escort警戒/编队阶段持续3秒后才标注恢复。

四机镜头轮换总览、攻击对、支援对和单机；实际对内距离超过650米改用单机。护航轮换38米SB2C近景、护航双机、上下文和威胁近景；训练34米单机、固定世界上方向。镜头只读快照，不移动/缩放单位，不伪造滚转。保留双方真实指挥卡、执行/时间线、暂停/倍率/重开和自由相机。

两型训练使用同一 `aircraft_training` 指令和已验S04飞控，实际执行及保留结果匹配当前order_id后才显示完成；阶段与拒绝/安全原因本地化。SB2C仅导航及作为护航对象，使用已准入r2模型、原点与clean接口；没有轰炸、后射手和起降。

最终源码、连续原生、Chrome和视频均已登记于 [S14交付](deliveries/S14.md)。S08接 [冻结交接卡](S14-S08-handoff.md) 做普通启动、最终包、10分钟、三次R及4倍实效；本轮不增加新镜头/模型范围。CV01/MAP02和候选音源不进入本19单位基线。
