# S14 → BOMB01 组合边界与场景需求

2026-11-11。S14拥有公共Session、注册、适配、菜单与观战集成。本轮仍为`candidates/s14-expansion/`私有候选，未替换普通S08包；BOMB仅在统筹验收最终冻结清单后单一准入。不得递归扫描BOMB开发目录。

## 必须增加的两个普通场景

1. **B-25自主轰炸**：使用AV04最终透明机鼻B-25J及真实日本舰艇目标，发布合法已知任务目标/区域。由己方观测、进入姿态、速度/高度、有限载荷、伤情与目标状态决定投放或中止。相机观察进入、完整离架、弹道、命中或漏失及脱离，不保证命中。
2. **战斗机拦截轰炸机**：至少接入已通过的一组真实机型，可用A6M拦B-25或F6F拦G4M。拦截方从己方接触发现目标，由统一指令分配战斗机；轰炸机继续自身轰炸/返航/受扰规则，不能转入狗斗。保护未截获、中止、漏失、损失等真实结果，不保证击落。

G4M可攻击实际美国舰艇或已准入的美国岸炮。无需等待AA02；MAP02装饰港口建筑没有单位健康，不作为“摧毁”目标。陆基双发可从合法在空初态开始，不把机场静态模型或陆基起降未接入伪装为任务完成。

## 航空与战斗唯一所有权

OPS r11提供唯一`task_bridge`、原飞行积分的`flight_bridge`与可选`CarrierMissionDelegate`。S14当前组合见`operations_installer.gd`：AircraftTasks300、OPS350、AircraftMotion400、ShipMotion410、甲板430、CombatDamage650、甲板残骸支承690。BOMB应组合进唯一任务执行器，不能再次安装AircraftSuite。非舰载轰炸机也使用同一任务域与飞行积分；不以给每款飞机注册另一套模块规避组合。

必须合并而非整文件覆盖的当前S14候选：

- `scripts/game/first_playable_session.gd`：可选OPS安装、正式舰艇fleet profiles、扩展战斗参数，必须保留同一catalog/world。
- `scripts/command/commander/fleet_planner.gd`：甲板`carrier_ops.on_deck`飞机不参加空中编组分配；只有性能数据显式`role: fighter`可进入舰队截击/空战护航列表。角色判断在通用枪弹/油伤撤离判据之前；非战斗机不归FleetPlanner航空策略管辖。轰炸编成、有限炸弹库存、资源/损伤中止及返航由唯一攻击任务规则负责，不能只用`source=human`永久锁住轰炸机掩盖角色缺口。
- `data/aircraft/performance.json`：S14给既有F6F/A6M补`role: fighter`；SB2C当前为`strike_navigation_only`。准入BOMB性能时保留两款战斗机角色，按正式契约更新攻击机角色及任务可用类型。
- `scripts/simulation/simulation_world.gd`：现有统一指令校验增加可选`area.on_station_duration_s`，仅`patrol`允许，有限数值范围1–86400秒。字段已随BattleOrder.area序列化，不增加第二入口。BOMB的任务类型/字段校验须重基到此版本。
- `scripts/air_operations/carrier_operations.gd`：删除隐藏的110秒巡逻返航条件；仅实际指令提供`area.on_station_duration_s`时按其在mission阶段的实际在站时长返航。缺省不限时；真实低油和显式召回继续生效。delegate active时不强加该期限，显式`return_requested/return_reason`沿已发布hook返回。UI显示实际指令期限与实际原因。
- `scripts/presentation/observer_text.gd`及模型Adapter：合并真实轰炸阶段/中止原因、真实库存与活动部件显示，不加入预写战果。

现有SB2C的DM显示必须保留。BOMB私有`BombingAircraftView`若对SB2C分支未调用其新`_damage`，不能因此整型替换既有AircraftAdapter并丢失已接入的断翼、烟、失控坠落/落水消费。正式组合沿旧SB2C损伤显示追加真实炸弹/舱门状态，或提供等价覆盖并做受影响回归；此项待BOMB冻结后处理，不扩改当前模型阶段。

## 轰炸任务资源与生命周期

未装防御枪位、枪弹为0不等于炸弹为0；有限炸弹库存须来自正式挂载/武器槽位。FleetPlanner只管理舰艇和显式战斗机，不能用通用`unit.weapons`枪弹合计抢占非战斗机的任务，也不能因最后一枚投下就立刻覆盖必须执行的拉起/脱离。活动轰炸任务的唯一delegate负责实际低油/无弹/受损/目标丢失的中止、拉起、脱离、重组及返航；正常巡航/返航/队形命令仍由共享任务入口合法执行。真实DM终端保持更高运动所有权。

BOMB正式机制冻结必须给出其角色字段、有限载荷快照、活动任务阶段、资源中止原因和指令释放时点。S14按该契约合并，不再为相同机体安装另一个轰炸指挥器或周期性重派任务；程序指挥与未来真人仍走同一校验。独立检查含：无防御枪且满载炸弹时可接受任务、投完后的连续拉起/脱离不被通用retreat覆盖、真实低油或损伤按同一任务规则改变后续。

## 战斗机指挥唯一所有权

组合时每个截击编组只能有一个程序任务分配者。当前FleetPlanner已能按己方接触分配显式战斗机；BOMB私有BombingCommander若也含截击策略，不能两者同时对同一批战斗机发新命令。优先保留FleetPlanner管理战斗机、BOMB任务规则管理轰炸角色；若最终冻结契约要求BombingCommander管理指定截击编组，则须以明确的编组/任务控制权在另一策略中排除，并验证取消、终止、重开后的交还。不能用永久`source=human`封锁另一策略来代替唯一所有权，不能让两条AI指令轮流覆盖。

最终组合检查保存同一飞机的完整指令ID/下令人/替代关系，核己方接触出现后的实际分配，以及任务结束后的继续截击或结束规则；不只检查曾经有一条intercept指令。

## 自主性与冻结验收

S14已将普通ShowcaseMissions改为仅初始化合法任务；fixed_update仅每0.5秒只读实际unit.task的phase，不复制commander_snapshot或完整订单。既有12/52/88/120/160秒以及护航12/58秒的演出指令已移除。训练入口明确标记训练，仍由统一飞控执行；只读镜头可以保留观察时长。

本轮自主回归使用相同两个真实战斗机、改变初始来袭距离：无接触181秒不产生定向攻击/拦截/重组/撤退；近距接触后拦截，远距接触与拦截随实际推进延后；初始低油改派返航。BOMB还须核实际轰炸实例与真实拦截干扰实例，以及延后探测/改变初态、低油/无弹/目标丢失/实际伤损对任务的影响。不能以“库存扣除”单独代替完整离架/首次碰撞/真实结果。

所有新行为证据使用组合后重新冻结的明确输入；旧演出版和单机制夹具保留历史身份。最终模型、基本飞行、轰炸、拦截、防御枪位、OPS/陆基作业、DM能力分别列状态。
