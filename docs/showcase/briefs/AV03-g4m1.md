# AV03 G4M1 一式陆攻模型

用户已授权日本较大型轰炸机，沿默认采用 **G4M1 一一型**。SB2C必须先由统筹明确通过，再安排本任务；不自动接续Ki-21。原轰炸机聊天可复用，或按工作量由统筹新建，单轮只做本型。

先精选并实际看过匹配一一型的整机多视角及主要防御枪位资料。现有套件照片、识别模型和档案目录只作为各自可支持的线索；投降代表团机的白色涂装/移除武装不能直接当战斗配置，G4M2机鼻/机翼/炮塔不混入。

主体保留大机身、双发短舱、机翼/尾翼、机鼻/座舱、后机身与防御武装位置比例；连续外壳、少量框线、简单轮杆，内部/细孔后置。炮位是带射界和活动轴的独立模块，未来可实例独立运动；弹舱/挂载清楚区分本轮水平轰炸配置和以后鱼雷配置，不能同时随意堆挂。

发布米制原点/轴、两台发动机与螺旋桨、起落架、必要控制面、弹舱/投放挂点、各防御炮口、左右翼/尾/发动机损伤分组。提供本型尺寸/性能/载荷来源与近似数据，不能拷贝战斗机性能。BOMB01负责水平轰炸/有限防御火控；OPS01负责陆基起降，本模型不是舰载飞机。

只拥有 `aircraft/g4m1/`、专属数据/参考/检查，公共航空/伤害扩展交统筹指定单一所有者。模块→整机安装→原生检视→使用场景，Chrome留集成。所有重型验证经verify同一锁、超时/清理；交付 `docs/showcase/deliveries/AV03.md`、证据/接口/哈希和未核实项，由统筹逐项验收。
