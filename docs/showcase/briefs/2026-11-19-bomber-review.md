# B-25 背部炮塔与日军轰炸机外形

普通港湾、轰炸和截击场景共用同一套单位。两个执行聊天采用 GPT-6.2 Sol High，统筹保留了修改前的运行输入、测试与 Web 包，位置为 `.local/repairs/20261119_bomber_review/before`。Godot 验证通过 `tools/verify.py` 串行进行，浏览器由统筹使用 Ego Lite 复核。

## B25G01 背部炮塔

检查已准入的透明机鼻 B-25J 背部双联枪塔，在日常轰炸及零战截击场景中贯通游戏内防守动作、姿态、射击事件、库存和模型。沿用本游戏的接触、有限弹药与武器执行器；采用简化的游戏规则。轰炸、返航与机身姿态仍由原任务控制。记录何时有合适的游戏内接触，何时因没有目标、角度、停火、弹尽或失能而安静。给出相同模型两实例各自改变姿态的证据，核对普通场景中可见的塔座／枪管运动和由事件产生的曳光。地面停机、暂停、重开及离开接触后的状态均应合理。

实施范围是 B-25 的装备／模型接口、已有模拟和航空表现适配，以及针对该变化的测试。其他飞机既有行为与模型文件由原模块保有。请记录新增运行资源，交付到 `docs/deliveries/B25G01.md`。

## AV05 一式陆攻一一型与彗星一二型

范围是 `aircraft/g4m1/` 的 1942-07 G4M1 和 `aircraft/d4y2/` 的 1944-10 D4Y2。先实际打开各自资料包中的整机原图，记录型号、来源、视角、限用信息，同时抓取正常运行模型的同机位改前画面。优先修改机身截面与收尾、翼根到翼尖的厚度和平面轮廓、座舱玻璃体积与连接。G4M1 特别核对机鼻玻璃、双发动机短舱和尾部，D4Y2 特别核对液冷长机鼻、串列舱盖和翼尾衔接。处理倒面、缺面、硬截断、交错、突起和色面造成的假轮廓。保留简化历史外观及现有活动件、损伤分组、挂弹、收轮、标记接口。普通观战下更容易认出两型为质量依据。

同机位交付每型改前／改后的近侧面、斜前、上方及普通跟随距离的画面，转一圈检查两侧与机腹。对比使用同光照、同机位及一致飞行状态。说明参考图无法确认的细节以及绘制成本，交付到 `docs/deliveries/AV05.md`。该聊天独占两架日机的模型；两个聊天均将普通包准入、Web 导出和浏览器复核交给统筹。
