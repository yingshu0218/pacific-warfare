# S04 A6M5a 舰载使用态接续

统筹在日本航空作业接入前安排原航空聊天；当前尚未派发。复用机体，不与 F6F 候选、OPS 或公共适配所有者同时写相同文件。普通 S08 基线继续可用。

2026-11-11 统筹实际查看 CV02 `native-r1/a6m_actual_wheels.png`：旧模型三轮接地，但尾轮支柱明显过长、停机机体过平。该图仅证明旧模型尺寸与甲板静态承载，不证明真实 A6M 停放外形。CV02 不负责修改飞机。

本次接续须以 A6M5a 匹配资料修正简化尾轮外形和真实接点，保持机体、机翼、炮口、飞行原点及损伤轴不变；从三个实际轮胎接点求停机俯仰与高度，不为了沿用旧坐标拉长支柱或缩放飞机。补简单放轮、襟翼、尾钩状态及纯几何数据，遵循已验收 F6F 接口语义，但不能复制其长度、角度和轮组布局。

在 CV02 正式甲板上验证三轮承载、自由钩与甲板约束钩、升降机与停机包络、舰岛/烟囱净空。若使用 1944 年 A6M5a 与 1941 年翔鹤，继续明确架空跨年代组合。收放机构用必要显隐/有限转轴即可；不做液压、内舱、地勤。

同型号多实例独立，既有清洁飞行与 DM 脱离状态不退化。先原生正侧/斜视及有意义的模型回归，再交 OPS 消费真实坐标；模型通过不能记作日本起降完成。正式公共准入仍由 S14 单一所有者完成。
