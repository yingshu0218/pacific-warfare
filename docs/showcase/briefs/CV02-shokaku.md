# CV02 翔鹤航母模型

按 `expansion-plan.md` 由统筹启动独立 Sol6.1 max 聊天；不创建下级代理。目标翔鹤级翔鹤，2026-11-11统筹已接受资料选择1941-08-23竣工配置。1941年照片与同级瑞鹤资料分别标注能支持的共通部分，不把另一舰的防空/甲板配置拼上来。

遵守军舰模块化/参考图规范和统一简化标准。必须实际看过整舰侧视、高位/俯视和斜前后参考。主体重点是舰体艏艉、飞行甲板轮廓与层级、舰岛、舷侧烟囱、升降机和真实外伸平台；主炮/高平两用炮逐座核炮型、数量/联装、位置与承载，轻防空另列历史/游戏清单。不做内部机库、精细索具/栏杆和表面孔洞。

沿 CV01 发布的 `docs/carrier-deck-contracts.md` 表达本舰自己的甲板布局，不能套用美国舰形状或把停机区域复制到障碍上。局部坐标、甲板高度/边界、升降机、起降中心线、停放/折翼区、障碍与宿主接口必须同可见表面一致。先以真实尺寸A6M和D4Y占位/准入模型检查净空，未准入的占位明确标记，不能冒充航空作业。

所有权为本舰专属模型/装配/舰艇定义适配、必要炮架变型、资料/专属检查。公共甲板语义如需变更先交统筹指定唯一编辑者；不改CV01、S14、航空AI、战斗/效果或根入口。模型独立展示和使用场景分开，模块→整舰安装→原生→使用场景后才安排Chrome。

所有重型检查用 `tools/verify.py --owner CV02` 统一锁/超时/清理。交付 `docs/showcase/deliveries/CV02.md`、对应证据/来源与配置表/哈希、甲板数据和未核实项；统筹独立看形体/炮位与装配后准入。
