# S13：云层与海面视觉效果

2026-11-10。用户明确要求制作云层与海面的视觉效果；本任务包含实际实现与验证，沿用简化画面、Codex＋Godot、独立板块对话和最多两个执行对话的安排。

## 视觉目标

直接改善现有 Showcase 群岛港湾与开阔海场景。固定白昼、疏云和温和海况，保持历史单位与战斗动作清楚。统筹已实际查看 S09 的 ship_sea.png 和 air_combat.png：天空缺乏层次；舰旁波纹细碎而远海平板；高空视角海天接线形成明显平直色带。旧图只作历史对照，新交付必须基于当前代码重拍。

- 云：可辨的大块疏云、少量薄云、柔和明暗与缓慢风移；方向与太阳照明协调。飞机与海面视角都要自然，转动镜头不能出现贴屏漂移、刺眼边缘、平面交线或云层反复跳变。使用 Compatibility 可承受的天空着色或有限云层，按实拍选择；本版不做体积光线步进或天气模拟。
- 海：近景有风向相关的多尺度波纹和起伏感，反光克制；远处细节平顺消退，减少摩尔纹、长条纹、闪烁和塑料感。海天颜色/雾化连续，不让高空视角露出平面边界或直线拼缝。浅水、岸线、舰艇尾迹、水花与既有地图保持协调。
- 整体：简化、清楚、电影观战友好；不是以重做舰机、增加精细材质或大幅后处理来抬高画面成本。云海的亮度不能淹没飞机轮廓、炮火与指令信息。

## 工程边界与所有权

先读 AGENTS.md、总体规划与任务表、S09 交付、tools/verify.py，再检查 scripts/game/first_playable.gd 的环境创建与更新时间、scripts/presentation/ocean.gdshader、地图岸线表现与当前相机范围。固定 Godot 4.7.2.stable.official.ed1daf0bf、带类型 GDScript、Compatibility。

拥有新增的 scripts/presentation/environment/ 模块、云海所需自制资源与来源记录、Showcase ocean.gdshader、独立视觉验证夹具及本任务文档/证据。可最小修改 first_playable.gd 的环境装配/表现更新时间；优先把环境职责收进独立组件。地图表现仅在岸线拼接确实需要时做小幅适配，明确列出。

保留 root 大和入口、assets/ocean.gdshader 的旧样件和 first_playable.json 开阔海基线数据。不得修改地形高度/地图布局、装备与场景编制、单位运动、弹道、探测、伤害或 UI 布局。S12 第 1 方案已选但尚未实施；本任务不借机实现 UI。

水位仍使用现有统一模拟平面，云海只影响表现，不改变 AI 视线、命中或飞行性能。若使用很小的视觉波高，必须检查舰体水线、尾迹和水花不明显脱离。云/海动画使用同一可控表现时间，明确暂停、倍率和重开语义；不能让材质或节点在重开时不断增加。

S04 最终机动证据已冻结、执行对话已结束，待统筹复核；禁止覆盖 S04/S09 既有证据。S10 当前只做资料/型号核对，其运行接入仍由统筹单独放行；不修改其文件。不要创建下级聊天或子代理。

## 执行与验收

1. 检查现有实现，记录局部恢复副本到忽略目录。先确立统一的日光、海天颜色和风向，再实现云、海及必要接点。
2. 完成组件装配后，通过共享验证锁做 headless 导入和必要机制检查。所有引擎、渲染、导出、视频编码、浏览器验证均经 tools/verify.py；一次最多一个重型验证进程。
3. 原生检查至少覆盖舰侧低视角、舰队远景、高空飞机/岛屿、港湾岸线；保留相同镜头的前后对照和一段连续画面，亲自查看云的移动、海面闪烁与海天接线。静态截图不是运动通过证据。
4. 原生效果收敛后才做一次有界的真实 Chrome 验证，重新构建到本任务独立忽略目录；不复用 S08 旧网页包，不启动 Safari，不把 headless 数据当浏览器帧率。记录设备、分辨率、时长、p50/p95、控制台/着色器错误，检查暂停/恢复、倍率、重开。当前基准为 M5/16 GB、1280×720、30 FPS 与 p95≤33.3 ms；不满足要定位云海增量与既有瓶颈并给出实际结论。此短测不替代 S08 十分钟最终集成验收。
5. 本轮临时窗口、Chrome 标签、HTTP 服务与预览/编码进程均有超时和 finally 清理；仅清理本轮拥有的资源。不要关闭用户已有窗口，不留下自动预览常驻。

交付 docs/showcase/deliveries/S13.md、docs/showcase/evidence/S13/ 实际截图/连续画面/验证记录与源码哈希；统筹维护总计划、coordination 和 acceptance。输出真实限制，不把模型、地形、空战或整体 Showcase 一并标成验收通过。完成后结束对话释放并发名额，统筹独立检查后给用户展示实际效果。
