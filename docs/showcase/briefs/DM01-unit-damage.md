## 当前缺口

AircraftAdapter 仅整体变换、螺旋桨与操纵面，StaticModelBatch 会合并同级静态几何，尚无独立损伤模块。CombatDamage 只有 engine/steering/control 和总结构，左右翼碰撞代理均归 structure；飞机 crashing 只做重力位置积分，未体现断翼失控姿态。因此不能随机隐藏机翼或套一段整机下落动画当作真实受损链。

## 必做行为

1. 发动机：真实 engine 损伤降低动力，严重时失去推力、机首烟火/螺旋桨转速连续变化；仅发动机失效不自动触发断翼或整机爆炸。保留可控滑翔/逐渐失速直到进一步损伤或实际接触，具体近似写明。不要增加发动机内部机械细节。
2. 单侧断翼：增加明确左右翼损伤状态，由实际对应碰撞部位/累积损伤触发。达到失效阈值后该翼和其附属操纵面/武器脱离或失效，同侧炮口不能继续射击；缺失区域不再充当完整机翼碰撞体。脱离件继承当时世界位置、姿态与速度，不能从模型原点弹出。
3. 失控与浓烟：从受击时的真实速度/姿态连续进入失控，以有限角速度、重力/阻力和足够简化的非对称升力近似呈现滚偏、下坠。不能瞬间改 heading/俯仰、原地翻滚、冻结姿态平移落水或回到旧的正常飞行摇摆问题。完整未受损飞机的 S04 v3 行为应保持。
4. 严重解体：真实严重结构毁伤可分成少量预切模块（机身、左右翼、必要尾部），每次只触发一次。碎片数量与寿命有上限，表现碎片可不参与战斗碰撞，但须标明近似；主单位仍按统一伤害/地形接触处理。无需实时切割、精细断口、飞行员或内部零件。
5. 坠海/地面：实际 unit_surface_contact→unit_impact 触发 FX01 对应水花/尘土。禁止提前播落水、重复爆炸或海下继续冒出空中烟。坠毁主机体/少量残片合理沉入或淡出并回收，不长期以完整飞机浮在海面；陆地残骸与海面处置区分。

## 模型与契约

先完成可分离模型模块及装配。保留已核实的完整飞机轮廓、比例、座舱盖和武器布局；可以在实际损伤分界设置 Node3D 组，使合批遵守部件边界，不退回整机每零件绘制或整体关闭合批。左右翼上的标志、灯、机枪、操纵面随所属部件移动；实例独立，不能因共享网格改动所有飞机。

模拟拥有部位健康、故障/脱离事件和主机运动，渲染只消费；不要让观察镜头、帧率、效果池或随机视觉抖动改变战果。新事件/字段先写契约，再接入。保持己方情报与正常指挥 UI 的失能/损失/任务状态真实，死亡单位停火。暂停/倍率/重开和 generation 去重覆盖碎片、烟尾、模型复原。

拥有航空模型损伤组、AircraftAdapter、独立损伤表现/运动 helper 与航空相关必要模拟/碰撞变更。CombatDamage、CombatFrame、data/combat 和 first_playable 属跨模块共享，必须等 S10 释放后再改，保留 ground 分支与云海接入。CombatEffects 必须等 FX01 交付；优先通过已发布接口扩展。不得自行回退 S04 v3、修改历史整机性能来制造表演或覆盖其他证据。

## 验收与交付

每型均覆盖发动机失效、左/右翼断裂、严重解体与坠海；验证仍由真实命中/损伤路径触发，受控场景与默认自然交战分别标记。关键检查包括对应部位判定/同侧武器禁用、丢失翼不挡弹、未伤实例不变、脱离瞬间位置/速度连续、空中到海面只撞一次、死亡停火、池化/重开回收，以及相同输入在不同渲染节奏/暂停/倍率下模拟一致。未受损飞行只运行相关 S04 机动/地形回归，不无故重跑全项目。

原生连续片段先收敛，再在最新云海/效果/陆基集成下做有界真实 Chrome 检查，记录可读性、帧时与对象数量；完整十分钟/规模仍交 S08。固定引擎/Compatibility/仅 Chrome，所有引擎、编码、浏览器通过 tools/verify.py 同一锁并清理，不创建下级聊天/子代理。
