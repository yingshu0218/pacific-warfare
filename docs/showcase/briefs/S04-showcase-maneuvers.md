2026-11-11，依用户“空战单位包含编队和机动性演示”及此前明显滚转/侧滚、先滚转再拉杆的要求。仅在统筹释放名额并明确接续时执行；原 S04 先完成 DM01 最终衔接，再补本项。S14 负责场景/相机，S04 负责实际航空控制，保持单一所有权。

现有 `AirCombatManeuvers` 提供 F6F 的 break_turn / roll_reversal / split_s；`AircraftTasks` 接受 patrol / escort / intercept / engage / regroup / retreat，尚无可直接选择完整轴向滚转的演示任务。S14 不应把随机自然接敌当作唯一入口，也不能为演出直接改 transform。

最低可见内容为协调大倾角转弯、爬升/俯冲、完整轴向滚转、滚转换向及安全条件下的半滚倒转；两型战斗机均应有符合自身性能的可读演示，不能把 F6F 参数复制给 A6M。无需新增复杂特技目录或飞行员动画。现有控制器已经支持 lift_plane_normal/load_factor_g 等输入，可复用有界滚转、载荷、动力和重力积分；进度从实际姿态/航迹判断，不能仅按时间改模型角度。

先滚转卸载再拉杆的阶段要明确，完整滚转累计角度须跨越±PI正确计数；低高度/失速/超速/失去动力/新指令/损伤时中止并交还既有安全控制。有限持续时间和失败状态，不能反复滚摆、无高度损失地持续倒飞、瞬间翻正或无条件强制执行。不要提升机型性能上限来满足展示。
