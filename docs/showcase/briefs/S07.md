## 真实整合

标准场景每方 1 艘主力舰、1 艘驱逐舰、4 架战斗机，共 4 舰 8 机、六型。型号／日期从已验收正式数据读取。保持历史尺寸与性能；场景初始距离、高度、剩余油弹和任务可安排，以便在可观看的时段自然经历搜索、接敌、炮战、防空、空战与脱离。不得安排命中、定时扣血或将预设轨道当作自主行为。

加载 catalog、固定 tick 世界与 S04/S05/S06 模块；场景只推进世界、消费快照与事件。表现池和摄像机不改变战果。每帧消费事件 outbox，遵守 tick 预算并显示实际播放状态；不以删 tick 掩盖设备跟不上倍速。重开释放旧对象、清空镜头／UI／效果历史，使用世界 generation 处理旧引用。

按表现实际需要复制单位／命令状态；完整 `world.snapshot()` 还包含所有模块和在飞弹丸，主要供回归和诊断，不应每个炮位／效果重复获取。弹迹由 S05 发射／终结事件维护，UI 以合理刷新频率读取命令。表现仍只读，不以省复制为由直接改写世界的可变对象。

基本海面、天空／光照、舰迹和 S05 效果统一到简化美术方向。近景看得到炮塔转向、实际发射、水花／空爆和伤情；不为电影效果改武器数量或命中逻辑。

补齐 T08 尚未接入的简单炮管后坐：按真实 fired 事件驱动炮管表现的短暂后移／复位，可对已验收的模型适配器作必要、局部的表现接口扩展，不能改舰体／炮位布局、模拟炮口和伤害。各实例独立，按仿真时间播放，暂停／重置不留偏移；不增加复杂内部机械。持续伤情的火烟与失能／沉没显示按 S05 phase 读取。

## 观战操作

- 自动电影镜头：全景、舰船／机群跟随、实际交战事件的重点镜头，稳定构图、合理停留与切换冷却。不反复追逐微小事件或穿入舰体／地面；不能因为镜头请求而改变战斗。
- 自由观察、选中单位跟随、人工接管／恢复自动；暂停、慢放、倍速、重开。退出活动区域或被毁单位有清楚的跟随回退。
- 简洁战报与自然结束条件，损失／撤离／库存消耗从真实状态统计。无目标、双方脱离、任务完成和超出展示时长等分别说明；观战结束不凭空摧毁单位。

## 双方指挥信息是正式 UI

遵守 `docs/showcase/command-and-observer-ui.md`。默认画面有双方紧凑指挥卡，能看到指挥官当前主要任务、受令编队和实际执行状态；有明显的“指挥态势”展开入口。时间线展示谁在何时向谁下了什么任务、执行变化及结束／调整原因。选中命令可定位相关部队或目标；终结对象可回看最后相关位置，不留下空引用。

显示实际 `BattleOrder` 与逐成员 execution，支持部分改派和多个并行任务，不把整军压成一句模糊旁白。命令拒绝、取消、替代和失败有可读原因；不显示原始 JSON、tick 编号、内部类名。中文产品文案，仿真分秒和可辨单位／编组名称。电影模式可收起面板，恢复后显示当前状态与近期历史。观众可以看双方，AI 依然只读己方情报。

中文字体需有可用于本地 Web 包的授权并随构建打包，确认标签／时间线无缺字方框；不依赖浏览器外的 macOS 系统字体偶然回退。
