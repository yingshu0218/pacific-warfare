# OPS01 模型接续与第一舰使用验收

由统筹在S04舰载使用态候选通过且有执行名额后接续原OPS01聊天。当前89项机制与421项冻结输入已做阶段独立复核；不重做无变化的整套长录像。普通S08包继续保持已验收版本。

## 必做接续

1. 消费S04发布的实际轮胎接点、收放轮/尾钩/襟翼状态和钩端；彻底替换原型固定4.4米钩后偏移。钩端扫掠应在同一母舰局部坐标判断实际索段与接触高度，不能只比较机体Z位置就宣布挂索；起落架放下与尾钩放下是分开的真实状态。
   首轮原生复核已退回旧F6F尾轮过长/三轮共面问题。S04修正后，停机俯仰与原点离甲板高度必须由新真实接点解出，不能继续假定三轮都在局部Y=-2.30或地面pitch恒0。滑跑抬尾、接地后尾轮落下采用有界连续姿态与实际轮胎圆面支撑，避免接触时跳俯仰/穿甲板；主轮两点与三点支撑分别明确。旧夹具快照不作为新几何的真值。仍不扩展精细悬架动力学。
2. 私有候选stage中使用同一模型版本做完整机制必要回归，再截取≥15fps的离舰、进近→轮胎触舰→挂索→减速、必要复飞/硬触舰短段。前置过程仍逐固定tick执行，只省略不相关巡航的画面记录。不用补帧动画代替真实渲染。
3. 统筹此前看过的3fps总览不作为新尾钩使用态或新硬接触代码的最终视觉证明。修复检视文字与地面画面重叠，保留实时状态/时间可核对，同时正常观察视距能看清飞机与甲板关系。
   现有 AircraftMotion 是升力平面驱动的质点积分，机体轴线暂与速度轴线重合。新真实短轮组不能沿用低头下滑机体硬贴甲板：必须明确下滑航迹角与机体迎角/俯仰的区别，使用模拟拥有、机型资料约束且有界连续的进近构型姿态；不得只在渲染层转飞机遮掩碰撞。沿原力积分组合，健康空战无此构型时保持已验收行为。放轮时仍检查完整旋转桨盘、下放襟翼/机腹的甲板净空，不能仅轮胎不穿透就算合法。接近低头、低翼或错误姿态导致先发生机体接触时沿DM处理，不虚构轮胎先落地。
4. 普通入口和生产航空/指挥模块由后续S14扩展的唯一所有者接入；本阶段发布最小组合hook，避免与BOMB01注册两个aircraft领域执行器。飞行/任务/甲板/DM各自只有一个状态写入者。

## 保留边界

当前仅验证零环境风、CV01埃塞克斯、1/2架F6F完整波次。双机只出动一架时，剩余后甲板飞机会物理阻挡回收；不能在生产命令接口宣称任意局部出动已支持。后续应有连续前移清场调度，或在演示/命令校验中明确该限制。当前先完成实际模型使用闭环，不扩展地勤细节。

舰艇炮战/日方甲板布局/多型混合/陆基机场/轰炸尚待各自范围，分别标记。有限油弹、真实取消/损失/复飞和二次循环的已通过机制不能在接新模型时退化。
