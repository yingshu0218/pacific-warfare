# AA02 两军地面防空与岸防部署

复用 S10 聊天，待 MAP02 发布稳定阵地和支承数据后由统筹明确启动。读取扩展计划、S10 交付、地形契约与当前地面单位模块。最多两个执行聊天，全部重型验证串行；不自行创建子聊天或代理。

## 责任与范围

消费 MAP02 的 `deployment_sites`，沿现有 GroundDeployments / TerrainQueries 注册真实单位，检查占位、支承高度、净空、朝向和可用射界。港口、码头、高地与岸炮阵地分别有合理部署，不把地坪装饰视为炮兵单位，不在模型里自行寻找另一套地面高度。

首次验证使用私有场景与未注册参数；公共 GroundDeployments、自动扫描单位/武器目录、普通 Session 和运行白名单由 S14 批次接入时统一修改。若部署扩展需要改共享代码，先在带 `.gdignore` 的 `candidates/aa02/` 提供候选和明确基线 hash，按显式清单组成私有验证 stage，避免半成品破坏已交付普通包。

美军复用已验收 40 mm M1 / M2A1 与 5 in/51 Mk 8 / Mk 13；日军先选择一款有完整依据的地面防空炮及必要岸防炮配置。先锁定具体炮型、炮架、服役时期和地面安装形式，核对真实照片/图纸，再决定复用已有舰炮的哪些模块。不能把美军 M1 更名、缩放成日军武器，不能直接把舰上炮座无支承地摆到土地上。若现有日军武器无法合理复用，向统筹登记所需独立模型范围，在本任务内按模块顺序完成必要炮架，不扩张为完整陆战兵种。

沿单一探测、火控、弹丸与伤害链，接收统一 BattleOrder。固定炮兵保持阵位，防空/对海职责、搜索/跟踪/射击/待命状态必须真实；视界、射界和地形遮挡限制不能因演示失效。弹药有限、真实损伤失能、暂停与重开清理沿现有规则。相机或展示导演仅安排观看，不伪造炮火或命中。

## 验收与交接

模块与炮架装配→阵地安装→射界/地形遮挡/真实弹着→场景演示。覆盖港口承载面、山地高度、目标从建筑后出现、不可射方位、无弹/受损、改派与重开。炮口火光、曳光、空爆或落水消费实际战斗事件，复用已验收 FX，不引入重复爆炸和音源。

交付具名部署数据、日军型号/资料/近似清单、`docs/showcase/deliveries/AA02.md` 及证据/哈希/清理记录。不得修改 MAP02 布局来绕开安装问题；接口问题交统筹指定一方处理。S14 在扩展场景接入后，S08 执行最终 Chrome 验证；本阶段不重复长时浏览器测试。
