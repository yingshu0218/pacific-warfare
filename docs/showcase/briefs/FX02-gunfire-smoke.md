# FX02 舰炮烟焰、命中烟尘与防空空爆

用户要求在本版看到火炮开火时的炮烟、随风缓慢飘散的烟团、炮弹爆炸与留烟，以及防空炮在空中的开花黑烟。目标是从正常观战视距读出事件的位置和先后过程。

## 画面

- 舰炮从真实炮口先出现短促闪光和有初始方向的烟焰，随后烟团在世界坐标中扩散、受风位移、变薄淡出。主副炮有可辨的规模差别。舰船向前运动时能看到它离开旧炮烟。
- 对舰命中可出现短亮芯、碎火星与较深烟团，对地撞击可带混尘的烟。实际弹体命中的材质和口径决定选用的表现。海面落弹保留已有水柱、泡沫和水雾。普通子弹打击、单纯到寿或失去目标应按各自既有事件处理。
- 高炮在真实空爆点开花。短闪之后出现轮廓不规则、有深浅的黑灰烟团，随后膨胀、向下风侧移动并淡出。密集空爆可以在天空中短时共存，仍能辨认附近飞机。保留小口径自毁与高炮空爆的外观差异。
- 沿用现有云海的视觉风向和仿真时钟。视角移动、暂停、变速、重开和迟到的事件批次都应表现正确。模型、火控、弹药、探测和伤害继续使用当前机制。

## 所有权与验收

FX02 独占此次表现层修改，优先使用 `scripts/presentation/effects/`、`scripts/bombing/effects.gd` 和必要的本任务测试。复用现有池、材质、简化几何和本地资源。保留曳光终止、水花、飞机受损烟迹与有限实渲染实例，重复消费同一事件应幂等。

提交实际事件的连续画面和证据，分别核对炮口首烟与飘散、炮弹接触后的爆炸与留烟、高炮开花与淡出。用固定观察机位或可追踪的世界坐标区分真实漂移和镜头移动。记录池峰值、暂停／清理和效果开关的模拟一致性。受控事件样张标注来源，另从正常游戏入口记录实战表现。
