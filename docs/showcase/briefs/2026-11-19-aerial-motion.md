# 战斗机的立体飞行与观战取景

玩家希望在普通自主空战中清楚看到更大的空间位移和更多不同的机动。主聊天保存了已发布运行输入与旧包，负责同种子回放、原生画面、普通 Web 包和 Ego Lite 验收。两项工作共用正常港湾与原有自主空战入口。Godot 验证经 `tools/verify.py` 串行运行。

## AIR02 自主飞行

在游戏既有的虚拟飞行控制与任务系统中，扩大受控的三维运动。两种战斗机均应有可辨的横向反转、带高度变化的转弯、沿机身轴线的滚转，以及机身与整条航迹一起偏移的斜向滚转弧，从当前游戏任务、飞机状态与可用动作中选择，在同一飞行积分里进入、过渡和收住。以观战时的动作区别和空间范围为目标，沿用现有机型限制与安全恢复。检查普通港湾的战斗机交战和原有自主空战段落，同时保留轰炸、双机队形、受损或退出的正常路径。收集动作身份、起止时间、实际航迹、姿态与退出原因。交付记录在 `docs/deliveries/AIR02.md`。

## CAM03 观众看空战

让玩家在普通 Showcase 界面主动选择持续观察战斗机交战，能看清坡度、升降和反转时的飞行轨迹。有条件时兼顾对手机位与环境参照，动作可读时尽量留住主体。相机只读现有模拟与姿态数据，标注当前可以核实的动作。暂停、手动跟随、自由观察、现有空中交战与重开应可用。优先复用现有观战控件。交付记录在 `docs/deliveries/CAM03.md`。

## 联合验收

在可重放的相同场景中对比每架仍在飞行的战斗机，区分自主交战、单项训练、非战斗飞行与失控下坠。实际航迹、姿态变化、镜头连续画面、功能回归和浏览器帧时间分别记录。对战局有影响的初态变更需单独说明。拍摄只改变观察方式。
