# AV02 D4Y2 舰载俯冲轰炸机模型

由统筹在SB2C准入/飞机接口稳定后安排独立聊天，目标 **D4Y2 彗星一二型**。先锁定具体子型与公开参考；现有 `docs/references/bombers/d4y/` 是D4Y3星形发动机素材，不可用于液冷机头整体重建。资料包须实际看完整侧面、展开翼高位/俯视、斜前后与必要起落架/挂弹/后射手安装图，并记录异型限制。

遵守已认可简化：机身、翼尾、长座舱盖、武器与挂载的外观形状/比例还原，表面保持连续，少量罩框；轮子/简单支杆、尾钩和必要控制面即可，不做内部发动机、铆钉、精密轮舱。不是将现有SB2C缩窄后换涂装。

提供独立纯模型、米制尺寸/服役子型信息、统一原点/轴、propeller、gear/hook、控制面、炸弹挂点/弹舱与后座枪位、必要部位损伤分组。实际不存在的折翼或武器不能为了接口统一而虚构；未知功能明确标记。模型不自行飞行、投弹或修改健康。

模型目录建议 `aircraft/d4y2/`，对应独立定义/性能资料/碰撞建议与检查归本聊天。共享builder若需要新增能力先登记，优先自身helper，避免改变F6F/A6M/SB2C。性能值明确资料/近似；用BOMB01攻击任务和OPS01航空作业，不复制战斗机狗斗。

先模块及整机连接/活动范围、同参考机位原生检视，再交使用场景；浏览器留最终集成。固定4.7.2/Compatibility，经verify共享锁、超时清理，不创建下级聊天。交付 `docs/showcase/deliveries/AV02.md`、证据/参考卡/接口/来源/哈希，统筹验收后才正式加入S14和轰炸/回收流程。
