## 场景设计

制作原创的“群岛港湾”测试地图，参考其开阔水域、岛链、水道、海岸聚落和港湾的组织方式。参考入口：

- [World of Warships 官方地图目录](https://wiki.worldofwarships.com/Ship%3AMaps)：Islands、Seychelles、Sleeping Giant 等布局对照。
- [官方 Update 12.3／Seychelles](https://wiki.worldofwarships.com/Ship%3AUpdate_12.3)：山岛、近岸水色与小岛群的视觉参考。
- [官方 0.7.1 更新](https://worldofwarships.com/en/content/update-notes-main/release-notes-071/)：港口城镇参考入口。

请实际查看少量有用的官方地图图像/截图并记录用途；上述文字检索不等于已完成视觉参考。自行实现地形和建筑，不提取或搬用该游戏资产。保留本项目米制装备比例与历史性能。

建议总活动范围约 24×24 km，主要测试区域约 12×12 km；这是可调整的场景初值，依据舰艇转弯与交战距离验证，不以压缩舰艇尺度适配地图。提供一张俯视布局图和坐标表，标明北向、比例、初始兵力、通道、港口、阵地和退出区域。

| 区域 | 必须具有的内容 | 用于测试 |
| --- | --- | --- |
| 中央开阔海域 | 足够展开四舰炮战、八机空间机动的连续水域 | 主炮齐射、舰队防空、立体空战、远近镜头 |
| 主岛与外侧岛链 | 至少一座有高差的主岛，数座轮廓不同的小岛/岬角；沙滩、岩岸与山坡关系清楚 | 遮挡、绕岛、狭水道、低空安全与弹着 |
| 港湾 | 可进入的水面、两三段简化码头/防波堤、仓库及少量港机轮廓 | 近岸航行、港口镜头、岸防交战 |
| 小镇 | 沿岸道路、少量有组织的屋顶/房屋组团，与港区相连 | 比例感、地面/建筑命中与低空视角 |
| 岸防用地 | 面向海面的岸炮台地、可布置防空炮的平整阵地，包含高低不同位置 | S10 实体部署、炮口高度、射界和遮挡 |

画面保持简化：清楚的地形轮廓、少量材质、屋顶块面、有限树丛即可。建筑不做内部结构或逐栋复杂破坏。不扩展天气、潮汐、流体、行人、港务或机场作业。

## 海面和统一地形

当前 `ocean.gdshader` 仅两组高频 UV 正弦相乘调色，海面为 120 km 平面。请替换明显规则的交叉纹理，做平缓、方向一致且尺度合理的波纹/法线，配合稳定天空/地平线、深水与近岸色差、克制反光和简化岸线泡沫。避免闪烁、摩尔纹和一眼可见的平铺格纹。暂停和重开使用模拟时间，不能改变战斗随机数或模拟。

地图必须是一份可复用数据，渲染、海陆判别、地面高度、遮挡、弹道首次命中、小地图与导航从同一地形来源派生。实现可采用低分辨率高度场或简化多边形等方案，先选择适合本项目的最小方案并解释。

- 飞机低空查询和实体地面接触不得一直假定 `y=0`。给 S04 发布纯数据/只读查询接口，空地图默认海平面，重开后接口仍有效。
- 炮弹、飞机坠落必须在实际坡面/建筑高度接触；陆地尘土与海面水花按首先命中的表面区分。不能只在画面放一座岛，却仍让炮弹/飞机穿过去。
- 岛屿遮挡探测和实际火线；允许合乎弹道的越山抛射，不把“目标看不见”和“所有曲射必被挡住”混为一谈。
- 舰艇导航使用按舰体尺寸和安全边距膨胀的航行边界；允许保守裕度，但不得用一个巨大包围盒封死可见水道。无路时停船/报告原因，不能穿岛或瞬移。
- 相机和自动镜头需要地形避让；地图、镇区和港口要能在正常 UI 定位查看。新增点位按钮仅为观战定位，不引入玩家指挥。
- 地形数据冻结于一次场次，重开不重复生成无上限网格/节点；相机、画质、显隐不能影响模拟结果。
- 现有 `ShipNavigation` 是小规模障碍可视图，不能直接给每个地形格子生成障碍节点；保留数量受控的岸线/通航表示。弹丸和视线查询也应先筛选候选区域，避免每发炮弹每步遍历整张地图三角形。性能由实际数据核对。

## 陆基安装接口

提供阵地点位清单，至少覆盖：港口入口岸炮区、港区防空区、岛上高地防空区。每个点包含稳定 id、世界位置/朝向、地表高度、可用半径、适配角色、建议阵营与必要的射界限制；允许由场景数据选择单位、数量、阵营，不用用户手工改生成代码。

验证阵地落在可承载陆地且表面足够平整，安装点高于/接于地表，不能悬空或沉到山体内。地形或炮台基座不得把自己的炮口完全包在遮挡体里。S09 可提供清楚的阵地几何，但不得把空阵地标为已参战单位；S10 独立补真实兵器。
