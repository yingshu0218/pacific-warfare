# S14：全单位 Showcase 与空战演示场景

2026-11-11 用户要求：“这个 showcase 的场景搭建，有必要就单独建一个 sol6.1 max 的对话，我要求目前已经搭建的单位都要出场，特别是空战单位，包含的编队和机动性的演示。”本任务是实际场景搭建与集成，不只交规划。独立 GPT-6.1 Sol / max 聊天执行，统筹审查后交 S08 做最终普通启动与 Chrome 长测。

## 目标和当前资产

沿用群岛、小镇、港口、岸防阵地和最新云海，形成一个启动后就能看清现有单位与核心行为的展示入口。保持历史尺寸、简化画面和真实模拟。六型旧 Showcase 只是起点，不能因旧清单限制而遗漏已经建出的资产。

首先实际扫描模型、独立子工程与交付记录，输出 `docs/showcase/all-units-inventory.md`，逐项记录纯模型路径、型号/日期、外观准入、模拟能力、出场位置/段落、观看入口与限制。统筹已找到的最低清单如下：

- 军舰：大和 1944-04、衣阿华 BB-61 1944-12-28、弗莱彻 DD-445 1942-07-18、雪风 1942-06-04；使用已验收模型与全部固定主副炮，防空保持历史/游戏两份配置。
- 飞机：F6F-5、A6M5a，以及 `aircraft/sb2c4/sb2c4.tscn` 的 SB2C-4。SB2C 在第三轮复核后已有源码修订，但未实际复验，不能误写成“未修改”或“已通过”。当前模型卡为 `docs/deliveries/sb2c4-delivery.md`，遗留审核点为 `sb2c4-review-round3-supervisor.md`。必要模型复验/修复由原模型聊天接续，统筹安排；S14 不自行覆盖其模型文件。
- 地面战斗单位：5-inch/51 Mk8 Mod0＋Mk13 Mod4 岸炮，40mm M1＋M2A1 防空炮，已有三座实例及真实指挥/库存/伤害链。
- 独立武器：实际盘点日军 7.7mm Vickers、25mm 单/双联及其炮架，美军 M2HB、M1917A1、40mm 四联，以及舰上复用炮塔。舰上已经出场的模块无需重复伪装成整舰单位；未入舰的完整独立兵器可在港口检视区按已有正确支架陈列，明确“兵器检视”，不能假称已接入战斗，也不能随意加装到历史军舰上。父子模块不重复计为不同兵器。
- 旧机场是场景设施，不是额外机型；评估可复用设施，不要求搬入整个旧岛或在本轮完成机场/航母起降。仅有参考资料的 G4M、B-25、D4Y、TBM、B6N 等不属于已搭建单位，不借此扩展为新造型任务。

“出场”必须有可辨认的实际画面和可选的观看入口；只加载、藏在地图远端或列表里有名字不算。至少四型舰、三型机、两型地面炮组都在同一主地图可见。SB2C 用独立性能/角色与适配，允许先展示编队航行与护航；不能套用 F6F 参数或标成完整俯冲投弹系统。若接入所需接口有真实缺口，说明具体文件和依赖交统筹安排，不默默删去该机。

## 场景与演示安排

先交一页简明场景安排后直接实施。默认进入引导观战，尽早展示空中单位；观众可随时选择段落、单位跟随或自由观察。建议顺序可按实测调整：

1. 群岛/港口与双方舰队短开场，每型舰有足够可读的侧前/侧面镜头，避免长时间全景看不到模型。
2. 双机编队巡航和协调转弯：长僚关系、合理间隔、独立飞行清楚可见；转弯镜头保留海天参照，能看出先滚转建立倾斜，再拉杆改变航迹。
3. 四机编队：两个双机分队，展示展开、攻击/支援分工、脱离与重组。四机只排成一行飞过不算完成。
4. 战斗机机动：爬升、俯冲、明显大角度滚转、滚转换向和条件允许的半滚倒转。姿态/航迹连续、速度/载荷/高度有机型约束，不出现瞬变、左右摇摆或反复抬低头。完整轴向滚转若当前控制器没有实现，交原 S04 行为聊天补充真实控制路径，不能靠模型旋转动画替代，也不能把侧倾 30 度称为翻滚。
5. SB2C 与护航战斗机同框，显示受护航对象和保护关系；战斗机可以脱离接敌并归队，SB2C 不参加战斗机式追逐。未实现投弹/后射手火控等能力如实登记。
6. 舰炮、防空和岸防交战：兼顾侧舷齐射、水柱、黑烟与曳光，镜头可跟到真实事件；自然伤损发生时可跟拍 DM01，不能按时间表直接施加伤害。继续提供可独立选择的真实命中受控伤损演示，并与默认自然战斗分开标识。
7. 导览结束后继续自然观战；各演示段可重看，不需要观众干等随机 AI 恰好做出某动作。

演示可选择初始态、真实高层任务、相机和段落条件。训练/受控段落应明确标识并通过统一命令校验/任务接口执行，敌方AI仍只读己方情报。不得由镜头脚本直接改位置/姿态、把飞机硬绑到编队点、修改历史性能以制造动作，或使用强制命中/定时伤害。选择独立段落可重置该演示，并按正常 generation 清理状态；自动连续导览不得隐蔽瞬移存活单位。

镜头应让动作本身可读：展示滚转时以稳定地平线的外部跟随为主，避免相机随飞机一起滚转把动作抵消；编队镜头至少同时看到两架或四架，而非一直特写一架。留足完成一个动作的时间，避免频繁切镜。

- 完整清单与实际场景一一对应，已有模型不遗漏；兵器模块与完整单位不虚报，已接入和只检视的能力区分明确。
- 正常入口能选择并看清每型单位；双机、四机、立体机动和护航分别有连续画面、真实状态/任务与段落入口。不能只提交几张姿态截图。
- 使用固定种子检查引导流程可达、选段/暂停/倍率/重开有效，导览与相机不改变同输入战果；新机型与数据装配有必要的接口/基本运动检查，保留现有 DM/FX 的池化回收。
- 模型/装配先完成，原生连续证据收敛后再做一次有界 Chrome 基本加载与选择操作。完整 1280×720 性能、10分钟/三次重开和普通启动路径交 S08；不得用原生帧率当作 Chrome 结果。
- 引擎固定 4.7.2 / Compatibility；全部 Godot/导出/编码/浏览器通过 `tools/verify.py` 同一锁，有超时和清理，后台优先，仅清理本轮创建的窗口/进程/服务。证据与运行源码哈希对应。
