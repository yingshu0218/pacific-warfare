# 交战节奏与单位作用

2026-11-12，用户补充：作为游戏，需要合理的交战时长，不同单位有不同抗打击能力、输出能力与战场作用。本要求纳入RX01修复；它不要求单位拥有统一存活时间，也不允许按时间表制造损失。

## 节奏目标

完整海空战仍沿总体规划的20–40分钟可持续观战目标；单项Showcase验证片段分别标明用途，不通过延长空场或冻结单位冒充持续交战。常规舰炮对抗应有数分钟的接敌、射击、受损应对与进退过程。集中命中后的失能可以很快，尤其轻型单位遭重型武器、飞机遭有效机炮射击时；不设保底存活时间。击沉动画只表现真实失去浮力后的过程，不能用慢放沉没来补足战斗时长。

区分三种时间：搜索/接近到有效攻击机会，首次有效命中到失去主要作战能力，严重损伤到沉没/坠落。不能把某一轮齐射、失去操舵、退出任务或进入沉没过程都称为已经被击沉。

## 模块化舰船损伤

用户进一步明确：舰体本身未被击破时不应轻易沉没，上层建筑损伤更多表现为模块缺失与效率下降。

- 舰体结构/浮力单列。真实水线附近或水下有效破口产生进水，进水和浮力储备决定是否沉没；上层建筑、火控和武器失能不会直接制造进水。
- 炮塔/炮位按现有安装模块分别受损。部分损坏影响该炮位的装填、转动等能力，彻底失效才停用；不改变炮弹的固有初速与弹重，也不让一座炮塔失能关闭全舰其余火炮。
- 火控、动力、操舵分别保存健康/效率。火控下降影响射击解算与精度，动力下降影响可用推力，操舵下降影响转向；避免用同一个control=0直接关闭整舰所有功能。
- 作战结构耗尽、主要能力丧失等可导致任务失能和撤离/救生状态，但舰体仍可漂浮。失能、正在沉没与实际损失分别显示。
- 严重火灾或爆炸若要影响下层模块，必须有明确的毁伤传递条件和可检查事件，不按时间自动触发沉没。

本轮先完成舰体浮力与已有炮位/动力/操舵/火控的基本模块关系。雷达/通信、独立供电网络、逐舱灌水、损管班组和复杂连锁传播为后续接口，不把它们扩大为当前修复的前置。航母航空作业、船舶航行和武器射击消费同一份实际模块状态；新增字段须有明确默认值，避免旧单位或场景换配置就改变规则。

## 单位作用与相对能力

| 单位 | 主要作用 | 抗打击与输出的设计重点 |
| --- | --- | --- |
| 战列舰 | 持续对海重火力、吸引火力并提供防空支援 | 装甲和结构保护主体；上层建筑、动力、火控与炮塔可分别受损；主炮单轮威力强但受装填、射界和命中率约束 |
| 驱逐舰 | 机动护航、反轻舰、防空与其他已实现武器任务 | 抗重炮能力明显较低，依靠航速、轮廓与行动规避；小口径炮射速高不等于对重装甲高杀伤。未完成的鱼雷系统不计现有输出 |
| 航母 | 航空兵投送、回收与持续补给 | 主要输出来自可用飞机；飞行甲板/航空作业失能与舰体沉没分别结算，自卫炮不承担战列舰炮战职责 |
| 战斗机 | 拦截、护航、争夺攻击窗口 | 命中后可迅速失能；生存主要来自速度、机动、协同与脱离。保留各机型性能差异，不以阵营对称为目标 |
| 舰载攻击机 | 把有限载荷送入俯冲/投放窗口 | 有效投放窗口、接近风险及拉起脱离决定任务价值，不追逐战斗机；任务中止与飞机损失分别统计 |
| 中大型轰炸机 | 编队突防、较大载荷投送 | 机体规模、结构和已有部位损伤有差异；机动较受限。不能把模型上的防御枪位计成尚未完成的防御火力 |
| 防空炮/岸炮 | 限制特定空域/水道，保护要地 | 输出受射界、反应、射速、引信、弹药和目标条件约束；火力网由真实多炮位射击组成，阵地本体保护较弱 |

## 校准与验收

先记录同一初始场景/种子的修复前后数据：目标类型与交战距离、每轮炮管数、实耗弹药、有效命中数/部位、装甲/传递后伤害、火灾进水、首次失能和沉没时间、撤退与任务变化。输出同时看每轮威力、持续射速及实际有效伤害，耐久同时看结构、防护、关键功能与进水，不能只比一个HP数。

合理的HP/部位耐久、毁伤传递等游戏近似可以校准，但需说明相对尺度与依据；不靠统一抬高HP、削平所有武器或给敌人降输出凑时长。历史尺寸、炮管编制、弹重/初速、装填与射速等已有依据的性能保持；发现其实现有误则修复并记录。双方沿同一规则，保留历史装备的不对称。

至少比较重舰同级对抗、重炮对轻舰、轻炮对重舰及空战/拦截的相对结果。机制夹具用于分离命中部位和防护原因，普通AI场景用于验证整体节奏；两者分别记录，不用静止无敌靶或导演命令补效果。参数校准结果仍须通过正常Chrome中的弹道、防空、受损反馈和真实任务UI检查。
