新增 `scripts/simulation/collision/combat_presence.gd` 统一物理存在性。`aircraft_motion.exited` 或 `ship_motion.exited` 为 true 的单位退出碰撞、视线/空爆遮挡、实际损伤目标和持续损伤更新；650结算也拒绝本 tick 已排队、退出后才消费的 hit/表面接触。仅 active=false 的失能舰、沉没/坠落过程和未回收残骸继续挡弹，失能舰仍承受允许的后续伤害。发射者离场保留原在飞弹丸，禁止离场后新发射；机械定时引信不因目标离场改变。己方最后接触按原观测时刻自然变旧、过期，未据敌方退出标记泄漏情报。真实 S04/S06 撤退与 reset 均通过，不改航空、舰队或 S07 文件。
