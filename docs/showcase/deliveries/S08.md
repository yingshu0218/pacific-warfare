# S08 汇总交付：普通入口、Chrome 长测与性能

2026-11-11。当前汇总范围为 S14 冻结的 **19 个模拟单位、9 种型号、5 个独立兵器展项与 16 个可选段落**。本记录接续 S14 已通过的专项验收，不重新宣布航母、轰炸、港口扩展或最终 20–30 舰／100 机规模完成。11 月 10 日阶段记录完整保存在 [S08-stage-20261110.md](S08-stage-20261110.md)，其中的旧包、旧浏览器记录与本轮分开。

## 启动

在仓库根执行，固定使用 `/Applications/Godot.app` 内的 `4.7.2.stable.official.ed1daf0bf` 和匹配模板：

```sh
cd /Users/infinity/Desktop/Dev/game-pacific
python3 tools/run_first_playable.py native
```

浏览器运行：

```sh
python3 tools/run_first_playable.py web --build
```

等待终端显示 `Open Chrome` 后，用 Chrome 打开 [本地 Showcase](http://127.0.0.1:8765/index.html)。`--build` 会从本轮准入清单重建，构建存于忽略目录 `build/first-playable/`；普通 URL 不加载测量脚本、测试夹具或内部诊断控件。默认服务上限一小时，用户可用 `--seconds` 调整；在启动终端按 **Ctrl-C** 停止本次会话。

- 顶部段落菜单选择双机、四机、机动、护航、火力或训练；这会重开该演示。独立兵器菜单只改变检视，不重置模拟。
- 点击 **启用声音**。底部 **暂停／继续**，倍率菜单提供 0.5／1／2／4 倍；暂停会停止模拟与当前声音，启用状态保持。
- 选择单位后点击 **跟随**。跟随时右拖环绕单位；自动电影时右拖转自由观察并可连续拖动；按 **C** 恢复自动电影。
- **恢复信息 → 指挥态势** 查看双方真实命令与执行时间线；选择指令后可定位受令编组或任务目标。**结束** 显示战报，**R** 或 **重开** 重新运行。

兼容入口：`python3 tools/run_first_playable.py native --scene open-sea`、`--scene harbor`、`--scene yamato`，以及 `--scene first`。根 `project.godot` 默认仍为 `res://scenes/main.tscn` 的大和检视。默认 native 和 Web 则明确进入 `res://showcase/all_units.tscn`。

## 实现边界与运行包

`tools/showcase_runtime.json` 以 S14 冻结清单为准入基线，只列出 396 个当前运行资源。隔离构建另外生成 3 个配置文件，复制时尊重 `.gdignore`，展开 Iowa 仓库内软链接，包含 S13 原创云海 PNG、字体许可证与全部已准入的嵌套单位／武器／弹药／场景数据。不会扫描新增目录自动纳入模型。CV01 航母、MAP02 扩展、AU01 候选及母带、参考照片、PDF、AI 图、研究／备份／测试工具都没有进入普通包。

固定 1280×720 实际渲染缓冲区；普通服务器仅提供 localhost 静态资源，没有浏览器进程扫描。原有声音 STREAM、声源预算、效果上限、兵器编制、射速、库存、弹道、损伤、AI 与固定 tick 均保留。

Web 的只读采样由验收端在页面启动前显式注入 `window.S08` 才启用；普通页面中 `S08`／`S14` 都不存在。观测记录真实 tick、积欠、事件、效果、残片、CPU 分段和实际 rAF，不推进世界、不派发命令、不制造战损。专用测试脚本不进入 PCK。

## 定位与优化

原生模块计时和 Chrome 实测发现：三个任务执行器为判断单位领域，每 tick 经 `owned_order_unit_ids()` 重建完整 `UnitDefinition`。增加 `DefinitionCatalog.unit_domain()` 直接读取同一份不可变定义的 `domain` 字段，只替换该领域判断。没有改动 `orders_snapshot()` 的完整历史、排序或 UI 的执行记录。

固定输入对照覆盖 guided 120 秒、four 160 秒、美军完整轴向滚转 18 秒、fire 80 秒。每 600 tick 的世界状态、RNG 状态、完整事件流 hash、计数及最终报告在优化前后完全一致。领域归属读取的总 CPU 从 **8.273／11.420／1.572／6.431 秒** 降为 **0.321／0.479／0.053／0.228 秒**；详见 [replay_comparison.json](../evidence/S08/final-20261111/replay_comparison.json)。

Chrome 前后使用同一种子、默认导览、同一质量／相机规则和 8 秒热身。帧调度造成实际镜头取样时刻不同，逐秒位置和标签保存在原始数据中，不能称逐帧完全同轨迹。

最早 `baseline/run.json` 尚未内嵌完整构建清单，只保留实际入口、环境和原始帧／状态；不把它的整包来源精度称为与最终包相同。优化后的基准与完整长测均绑定最终普通包清单，固定输入的模拟前后等价另有完整事件／状态对照。

| 倍率／采样墙钟 | 优化前 p95 | 优化后 p95 | 实际推进倍率 前→后 | 结束积欠 前→后 |
| --- | ---: | ---: | ---: | ---: |
| 1×／30 s | 23.8 ms | 21.1 ms | 0.999→0.999 | 0.0115→约 0 s |
| 2×／10 s | 38.6 ms | 24.335 ms | 1.994→1.991 | 0.0040→0.0034 s |

**4 倍仍未达到稳定 30 FPS。** 优化解决了这个样本的显著模拟积欠，不能把实际推进接近 4 倍等同于画面达标。1 倍和 2 倍的这一段 p95 达到目标，最终长时结果另列。全部慢帧、热身和 UI 操作保留，未以最好一秒替代持续样本。

## 最终实际 Chrome 验收

设备为 **Apple M5／16 GiB、macOS 26.6.2，Chrome 157.0.8103.39 arm64**，ANGLE Metal Apple M5，DPR 1、CSS／实际缓冲区均为 **1280×720**。使用独立可见 Chrome、后台摆位及禁用后台节流参数；没有启动 Safari，也没有以 headless 或瞬时 FPS 代替实测。页面采集帧全部 `visible` 且 `focused`。

最终实际 Chrome 运行 **2026-11-10T22:00:02.884Z → 2026-11-10T22:11:31.529Z**，36 项功能检查通过，无页面异常、Godot／WebGL 错误或重新加载。包括开声后暂停／恢复、真实双方指挥时间线选行及两种定位、兵器检视不重置、完整轴向滚转入口、SB2C 单位跟随、follow 连续环绕、auto 首次右拖接管后继续拖动及 C 恢复、慢放／2倍／4倍、结束战报。

自然 fire 场景累计 **615.056 墙钟秒／615.000 仿真秒**，不是等待静止页面。614 个自然区间的状态样本均未暂停、未结束，活动单位 11–19，移动单位 7–16。真实事件包含炮击、空爆、落水、断件与解体，未注入损伤。本轮自然局不用于宣称覆盖全部受控损伤类型；全模型／十项训练／四机与护航完整循环和受控损伤的专项结论承接 [S14 独立复核](../acceptance/S14-review.md)。

**四次实际 KeyR**：首个在自然生成的存活残片存在时执行，再于长时中段两次，最后战报后一次。三次中段重开快照与最终快照均为 **19 模型、0 残片、0 活动／可见 FX**；384 个已分配槽位保留复用，未逐次新建。后两代相同25–40秒区间节点数回到相同的 4,866／4,881 档位，完整范围见逐代数据。声音启用状态在暂停与重开后保留。

| 最终运行区间 | 有效帧／墙钟 | p50／p95／p99 | >33.3 ms | 实际推进／结束积欠 |
| --- | --- | --- | --- | --- |
| 自然 1×累计（含真实镜头／截图／重开附近的帧） | 57,978 帧／615.056 s | 8.9／20.3／26.7 ms | 0.597% | 累计 0.9999×；各段不足一个 tick |

自然1×的最大帧时 **93.8 ms**，>50 ms 为 0.107%；没有删去长帧。8秒热身另存。UI观测每0.1秒刷新，推进倍率以真实仿真端点／墙钟计算；帧分布使用原始 rAF。汇总用明确的开始／结束时间过滤区间，避免把暂停后的 UI 操作误算作暂停音频。

负载峰值：19 单位、167 炮位、259 个真实弹丸、2,819 次绘制调用、4,901 节点、3 个存活残片。FX 384 槽位曾饱和，`dropped` 累计字段单代峰 **10,896**，其中 **10,439** 次改用低优先级或旧烟段槽位，该代差值 **457** 次未能分配新视觉实例；另一代未分配峰值为 **461** 次。这是既有有界视觉池的压力记录，不是模拟弹丸／伤害丢失；本轮未更改其容量与优先规则，也不宣称零视觉舍弃。4×画面性能与高负载视觉密度是保留限制。

内存各口径分别记录：

- WASM 保留容量全程 **173,670,400 B（165.625 MiB）**；JS used heap **32.2–84.5 MiB**，有 GC 波动。
- 本隔离 CDP 会话中占用最高的 Renderer **PID 83362**，物理占用 **396.3–574.4 MiB**；浏览器主进程 **71.9–77.0 MiB**；GPU进程 **385.6–501.5 MiB**。各 PID 的 RSS／物理占用原始值独立保存，不相加冒充页面总内存，不包含用户已有浏览器。
- 音频使用当前免费原创程序合成，最多8个瞬时＋4个引擎声源，native AudioBufferSource 创建数全程 **0**。开启声音的真实输出峰值 0.295135，暂停3.041秒时 tick 固定，去掉300ms边界后的输出 RMS **0**。真实输出旁路录音 [actual-output.webm](../evidence/S08/final-20261111/chrome/actual-output.webm) 经离线解码通过：7.92秒、48kHz双声道Opus，峰值 -27.09 dBFS、RMS -57.62 dBFS。这段是远距导览的较低音量，不代表所有视距听感；未把源文件当播放证明，也不称历史装备实录。

## 版本、失败记录与清理

普通 PCK 的 SHA256 为 `edcbad51ca5ae54126d5cf6565bdd5ff1c1de117a3de78601cb609e4e7f5a2bc`，16,747,256 B。PCK 解析审计校验 **444 条载荷、174 条 remap**、九型号、字体和 PNG、实际项目入口，载荷 MD5 与 manifest 文件 SHA256 全部吻合。详见 [pack_audit.json](../evidence/S08/final-20261111/pack_audit.json)。源码对 S14 的变化只有领域标量读取与默认关闭的观测入口；完整列表、模板和产物 hash 在 `build_manifest.json` 和本轮证据索引。

确实运行过普通用户命令 `python3 tools/run_first_playable.py web --build`，随后请求默认 HTML/PCK 并停止服务；另以没有任何注入的 Chrome 页确认实际 1280×720、无测量全局变量和无脚本错误。原生 all、open-sea、harbor、yamato 四入口均用有上限的真实启动命令通过并退出。证据分别为 [user_command_http.json](../evidence/S08/final-20261111/user_command_http.json)、[plain/run.json](../evidence/S08/final-20261111/plain/run.json)、[native_launch.json](../evidence/S08/final-20261111/native_launch.json)。

失败记录保留：首次普通预览的 5 秒服务窗不足以让独立探针赶上，后用同一次受控命令与 HTTP 探针成功验证；一次优化后 Chrome 排队等待 OPS01 时互斥锁超时，没有启动第二个渲染负载。`attempt-follow-mode` 的失败是脚本错误要求跟随右拖脱离目标；实际两段角度均改变，产品语义应保持跟随。`attempt-menu-timing` 是连续点击时使用未刷新的可见布局，最终脚本等待点击后的新 UI 快照，完整保留时间线选择与两种定位断言。临时错误地新增的 follow→free 分支已撤回，当前相机源码与 S14 一致；原生与最终 Chrome 分别验证 follow 环绕和 auto 接管。

所有引擎、导出、原生窗口与实际 Chrome 运行均经 `tools/verify.py` 同一排他锁；记录 PID／进程组、超时、退出与 finally 清理。内存采样只使用本次隔离 Chrome 会话的 CDP 进程 PID，不读取无关浏览器。只关闭本轮隔离 profile／Chrome／HTTP，保留用户原有窗口。完整报告和退出证据见本轮 `cleanup_audit.json`；没有对外发布。
