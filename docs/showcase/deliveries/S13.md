# S13 云层与海面交付

2026-11-11 用户反馈修订：已修复海面独立亮雾带导致岛屿像被分割的问题。当前实现、同镜头对照及新 Chrome 验证见 [S13 雾带修正](S13-fog-fix.md)。下文及原 S13 证据保留为首次交付的历史记录，不将旧 hash 或帧时冒充修订后结果。

2026-11-10 制作，2026-11-11 归档（Asia/Shanghai）。实现、自验收及本轮 Chrome 短测完成。统筹已复核 20/20 冻结运行源码、实际截图、连续拼图及 Chrome 原始数据；总计划与验收索引由统筹维护。本交付不代表 S08 十分钟、最终规模或整个 Showcase 通过。

## 交付内容与边界

- 新增 [CloudSeaEnvironment](../../../scripts/presentation/environment/cloud_sea_environment.gd)、[天空 shader](../../../scripts/presentation/environment/daylight_sky.gdshader)，统一日光、海天色和风向。世界方向上的大块疏云、微弱短薄云缓慢移动；垂直视差平缓限制，避免高空出现云片交线。没有屏幕贴图、体积步进或天气模拟。
- 改进 [Showcase 海面 shader](../../../scripts/presentation/ocean.gdshader)：原创多尺度坡度纹理、风向相关运动、克制反光、mipmap/屏幕导数与距离退细节。远裁面前融入统一雾色，低角度增加平顺过渡，去掉旧高空深色横带。
- [first_playable.gd](../../../scripts/game/first_playable.gd) 仅替换环境装配、同步绝对模拟时间及相机位置；相同参数不重复写材质。暂停冻结、倍率随模拟钟、重开归零并复用资源。
- 两张 512×512 纹理由 Godot FastNoiseLite 和周期差分原创烘焙。[生成脚本、参数与来源说明](../../../scripts/presentation/environment/README.md)。没有购买、上传或使用生成图作为运行证据。

严格 y=0 水面，无波高位移，因此舰体水线、原尾迹及水花不发生逐浪脱离。地图地形/布局、shore shader、模拟、单位/兵器、UI、根大和入口、旧 assets/ocean.gdshader 和开阔海数据未修改。S04/S09 既有证据未覆盖。实施前确认仓库没有 Git，局部恢复副本在忽略目录 .local/s13-before/。

**性能来自 chrome-attempt2，最终控制来自 chrome/run.json。前者整轮因菜单输入失败而失败，不能标作整轮通过。** 六个性能窗口已完整采集，共 61 秒；最终补测没有重复性能窗口。两包生产运行源码与资源完全相同，仅验证 probe 增加菜单几何与无损资源 ID 字符串。完整构建及差异见 [build_manifest.json](../evidence/S13/build_manifest.json)；当前工作区 AU01 后续更新了一个不被 Showcase 消费的离线音频 recipe，已在源码记录中单列。

## 失败记录、限制与清理

原生首轮沙箱图形启动 abort；授权图形目录访问后通过。一次 Environment 枚举名错误被包装器判失败并修正。初稿长薄云已减弱、截短；近海规则相位波纹改为无缝坡度纹理，后续以最终实拍收敛。

Chrome 历史完整保留：

1. [attempt1](../evidence/S13/chrome-attempt1/run.json)：旧跟随相机覆盖了验证机位，暂停后相机仍收敛，整帧像素检查失败；高空标签也不能作为有效高空成绩。修正 probe 的 free/followed_id、focus/yaw/pitch/_snap。
2. [attempt2](../evidence/S13/chrome-attempt2/run.json)：暂停时间/像素、六个性能窗口通过，但 End/Enter 没选中 4×，整轮失败。改成读取真实 PopupMenu 几何后鼠标点击，未改产品 UI。
3. [attempt3](../evidence/S13/chrome-attempt3/run.json)：刷新导出因 AU01 持共享锁超时，串联检查未拦住旧夹具启动，读取缺失菜单字段失败。随后严格先确认导出成功，再启动最终补测。另一次等待锁超时未启动浏览器。锁失败不是源码/引擎错误。

每轮都由 finally/包装器清理。[cleanup.json](../evidence/S13/cleanup.json)核对所有 S13 实际进程组均 absent、ps 无匹配；四个真正启动的 Chrome 轮次均关闭本轮上下文、HTTP 服务并移除私有 profile。未关闭用户窗口、AU01 或其他进程。共享锁已释放。

简化限制：远景云穹顶不提供体积穿云、云影或 AI 遮挡；海面无真实浪高、流体、屏幕反射和舰艇实时投影；正常近景依靠坡度与低强度反光表达水面。没有通过增加重后处理、修改单位、地图或战斗状态掩盖问题。
