# S07 首个可玩场景与观战界面

2026-11-10。**S07实现与原生范围已由统筹验收通过；浏览器及10分钟多轮验证由S08验收。** 固定Godot `4.7.2.stable.official.ed1daf0bf`、typed GDScript、Compatibility。当前目录没有Git，按文件、正式接口和验证报告交付。

## 一键入口与复验

在工程根目录执行。所有引擎操作均经统一互斥包装器，关闭观战窗口可正常退出；自动检查和实拍均有超时。

```sh
python3 tools/verify.py --owner S07 --timeout 1200 --lock-timeout 10 godot --render -- res://showcase/first_playable.tscn
python3 tools/verify.py --owner S07 --timeout 90 --lock-timeout 10 test res://tests/test_first_playable.gd res://tests/test_first_playable_ui.gd res://tests/test_first_playable_report.gd
python3 tools/verify.py --owner S07 --timeout 240 --lock-timeout 10 godot -- --script res://tests/first_playable_run.gd -- --seconds=900 --output=res://docs/showcase/evidence/S07/natural_run.json
```

已接受的演出图片无需重复拍摄。仅复拍持续伤情：

```sh
python3 tools/verify.py --owner S07 --timeout 180 --lock-timeout 10 godot --render -- --script res://tests/first_playable_capture.gd -- --damage-only
```

完整实拍用同一命令移除`--damage-only`；仅720p界面使用`--smoke-ui`。自动捕获缺少要求的实际事件／状态会明确失败，不能用空截图计为通过。

正常自动镜头的三类事件时刻实拍（不调用手动相机）：

```sh
python3 tools/verify.py --owner S07 --timeout 180 --lock-timeout 10 godot --render -- --script res://tests/first_playable_auto_capture.gd
```

观战按钮提供暂停／0.5、1、2、4倍速、自动电影、自由观察、单位跟随、指挥态势、收起／恢复信息、启用声音、战报、结束和重开。Space暂停，C恢复自动，F自由观察，Tab展开态势，H收起信息，R重开；右键拖动、滚轮缩放，Shift+WASD平移、Q/E升降。点击命令定位编组，可另定位目标，退出对象保留最后相关位置。声音默认关闭，需用户启用。

## 实际文件与接入

- `showcase/first_playable.tscn`：独立新入口。`project.godot`根默认大和和旧`showcase/showcase.tscn`均保持，未搬迁旧工程。
- `data/scenarios/first_playable.json`：4舰8机、六个正式型号、两方各两个双机组。水面初距8km；先遣双机与后方警戒双机分别布置，保留型号、服役年代、武器与历史性能。只安排初态、余油及撤离区，不安排命中、伤害或轨道。航空自主退出区与S06指挥配置一致。
- `scripts/game/first_playable_session.gd`：正式catalog与AircraftSuite、CombatSuite、FleetSuite装配，固定tick／积欠、逐帧drain_events、真实战报与可达结束条件。定义域／炮位角色按型号缓存，fired热路径不复制舰艇定义；每帧只复制一份单位读模型，命令每30仿真tick刷新，表现不调用完整world.snapshot。
- `scripts/game/first_playable.gd`：正式模型、S05效果和环境装配，以及暂停、速度、重开等操作。舰机退出、残骸和沉没按真实字段显示，未修改战斗／航空／舰队模块或装备参数。
- `scripts/presentation/cameras/observer_camera.gd`：只消费复制数据和真实事件。全景、舰机跟随、自由观察、命令定位、退出回退；近距任务和实际炮位转向／装填状态可触发提前跟拍，事件只决定摄影。9秒最短停留、切换冷却、齐射后有限等待实际落弹；同一伤情不会持续压制其他交战。过期salvo不标当前齐射，水柱／空爆消退后改称对应海域／空域。
- `ui/observer_hud.gd`、`observer_text.gd`、`observer_map.gd`：720p默认双方紧凑指挥卡、并行任务、双机组名称、真实逐成员执行／改派及终态时间线，支持定位和滚动。中文阶段／原因覆盖S04/S06及blocked；不展示tick、类名或JSON。速度、单位选择和暂停按钮随重开同步；观众读模型不回流给指挥官。
- `scripts/presentation/models/visual_recoil.gd`：实际fired事件驱动现有炮管网格后移／复位，按仿真时间播放，各实例独立；没有改宿主、几何大形、炮口Marker、库存或伤害。暂停与重开保持正确偏移。
- `scripts/presentation/ocean.gdshader`、`wake.gdshader`：简化海面和收窄渐隐尾流。复用S05基础火光、曳光、水花、空爆、火烟和原创程序音效。
- `export_presets.cfg`：增加递归JSON与字体授权文件过滤。打包既有Noto Sans CJK SC／OFL字体，未依赖macOS字体回退。
- `tests/test_first_playable*.gd`、`first_playable_run.gd`、`first_playable_capture.gd`：真实场景操作、状态隔离、自然流程／摄影审计和原生实拍。受控战报分类用例明确独立，不进入正式场景或演出截图。
- `tests/first_playable_auto_capture.gd`及[观战运行契约](../first-playable-runtime.md)：正常自动镜头实拍、读模型、事件／时钟、重置、控制与Web交接说明。
