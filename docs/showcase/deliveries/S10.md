## 真实默认实战与受控机制的区别

[最终默认180秒实战](../evidence/S10/default_battle.json)使用完整15单位、固定种子707，无注入目标、伤害、炮弹或健康值；43项战斗输入hash开始/结束完全相同。实际结果如下：

| 路径 | 发射 | 单位命中 / 损伤事件 | 说明 |
| --- | ---: | ---: | --- |
| 岸炮 → 舰艇 | 5 | 3 / 0 | 实际命中装甲目标；现有HE/装甲粗代理判为无有效损伤，没有为演出改穿甲 |
| M1 → 飞机 | 110 | 2 / 2 | 碰撞命中产生真实飞机结构损伤；不是命中脚本 |
| 日舰 → 地面炮组 | 32 | 0 / 0 | 32发均先撞实际地形，弹着距岸炮根部约19–588米；保留真实散布/低弹道和岛岸阻挡结果 |

岸炮最远实际开火距离约1,999m，两个M1最远约2,729/2,731m，均没有放大历史射程。M1有效防空距离配置 **2,743.2m**；Mk13范围上限 **15,636.24m**，127mm、22.6796kg、960.12m/s。M1为40mm、0.88904kg、874.776m/s、120rpm；不调整旧舰机性能。

最终默认记录中 **108次M1自毁全部是8.5秒**，而该轮AA的截击解算时间为 **2.83–3.54秒**。独立 `self_destruct_s` 采用手册7–10秒曳光燃尽范围的单值近似，`burst_radius_m=0`，2米自毁破片半径是显式粗代理，未按目标截击时刻设置重高炮式引信。

[48项受控同图检查](../evidence/S10/mechanisms.json)明确使用静止目标姿态、耗尽库存和定点实弹探针，**不是默认战斗成绩**。它覆盖实际岸炮弹道对舰相交、M1碰撞损伤、固定寿命自毁、地面承载拒绝、炮口匹配、有限弹药守恒、停火、后山阻挡和场地85°仰角上限；真实127mm命中炮架使ground进入disabled，继续真实406mm命中可摧毁为原位wreck。失效后不动、不射击、不进水、不坠落，残骸继续碰撞，30秒后removed。这证明默认对岸未命中不等于地面单位不可受损。残骸沿用静态模型与既有火烟，不另做碎裂模型。
