# FX01 战斗动态效果

2026-11-11（Asia/Shanghai）。**实现、原生及Chrome专项自验完成；统筹已实际接受缺陷修复与Chrome画面，最终hash/进程独立核对由统筹登记。** 本轮为 S10/S13 冻结输入上的效果专项，不替代 S08 十分钟、DM01 真实飞行路径或 S14 全单位验收。旧 S05 交付保留为历史记录。

## 已实现

- 真实 `surface_impact(surface=sea)` 生成三段有轮廓变化的低多边形水柱、少量水雾与向外扩散的泡沫；水柱沿实际交点升起、回落、淡出，基部保持 y=0。406mm 与127mm尺度不同。`unit_impact` 复用有上限的大范围落水，地面/建筑仍生尘。
- 真实 `airburst` 产生短闪光及三片不规则深灰黑烟，快速膨胀、缓慢漂移并在约6.5–7.2秒内淡出。M1 `tracer_self_destruct` 保留实际8.5秒自毁，只用约0.68米、1.8秒小烟团；重高炮本夹具烟片约6.35–8.06米。没有改引信、目标或伤害。
- `fired.tracer` 抽样弹丸使用实际初态与重力，按事件时间外推，短尾长度0.8–6米、亮芯宽0.075–0.12米（视觉光晕近似）。hit/airburst/surface_impact/projectile_expired 立即结束对应弹迹；批量消费不会让已经终止的弹丸继续穿过目标。
- 持续烟火读取真实损伤快照。移动烟源按锚点位移补点，每次最多16点；旧烟留在世界轨迹，饱和时回收最老的同类烟。持续火焰附着本帧部位，停止发动机不会继续播放正常发动机循环，固定 ground 不分配发动机声源。

生产改动只有 [CombatEffects](../../../scripts/presentation/effects/combat_effects.gd)、[共享几何 helper](../../../scripts/presentation/effects/combat_effect_geometry.gd) 和[效果 shader](../../../scripts/presentation/effects/effect_surface.gdshader)及伴随UID。没有更改弹药/伤害/飞控、地图云海、模型、公共 first_playable 或 AU01。声音仍用既有原创程序合成；Web STREAM 与宿主幂等 stream_paused 路径保留。独立 Web 包排除未消费的 AU01 候选资源。

## DM01 消费与实际修正

[完整消费契约](../fx01-effects-contracts.md)和[源码冻结标记](../evidence/FX01/implementation_freeze.json)已发布，最终为 revision3 patch2。保留 advance→consume→apply_snapshot 顺序；持续烟火在 apply_snapshot 使用当前位姿，旧瞬态效果由 advance 老化。damage.effect_emitters 可提供最多4个部位烟火源，空数组停止新发射。真实 unit_impact 后停止主机体新空中烟火；离场与 generation reset 清空相应状态。

统筹/DM01 发现并修正了两个实际问题：

1. 原实现从上一帧快照生成烟火，96.2m/s、每帧4tick时落后约6.4米；火焰自身也停在旧世界位置。现在烟源使用当前快照，火焰跟随部位。[检查数据](../evidence/FX01/effects_checks.json)覆盖46帧含转向、82个存续火焰样本，新烟源及火焰锚点最大误差均0米。[原反例](../evidence/FX01/external_review/fx01-r2-review/engine_source_lag.png)与[修正后机首](../evidence/FX01/native/smoke_engine.png)可复查。
2. [失败水雾近景](../evidence/FX01/failures/water_close_r3p1.png)的水平硬边在UV边缘归零后仍存在。逐层隔离显示：关雾不改变硬边，隐藏不透明海面后消失；大面片被y=0海面从遮罩内部截断。新增片元世界高度淡出后，[同一失败机位](../evidence/FX01/surface-debug-fixed/all.png)不再出现这条边；[完整水柱近景](../evidence/FX01/native/water_close.png)和[正常距离](../evidence/FX01/native/water_observer.png)均已实际查看。未修改海面或取消其深度遮挡。诊断也对照了固定引擎的[GLES3雾混合源码](https://github.com/godotengine/godot/blob/ed1daf0bf/drivers/gles3/shaders/scene.glsl#L2558)。
