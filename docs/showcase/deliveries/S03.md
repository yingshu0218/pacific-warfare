## 表现API / S05–S07接入

接口与S02对齐，无继承/复制其易变脚本：[完整使用说明](../../../scripts/naval/destroyers/README.md)。

```gdscript
visual.apply_state(unit_state.snapshot())
visual.apply_weapon_state(station_id, {"train_rad":train, "elevation_rad":elevation})
var sockets: Array[Dictionary] = visual.mount_sockets()
var muzzle_local: Transform3D = visual.muzzle_transform_local(station_id, barrel_index)
var muzzle_world: Transform3D = visual.muzzle_transform_global(station_id, barrel_index)
```

`apply_state`消费position_m/rotation_rad/active/weapons，显示世界给出的姿态。模型不自行推进/插值/自动瞄准。角度弧度、train相对base_yaw、正X俯仰抬炮口、前向为`-basis.z`。`gun_elevations_rad`可选逐管输入；不等俯仰时使用实际逐管炮口。未知炮位/非有限角度拒绝，socket getter深复制。调用方在加入场景树完成_ready后使用；单位实例缩放保持1。

武器周期、转速、初始库存和代表弹药参数均明确`provisional`，须由S05选择具体弹型/引信和校准；不是历史性能终审。S05仍负责射界遮挡、自舰/友方避射、火控、装填和发射；主炮机械限位与显示硬限位并不赋予所有角度开火许可。S06另接舰艇运动，S07只消费世界快照。
