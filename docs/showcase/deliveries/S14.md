# S14 全单位 Showcase 最终集成交付

2026-11-11（Asia/Shanghai）。**实现与本轮自验完成，提交统筹最终复核；S08 普通启动、长测与加速验收仍独立执行。** 本次接续已验 SB2C r2、S04-training、FX01 与 DM01，完成 19 单位场景、两型十项真实训练、四机及护航完整循环。最终Chrome共74项通过，基础控制另有15项已通过的局部检查；失败原因、来源与清理均保留。

## 使用与范围

正常入口 `res://showcase/all_units.tscn`；根 `project.godot` 的大和入口保持原状。19 个真实单位包含四舰、6 架 F6F-5、4 架 A6M5a、2 架 SB2C-4、1 座岸炮和2座 M1防空炮，共9种型号；另有5项兵器检视，不重复计入战斗单位。型号、原资源、观看入口与能力见[清单](../all-units-inventory.md)。

菜单16段：连续导览、双机、四机、自然尾追规避、SB2C护航、舰炮火力，以及 F6F/A6M 各五项训练。选择新选段会明确重开整场并增长 generation；兵器检视不重置。单位菜单及“跟随”可直接看九型实体；保留暂停、倍率、R、自由/自动相机、双方指挥卡和真实任务时间线。

导演仅通过统一 BattleOrder 下达高层演示命令，source=human、issuer_id=s14_exercise_director，界面标为“演示任务”。接敌后的目标、枪弹、损伤、姿态及终端运动均由生产模拟决定；镜头不控制模型运动，敌机只用己方 contacts。四机总览穿插攻击对/支援对近景；护航穿插 SB2C、双机和威胁近景。训练保持世界上方向，34米单机视距可看完整机身、倒置、拉杆和改出。

SB2C 使用已准入 r2 原模型与原 clean 接口，飞行参考减 y=2.38米、不缩放，轮/翼面/弹舱、桨与舵面沿既有适配。仅导航、编队及作为护航对象；未接投弹、后射手、起降、实用武装或预切毁伤。独立性能与一般碰撞估值均保留，未调两型战斗机性能。

## 真实训练与循环

训练直接发 `aircraft_training` 和明确参数，继承同一 AircraftTasks；没有新增执行器或第二套飞控。起始离地2400米、速度115米/秒，与其他友机隔离。界面同时核对当前 order_id、该单位的 execution 和实际 training 结果，接收回执及旧训练记录均不能触发“已完成”。阶段、拒绝和安全接管原因使用中文；工具提示不泄漏内部字典。

完整滚转实际峰值为362.00°/363.78°，随后真实改出；半滚倒转实际高度变化为−772.84/−716.54米。十项均匹配实际完成，最小训练友机距离超过4.4公里。数值来自[完整集成数据](../evidence/S14/final/integration/)，不是字幕或旋转动画。

四机段12秒接敌、52秒发重组命令。两方重组实际完成事件分别142.533和152.083秒，导演152.100秒才标注重组完成。实际航空发射120次，双方各1架自然损失，其余成员继续重组。护航段12秒出现威胁、58秒命令威胁撤离；所有存活护航机保持真实 escort 任务、回到保护机2500米内并持续3秒，94.017秒标注恢复警戒。本种子护航航空发射为0，证据证明威胁响应及返回，不宣称护航枪战。
