## 接入口与实际行为

[舰队契约](../../fleet-contracts.md)是S07可消费入口：先configure，再分别安装正式AircraftSuite、CombatSuite、FleetSuite。`FleetConfig.load_file("res://data/fleet/showcase.json")` → `FleetSuite.install(world, config, enable_commanders=true)`；最后参数false可用human来源或受控机制测试。配置、场景编组、航点、双方巡航/撤离区域、海岸盒共享接法、初始余油/旗舰优先级和原因码已写入契约。S01状态类和高层命令语义未改。

| 文件/模块 | 职责 |
| --- | --- |
| `scripts/simulation/ship_motion/fleet_config.gd`、`ship_motion.gd`、`ship_navigation.gd` | 独立参数校验/冻结；有限航速、加减速、转舵加速度和按速度限制回转；同tick邻舰预测、稳定右转让行、显式海岸盒可见性图绕行；伤情影响实际航行 |
| `scripts/behaviors/fleet_formations/fleet_tasks.gd`、`fleet_formations.gd`、`fleet_suite.gd` | ship域唯一任务执行；巡航/保护/防空/舷侧炮战展开/集结/撤退/旗舰接替；运动追随站位；逐tick重查归属，部分改派与取消释放实际控制 |
| `scripts/command/commander/fleet_planner.gd`、`fleet_commander.gd` | 200优先级；纯己方快照规则规划器；6秒决策、24秒普通换令冷却、18秒失联迟滞、保持当前可用空中目标；新威胁/失去旗舰/严重伤情可提前反应 |
| `data/fleet/showcase.json` | 四型历史航速上界、独立运动/航行/规则近似、双方区域；单位定义/尺寸/炮位/战斗参数保持原所有者维护 |
| `tests/fixtures/fleet_*.gd`、六个`test_*`、`tools/collect_s06_evidence.py`、`plot_s06_evidence.py` | 受控机制、正式组合见证、证据归档和纯轨迹图；不通过测试夹具替换正式战斗模块 |

程序指挥官只读`commander_snapshot(faction_id)`并调用`submit_order`。FleetPlanner没有世界引用，不读观众快照、敌军实时坐标/命令/伤情。高层请求为BattleOrder，ai/human同一身份、阵营、能力、归属、执行路径；正在执行的human命令受到尊重。各域执行器回报execution，S07据逐成员真实阶段/原因展示，不依赖订单最初的forming摘要。

四机威胁下，一对拦截，一对保护，使用S04已有group/双机角色；不重新实现飞行编队。舰艇engage只把新鲜己方接触的目标和fire意图交S05；炮位、命中、库存和毁伤均无第二写入者。失联清目标，搜索最后观测，32秒未重新接触则真实失败`contact_not_reacquired`，之后可集结/恢复搜索；不知道敌舰沉没时不作击沉报告。

disabled舰浮水并有界惯性减速；sinking/wreck位移只由S05积分。尚未removed的舰体保守留作避碰障碍。撤退必须真实到达区域并减速，才completed并设置`ship_motion.exited`、active=false，发一次`ship_exit {destroyed:false,sunk:false}`；导航排除退出舰。完全失去动力/燃料且未到撤离区时，同一executing任务显示`blocked`及`propulsion_unavailable`/`fuel_exhausted`，保留防空和已知接触内的对海自卫，不重发失败撤退、不假成功/沉没。

S05退出单位仍参与弹丸/后续伤害的独立缺陷由统筹协调原所有者修复；本板块已发布退出字段并排除导航邻居，未越权修改S05。S07须据exited区分撤离与失能/沉没记账。
