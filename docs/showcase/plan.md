# 小规模战斗与飞行 Showcase 计划

## 目标与边界

制作一个独立可启动的装备联调演示场景，不替换根项目主场景、不修改 `project.godot`。展示不对应真实战役：1944 年沃莱艾日军机场是保留原貌的日军设施；跑道以北、与机库和滑行区隔开的无人地面靶区标为“中立试验靶区”。大和号只向该靶区射击。日军舰载及岸上防空只将美军 F6F 列为敌对目标，绝不把友军设成有效目标。

保持所有资源 1:1 米制，使用根项目 Godot 4.7.2 Stable 与 Compatibility。场景入口放在 `showcase/`，通过根项目资源路径启动；修改与证据均限定于 showcase 目录和 `docs/showcase/`。

## 已审计接口

- 大和号由 `scripts/ship_geometry.gd::build_ship()` 组装。坐标为右舷 `+X`、上 `+Y`、舰艏 `-Z`，舰体原点在中纵剖面和舰长中点。武器节点为 `WeaponMount`，具 `elevation_axis`、相对基准的训练角、射界、速度和 JSON 安装位元数据。主/副炮以及 12.7 cm、25 mm 武器的炮管几何沿局部 `-Z`，口径、炮管间距、轴位置和近似运动限制来自 `data/weapon_profiles.json`。
- `aircraft/scenes/a6m5_52ko.tscn` 与 `aircraft/scenes/f6f5.tscn` 由各自完整程序模型构建；轴向同为 `-Z`。A6M5a 的 20 mm 炮口节点名为 `20 mm muzzle`，F6F-5 的六个 .50 in 炮口名为 `Browning muzzle L/R NN`。机炮固定随飞机机体，不另造替代飞机或固定轨道。
- `island_airfield/scripts/woleai_environment.gd` 负责真实比例岛屿、海面、跑道、设施和固定阵地，既有地面炮目前仅静态展示。机场中心为 `(0, 0, 0)`，跑道长轴沿 Z，约 1000 m；既有两处 Type 96 与三处 Type 92 阵地坐标见该脚本。动态炮位将复用现有 Type 96 舰载炮架/炮身与 Type 92 三脚架/维克斯枪体场景，位置对应现有阵地，不改机场生成器。
- 现有机场航线控制器是固定航点的单架 A6M5 起降展示，不用于空战；新模拟直接复用飞机网格和炮口接口，独立实现速度、转向、爬升、损伤及拦截。

## 实施拆分

1. **装配与空间审计**：新建 `showcase/showcase.tscn` 和运行脚本。复用岛屿生成器与完整大和号；标注并生成隔离靶区。选择海上舰位，使主炮、副炮、舰载高炮到靶区/接敌空域均在真实米制距离内。创建两架 A6M5a、两架 F6F-5，分别标记日军/美军阵营及服役年代。
2. **炮术与碰撞**：使用原炮口局部几何/明确炮口标记。主炮和副炮从不同安装位独立瞄准靶区，按射界、炮口速度、转向/俯仰速度及装填节拍控制。以 1/60 秒固定步长积分重力与速度；线段-目标球体检测真实命中，伤害改变靶标状态并生成受上限约束的爆炸、烟效。没有脚本定时命中。
3. **飞行与机炮**：以连续速度向量、有限转弯率和爬升率追逐对手并计算提前量；模型姿态由速度方向更新。A6M5a 的 20 mm 炮、F6F-5 的六挺 .50 in 机枪从模型炮口发射；弹丸离散固定步长运动、扫掠碰撞并扣除飞机耐久。击毁后进入失控坠落状态。
4. **防空**：从大和号现有 12.7 cm Type 89 双联炮与机场 Type 96 双联、Type 92 机枪位置发射。Type 89 为按飞行时间触发的高爆空炸，Type 96 与 Type 92 只发射直接碰撞弹；Type 92 不创建高炮空炸。所有交战前检查阵营，友军永不成为射击目标。
5. **观战交互**：总览、舰炮、靶区弹着、空战、防空近景镜头；鼠标自由环绕/平移/缩放，镜头跟随与镜头目标切换；暂停、1×/2×/4×、重置、HUD 隐藏。战术 HUD 显示当前目标、武器状态、阵营、弹丸与命中计数。
6. **复验与交付**：已完成 headless 导入及机制验证、120 仿真秒运行、三次重置审计和原生四视角截图。装配验证通过后，用临时 Web 构建在 Chrome、Safari 检查显示及相机快捷键，并在 M5/16 GB 设备记录运行中的 F8 性能快照。预览进程和测试标签已关闭；结果、命令、证据和简化项记录在 `delivery.md`。
