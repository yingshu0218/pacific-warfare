# F6F-5机动质量复核（v3自验完成，待独立验收）

2026-11-10，用户进一步要求消除姿态突变、摇摆与反复抬低头，并看清滚转定升力方向后拉杆转向。保留v2原生录像、原始帧hash、曲线和源文件于`v2-before-f6f-calibration/`。

## 已定位的实际原因

- 四对四`us_0`，29–45s长期约-78°坡度；实际载荷约0.85g下降至-0.35g，39–45s持续负载荷并加深俯冲。控制器计算升力朝向与垂直补偿载荷相互矛盾，负载荷还使横向曲率反向。不能把有坡度当作已经正确转弯。
- 三维目标方向的最短弧在目标位于身后时可能向上绕，而非先滚转建立转弯平面；归队期望方向虽限制25°，仍出现实际超过50°上仰。此为控制几何错误，不能用延长平滑掩盖。
- 高坡度以垂直需求除cos(bank)请求载荷，低速时过载/能量约束持续饱和；归队、安全与追瞄的控制权交替导致抬头—卸载循环。
- ±78°世界坡度限制让倒置与半滚倒转无法发生；其改法必须是实际升力框架和航迹控制，不能仅转模型。

## 确定的修正范围

普通引导分别计算航向与航迹俯仰的期望角速度，再求协调升力方向和可承受正载荷；按速度/失速裕度限制坡度。独立机动控制指定机动平面与拉杆载荷，先依实际滚转对准再拉杆；有限滚转加速度/速率和正载荷会真实弯曲航迹。F6F增加情境触发的大坡度急转、反向滚转及有足够高度和速度余量的半滚倒转，均有几何完成、超时和安全中止。安全模式只选一个实际控制者，并保持进入/退出阈值。无需所有机型做相同动作。
