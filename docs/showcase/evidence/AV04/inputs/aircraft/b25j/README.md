# B-25J 透明机鼻轰炸构型 / AV04

**B-25J-1-NC早期标准，1944-07**。代表构型，不是具体尾号复原；Wright R-2600-13双发、各三叶桨、双垂尾、三轮起落架，12×.50口径枪。原始手册是1944-07基版的后续修订汇编，晚期增枪不采用。外形和主要装配按[已打开的原图/原页](../../docs/references/aircraft/b25j_1944_07/modeling-brief.md)约束，不从旧实心枪鼻换皮。模型为原创程序几何，玻璃是不透明深色块，省略细密结构和内舱。

纯模型 [b25j.tscn](b25j.tscn)，检查场景 [inspection.tscn](inspection.tscn)。1:1米制、+X右/+Y上/−Z前；含炮口中立可见包络长17.47m（名义机身长16.30045m，不含武器）。根原点固定于几何基准，**不是测得的历史重心**。飞行宿主模型偏移为零。`b25j.gd`与本机`geometry.gd`是唯一运行时模型依赖；通用网格helper从AV03复制，飞机形体独立重建，不运行共享Builder/Adapter、不注册单位、不改普通入口。

`apply_visual_state(Dictionary)`只立即消费快照；没有_process、计时器、飞行、射击、生成炸弹、扣库存或随机故障。缺项保持状态，有限数值检查类型/夹限；错误类型和NaN/Inf不变成动作。宿主负责推进和插值。

| 快照字段/方法 | 行为 |
| --- | --- |
| `propeller_left_rad`、`propeller_right_rad` | 各侧桨局部+Z独立相位；宿主在发动机失效后决定停止和烟效 |
| `gear` | 0收、1放，连续有限行程；两主轮简化+X后收88°、前轮后收95°，最终隐藏，不制作完整轮舱/多连杆传动 |
| `flap` | 0…1→四片内/外襟翼绕+X向下0…35°，与双侧翼宿主一致；不是气动标定 |
| `aileron_left_rad/right_rad` | 各自局部+X，±0.35rad |
| `elevator_left_rad/right_rad` | 各自局部+X，±0.35rad |
| `rudder_left_rad/right_rad` | 各自局部+Y，±0.35rad，实际双垂尾，未虚构单中央舵 |
| `bay_door` | 0关、1开；左右外侧纵向+Z轴分别−/+85°，必要双扇门，非复杂液压机构 |
| `payload_mode` | `bombs_6x500` 或 `empty`；没有混装鱼雷/火箭 |
| `bomb_visible` | 6个bool，逐枚显隐，**模拟库存归BOMB01唯一管理** |
| `guns` | 按下表ID传`{yaw_rad,elevation_rad}`；炮口实际随+Y偏转/+X仰俯，固定枪限位为零 |
| `apply_damage_state({id: attached_bool})` | 六个实际部位宿主显隐，不产生战果/运动/碎片 |
| `set_flight_configuration()` | 收轮/收襟翼；保持根原点、枪位、载荷和桨相位 |
| `set_landing_gear_deployed(bool)` | 同一快照接口的二值入口 |
| `get_parked_transform()` | 用真实轮心/半径求三轮支承：俯仰+0.27947°，原点Y2.171444m；不变更自身根变换 |

以上是**未测绘的保守表现夹限，不能授予真实开火许可**。宿主须另验机身/翼尾/桨盘、友军、地形与目标方向遮挡；背塔能转360°不等于任意射线可用。没有火控、无限弹药、历史射界合格声明或完整备弹量。

`markers`、`guns`、`propellers`、`surfaces`、`gear_axes`、`bay_doors`与`damage_modules`字典可消费；68个实际Marker、路径/位置/枪口方向/部位包络见[interfaces.json](data/interfaces.json)。`left_wing/right_wing`分别拥有该侧`engine_left/right`及桨和主轮，断翼不会留下悬空发动机。发动机可独立失效/隐藏；只停桨用相位快照，不必把整翼隐藏。尾部携带双鳍/方向舵、平尾/升降舵和尾枪。宿主解挂须保持global_transform；父/子AABB提案不可重复当独立命中体。

载荷为有战时记录的**内部6×500lb GP**，两侧梯架各三层，站位为保守装配估值。槽0/1是下层，2/3中层，4/5上层；同侧下层必须先清空，`0,1,2,3,4,5`为可用顺序，开门后由BOMB决定释放。逐槽实际中心/尖端/侧挂点已发布，不能一次扣空再伪造逐弹显示。AN-M64选TNT，1950年TM9-1980表列完整弹511.8lb=232.148575kg，6枚1392.89145kg；名义级别总3000lb不等于实际总质量。此表不是1944具体批次/引信证明。BOMB01现有240kg占位值待统筹协调，模型没有修改共享弹种表。简化弹体约1.5026m长/0.356m直径/0.40m尾翼，非精细AN-M64引信/尾箱复刻。来源、性能缺口和未注册接入提案见[proposal.json](data/proposal.json)。

真实轮心：主轮`(±3.12,−1.65,0.30)`、r0.52m，前轮`(0,−1.85,−5.85)`、r0.35m；中心/半径是照片拟合，**模型中轮胎实际值**，不冒充原厂站位。放置：`Transform3D(Basis(Vector3.UP, heading), surface_station) * model.get_parked_transform()`。MAP02地面8.04m实查跑道/滑行道/8停机点；全桨盘、机腹/载荷、全开门、下襟翼与建筑包络通过。16m滑行道每侧翼尖外伸2.2997m，不能据此声称动态滑行/交通或起降完成。

正常视距下保留轮廓与主要装备；可选机身星徽整块省略，避免曲面穿插，保留完整左上/右下翼面星徽。独立网格/面数以接口报告为准，不作为机群Chrome性能。最终证据、冻结与交接见[AV04交付](../../docs/showcase/deliveries/AV04.md)。未完成：生产注册、真实飞行/起降/轰炸/DM运动、Chrome；无折翼、尾钩或正常航母回收资格。
