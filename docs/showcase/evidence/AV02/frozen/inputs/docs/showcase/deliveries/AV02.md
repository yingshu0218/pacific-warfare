## 尺寸与三轮承载

1:1米制，缩放`(1,1,1)`；+X右、+Y上、−Z前，固定展示基准`(0,0,0)`，不是实测重心。A-11表II的SUISEI-12为翼展11.497m、长10.22m、高3.740m；采用名义翼展11.50m。表的Height没有写姿态、桨相位或轮胎压缩，不能与停机网格测量混写。

实际清洁飞行网格包络：**11.500×2.565×10.220m**（X/Y/Z，桨相位0）。三轮解算停机俯仰**10.791146°**、Y平移**1.240352m**，保持机体原点不变。主轮中心`(±2.18,−1.28,−1.80)`/半径0.32m；尾轮`(0,−0.34,4.20)`/半径0.12m，均为照片约束的简化重建，不冒称厂图站位。没有拉长尾轮来水平停机。

最终同状态、桨相位0的停机网格高**3.698153m**、长10.102157m。解析半径1.60m完整桨盘上端3.695781m、下端离甲板**0.552369m**；网格桨叶本身有宽/厚，毫米级包络差异保留。旧3.012691m来自旧运行中的1.1rad桨相位；此前读取新源码与旧JSON混合曾造成歧义，最终已重新运行并核哈希，未靠改支柱凑3.740m。

三轮解析切线误差<1e-5m；64段轮胎网格最低点偏差约0.032mm，检查容差0.1mm。真实独立部位净空：机腹0.249m、下颏1.132m、40°襟翼0.462m、70°翼下减速板0.843m、完全下放钩端0.0517m。**完全放下投弹摆架时炸弹会低于静态地面约0.50m**，停机开舱只能保持收架，完整摆架用于空中，由BOMB01校验姿态/甲板与释放许可。
