# OPS01 第一阶段参数与原始资料

2026-11-11。固定 Essex CV-9 1944-04-15；F6F-5 1944 子型，架空组合。本文件只支持简化模型参数，不是实际飞行操作指引。

## 实际打开的原始资料

- 美国海军《AN 01-85FB-1》，本地原件 `docs/references/aircraft/f6f5_1944/original/f6f-pilot-handbook.pdf`，来源[手册扫描件](https://fredhaise.space/docs/career-paths/F6F_Pilot_Handbook.pdf)。本轮实际渲染并逐页看过 PDF45/50/51（印刷33/38/39页），图保留于 `sources/manual-045.png`、`manual-050.png`、`manual-051.png`。后期修订含1947内容，不能把整本手册等同于1944舰队程序。用于轮/钩/襟翼状态与程序顺序：离舰后收轮；初始回路降速；着舰前放轮、放钩、放襟翼；滑行通过动力/制动完成。没有从这几页读到固定着舰速度或阻拦减速度。
- NAS Patuxent River，F6F-5 BuNo58310，1944-09-07，TED PTR-2125，[海军原报告扫描件](https://www.wwiiaircraftperformance.org/f6f/f6f-5-58310.pdf)。已下载 `sources/f6f-5-58310.pdf`，实际打开PDF1–6（报告印刷7–12页）。5页为全襟翼起飞性能：总重12420lb，无风755ft、25kt风355ft、86.5mph；6页为清洁/着陆状态失速，着陆状态断动力84.5mph。有测试仪表/动力故障限制，文中已说明。历史值作为包线参考，不作为本项目点质量积分的精确拟合。
- CV01同源[甲板契约](../../carrier-deck-contracts.md)与`naval/essex_cv9_1944_04_15/data/deck.json`。15.85m顶面、同源障碍/孔口/八根索及升降机高度；不是OPS新绘另一块甲板。舰速上限32.7kt沿CV01资料；当前15m/s约29.16kt。
- S04 r10 已准入的[实际模型几何契约](../S04-carrier-usage-contract.md)，固定清单SHA256为`379681d3aa81909d08a1e7c28a323ca7bac03054a390e2efb83d558ec8c9a3f3`。OPS仅在私有stage消费四份候选文件。接续中实际打开了原始海军照片`docs/references/aircraft/f6f5_1944/carrier-usage/original/80-G-321823.jpg`与`80-G-K-1072.jpg`，用于核对抬头、放轮/放钩/襟翼关系；照片不能提供数字化迎角曲线。NACA L5B13仅找到元数据，全文下载未成功，未将其曲线用于参数。

## 历史量与近似的边界

`scripts/air_operations/parameters.json` 为作业包线与计时参数源，轮/钩几何只消费S04 helper。全襟翼失速37.775m/s取84.5mph换算，原报告重量/配置限制如上；原清洁状态44m/s、空中推力/阻力/油耗仍消费已有F6F性能。模型到飞行坐标的平移仍为`(0,-2.30,0)`，这不再代表三个轮胎都在Y=-2.30；旧18.15m停放原点与pitch=0已撤销。

新主轮中心为`(±1.93,-1.00,-1.27)`，半径0.43m；尾轮中心为`(0,-0.30,4.52)`，半径0.15m。沿机体局部的真实甲板法线求轮胎圆周支承，三轮解出9.6453°停放俯仰与1.203077m原点离甲板高度，即甲板局部Y≈17.053077m。该值来自已准入的简化模型，不宣称轮组工程测绘。旋转桨盘完整包络始终参与飞行接触检查；停放时桨盘净空0.237295m、35°襟翼/机翼最低净空约0.255642m。机腹、翼、尾支承点来自实际候选mesh的离线凸包，运行时不持有场景节点。

以下均为明确的游戏运行近似：49m/s抬轮/进近目标；43–56m/s触舰空速；≤4.2m/s下沉，方向误差≤6°、坡度≤5°，舰转速≤0.3°/s、倾斜≤3°；最低甲板迎风12.86m/s、侧风限制3m/s。静止空气下使用真实母舰航速形成迎风。第一阶段非零环境风直接拒绝，未把未接入空气相对速度积分的风场当作助推。

全襟翼目前通过失速/可用升力包线进入原力积分，尚无数字化的襟翼/起落架附加阻力极线。49m/s是保守起降运行目标，并非把海军报告的86.5mph起飞值改写成49m/s；因此本项目甲板滑跑长度不能宣称精确复现报告的355ft。

滑行3m/s、加减速0.7m/s²；甲板起飞推力减滚阻的净加速度3.55m/s²；扫过现有索位后沿甲板减速7m/s²。后者约0.71g，是常减速度近似，不模拟真实索缆弹性/挂钩载荷。甲板运行距离由积分位置与实际艏边界判断，不能满足速度就中止；没有蒸汽弹射或自动着舰设备。110s是演示巡逻时长；5s准备、30s整备为加速演示计时，不宣称历史甲板周转时长。

连续甲板重新布置新增1.2m/s、0.35m/s²的抽象人员/牵引力，按固定tick积分，未制作或宣称某款历史牵引设备。甲板滑跑将停放俯仰逐渐降低1.8°以抬尾，接地后再以2°/s落尾，原点高度随实际轮胎支承重算，不硬贴水平机体。消坡6°/s与偏航15°/s为简化接触阻尼。提前复飞与实际硬碰撞分开；后者使用既有CombatDamage地面撞击规则，没有假称精确载荷/着舰损伤预测。

原AircraftMotion为升力平面驱动的质点积分，OPS只在进近/带襟翼爬升及其退出过渡中分离速度航迹与物理机体姿态。9°进近机体俯仰、6–14°迎角范围、3°/s构型变化，以及机体14/15/65°/s的pitch/yaw/roll过渡上限，均为照片/模型净空约束下的运行估计；不是原厂气动极线。离舰保持当前迎角至真实轮胎离甲板0.15m，再连续卸除。过渡完成后直接回到原飞行积分，无永久额外角速度限制；清洁mission在原作业名册内的1200tick对照位置/速度/姿态误差为0。

尾钩自由钩端与实际鞋边来自S04 helper。对当前机体/甲板姿态求0–40°上偏约束，鞋边不低于甲板+0.02m；不移动飞机迎合尾钩。运行时三维鞋端扫掠段对实际索段求最近距离，0.073m阈值由0.023m索半径和0.05m鞋半宽组成。静态约29.95°只作S04参考，运行中不固定该值；正常触舰实例约23.64°并随落尾变化。未模拟弹性索、拉伸形变或钩载荷。

损伤后的宿主排除服从原DM。残骸以首次碰撞姿态开始，停桨后消费实际桨叶相位与剩余mesh，以重力方向对支点的力矩作有界倾转和落定。质量中心由声明的残骸近似计算：5650kg参考质量减满油681kg得4969kg基准干质量；body/左右翼/tail分别占70%/12%/12%/6%，位置取`parameters.json`的明确估计，加剩余实际燃油，断离宿主排除。该质量分配只用于残骸稳定性，不改变飞行质量/气动力或DM结果，不能当作原厂重心/惯量资料。

倾转为过阻尼简化，力矩除20m²/s的等效系数，角速度上限0.35rad/s；每步只接受重力势能不增的旋转，真实mesh重新求不穿透的支承高度。接触采样高度容差8mm，质量中心沿重力投影距接触凸包≤15mm且支承跨度>0.15m才算稳定。当前实际硬触舰的最后支承跨度5.348m、投影误差11.75mm，最终约3.9°俯仰/21.4°侧倾，不保持首次−2°姿态或单桨尖长时间悬空。碎片数量、受损结局、寿命与运动仍归既有DM；没有新增随机战损、精细悬架或完整刚体系统。

容量是有限现存实例、停车槽、油料kg和实际WeaponState逐枪弹数，不生成替代飞机。无需折翼或升降机下行；不开放SB2C或机库通行。F6F实际轮/钩/襟翼已在私有stage消费，普通S08公共模型尚未替换；组合与后续准入边界见`integration-hooks.md`。
