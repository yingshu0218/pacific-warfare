# 建模参考图与交接规范

更新：2026-11-10。用于[首版单位名单](../unit-roster.md)中的军舰、飞机和独立武器。目标是让 Codex 清楚地看到正确大形、比例和安装关系，适配首版简化画面。

## 1. 一个型号交付一份可直接使用的参考包

建模任务的输入必须包含：**目标身份＋精选原始图＋统一风格目标图＋必要尺寸与结构约束＋缺口＋对照视角**。只有相册网址、搜索结果、文件数量或“参考网上资料”不足以完成交接。

采用[统一视觉目标与 AI 参考图制作流程](../art-direction.md)：先以真实资料限定型号和结构，用 Image Gen 把杂乱的照片转成适合本游戏的简化外观目标，再通过同一个 Godot 粗模输出一致视图。原始资料、AI 目标图、模型实际截图保留各自身份；目标图可以指导外观简化，但不是新发现的历史证据。

每型默认精选 6–8 张整机／整舰图，必要局部通常 2–4 张。数量是整理预算，验收看覆盖问题；四张互补的好图可以优于二十张重复照片。独立武器通常需要 3–5 张有不同用途的图。不为了凑数纳入裁切、重复或子型不明的图片。

## 2. 先固定目标，再搜索

- 飞机写明子型、机鼻／发动机、基本武装、机翼与起落架展示状态；军舰写明舰名与改装日期；武器写明炮型和炮架型式。
- 涂装作为独立属性；博物馆或成品模型采用某架名机涂装，不能据此认定其机体子型。
- 先列当前要解决的三个大形问题，再定搜索词。例如“SB2C-4 机身与座舱比例”“展开翼平面”“后座枪架连接”。
- 使用英文型号和日文名称补查，按视角搜索：`full aircraft`、`in flight`、`side view`、`top view`、`walkaround`、`completed model`、`全景`、`側面`、`完成品`。军舰加舰名、舰号、年份及 `broadside`、`aerial`、`bow`、`stern`。
- 搜索缩略图只作为线索。进入原始页面核型号、日期、说明和作者，再打开实际图片；不凭搜索摘要或文件名写“已看过”。

## 3. 按用途选择来源

| 来源 | 主要用途 | 使用边界 |
| --- | --- | --- |
| 有档案编号的实机／实舰历史照片 | 确认年代、配置与实际外形 | 模糊、烟雾、遮挡或强透视的图可能不适合直接改形 |
| 博物馆、保存单位的实物照片 | 观察体量、连接、活动状态 | 查修复史、缺件及改装；不能自动代表战时配置 |
| 清晰、完整、同一作者的成品模型相册 | 多角度观察轮廓与空间关系 | 允许作为直观外观主参考；子型和关键结构需与真实资料交叉核对 |
| 原始手册、厂图、可信尺寸表 | 长宽比例、关键安装与机构关系 | 辅助约束几何，不以线图替代用户需要的直观全身照片 |
| 游戏模型与渲染图 | 参考简化程度、可读性和表现 | 不提供历史正确性的独立证明，不照搬其模型／纹理 |
| 基于本型资料生成的 AI 目标图 | 统一材质、色面、细节保留程度和展示方式，指导本游戏的视觉目标 | 逐张核结构；标出主动简化与未接受偏差，不提供新的尺寸或历史事实 |

**历史可靠性和建模可用性分开评价。** 一张真实但很糊的战时照片可以核配置；一组成品模型照片可以解释体量。两者配合，不要求所有图片承担相同任务。AI 生成或补画的“多视图”不作为历史形状依据；不能把自动补出的机翼、炮位和背面当成已核实结构。

## 4. 按问题覆盖角度

| 对象 | 开始主体建模前需要看清 | 组装／运动前补充 |
| --- | --- | --- |
| 飞机 | 完整侧面或接近侧面：机身／机鼻／座舱／尾翼；完整高位或俯视：翼形与翼尾位置；正前或接近正前：翼厚、上反角、机身体量；完整斜前：三维体量交叉检查 | 斜后：尾部和后座；机腹：起落架、弹舱、鱼雷或炸弹；需要折翼时才补折叠前后与轴向 |
| 军舰 | 全舰侧面：长高比与建筑层次；高位全舰：甲板和主要炮位；斜前／斜后：艏艉和舰桥体量；左右舷差异有依据 | 舰艏／舰艉方向、真实安装甲板和炮座；航母补飞行甲板、舰岛、升降机边界 |
| 独立武器 | 完整侧面、斜前、后侧，能看清底座与运动部分 | 与宿主接触、回转和俯仰关系；不要求首版还原传动内部 |

“俯视”须区分严格顶视与高位斜视；有透视的图不能直接量成正投影。近侧面照片也要标出停放姿态、起落架状态和明显透视。稀少史料缺某角度时，可用其他互补视图加尺寸约束，记录近似范围；不声称已经得到测绘精度。

飞机落地外形检查须把机体轴线与地面分开：简化轮子和支杆仍要保持真实安装位置与长短关系，不能为了让模型原点落在地面而把三轮强行做成同一局部高度。由实际轮胎圆面/接点解停放姿态和离地高度，再与地面侧照对照；飞行适配原点不随停放姿态重设。航母/机场装配检查同时保留机体姿态、轮胎接触和完整外形包络，三轮不悬空不等于停机造型已经正确。

## 5. 逐张看图后的筛选

每张图片都写明以下信息。推荐沿用每型目录中的 `sources.json`，在 `modeling-brief.md` 中呈现建模真正需要的精选内容。

| 字段 | 内容 |
| --- | --- |
| 图片编号／位置 | 稳定编号、原始页面、原图地址、本地文件或明确的外链 |
| 身份 | 具体型号、舰别／子型、年代、实物／成品模型／游戏模型；不明项写不明 |
| 视角与状态 | 左右侧、斜前／后、俯视／高位、折翼／展开、在空／停放、部件是否打开 |
| 可以参考 | 明确到轮廓、比例、安装、某一活动关系 |
| 不可据此判断 | 裁掉的翼尖、被遮挡部分、另一子型专有特征、历史涂装、精确尺寸等 |
| 检查结论 | 已看原图、有效像素与裁切情况、主参考／局部辅助／异型限制／淘汰／待看 |
| 来源与权利 | 作者／馆藏、许可或使用限制、检索日期；参考图与可发布游戏资产分开 |

优先原图长边 1600 像素左右或更高，但更重要的是对象本身清楚、占画面合理、边缘完整。4000 像素的施工零件照不能替代 1000 像素的整机照。历史小图仍可核对配置；放大或锐化不会产生新的证据。

下列图片不能计入“完整整机角度”：裁掉翼尖、机鼻、舰艏舰艉；仅有零件；严重遮挡；折翼图用来证明展开翼形；同角度重复。无来源 AI 图、子型错误且无法划分共通部分的图不用于改形。旧图不必删除，标清排除理由即可。

## 6. 从参考图到模型的执行步骤

1. **准备原始资料与结构约束。** 先填目标身份、精选图与覆盖表、必要尺寸和装备，列出最多三个当前阻塞大形的问题。常规资料整理由执行者检查，不新增逐图等待用户批准的环节。
2. **生成并检查风格目标图。** 给 Image Gen 输入本型原图、固定结构和统一风格要求，先做一张整机／整舰主图。回查主要轮廓、子型特征、部件数量及连接，记录可用范围与偏差；不用生成图补写历史事实。
3. **做简化主体。** 按米制、可信尺寸和原始多角度照片确定几何，用目标图指导可接受的简化、材质与色面。已有粗模可先导出截图作为生成输入。尚无依据的局部标记估计，不用虚构连接件填空。
4. **导出同模型视图并匹配对照。** 从同一个 Godot 场景导出侧／前／俯／斜视。保存与所选照片接近的朝向、仰俯、投影和画面占比；先校相机再判形变。需要时将粗模视图交给 Image Gen 补外观目标，但原始粗模视图始终保留为几何基准。
5. **按同角度交付。** 提供原始图、AI 目标图与模型截图的对应编号、改前／改后、修正的两三个差异与剩余缺口。先过主体轮廓，再过安装和必要运动，不用一张精修斜视图证明所有角度都正确。
6. **达到首版标准后集成。** 主要轮廓、比例、接触关系和接口可用即推进；铆钉、细孔、驾驶舱内部、细密索具不进入此轮。原生检查后完成使用场景装配，最后才做浏览器检查。

缺图只限制依赖它的几何判断，不把所有机制开发一起停住。参考包还不完整时，可以标明“允许检查现有形体／不允许据此定稿某部位”；不能把缺图悄悄变成已验收。

## 7. 目录与交接

每个具体建模目标有独立目录。已有 `docs/references/bombers/<系列>/` 不搬迁：先在目录说明中锁定当前子型，新增变型时再分子目录。新舰型可按 `docs/references/ships/<舰别_日期>/`，新飞机按 `docs/references/aircraft/<具体子型>/`，武器按 `docs/references/weapons/<炮架型式>/` 组织。

交接保留 `README.md` 或 `modeling-brief.md`（精选图、用途、角度覆盖、缺口）和 `sources.json`（来源台账）；已合法取得、允许保留的图片放同目录或 `images/`。只能链接的图片记录来源并标明访问状态。图床失效不得宣称已查看；没有必要把所有外部图片下载到仓库，更不能作为发布纹理打包。

AI 目标图放 `target/`，同时记录输入图片、实际提示词、风格版本、生成工具、主动简化、检查结果与适用范围。Godot 多角度检查图放 `checks/` 或链接既有验证目录。不得覆盖原始照片，不能把生成图改名伪装成史料或实际游戏截图。

使用[参考任务卡模板](../templates/modeling-reference-brief.md)。现成示例见 [SB2C-4 参考任务卡](../references/bombers/sb2c/modeling-brief.md)，本轮问题清单见[参考图审阅记录](../references/reference-audit-2026-11-10.md)。模板中的未填项不是已完成参考包。
