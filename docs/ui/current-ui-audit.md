## 发现与改版要求

| 优先级 | 实际观察 | 对观战的影响 | 规划要求 |
| --- | --- | --- | --- |
| 高 | 默认左右两个指挥面板各约 423×293 像素，合计约占 720p 画面 27% | 高层任务与每个编队细节同时常驻，抢占主体画面 | 默认只常驻双方真实任务摘要；完整命令与成员执行状态按需展开 |
| 高 | 战报面板出现在指挥卡下面，上方标题和统计被遮住 | 用户打开战报仍无法完整阅读 | 战报进入独立最上层模态；遮罩与焦点管理明确，关闭后恢复原观察状态 |
| 高 | 底部默认 13 个选择器/按钮同排；收起信息后仍留 12 个 | 常用播放操作与重开、结束等低频操作同等抢眼 | 常驻播放、镜头模式、态势入口；声音、地图/单位查找、战报等分组；结束/重开进入菜单 |
| 中 | 展开指令时左右大面板覆盖约 61% 的画面，左侧还需要滚动 | 观察行为和查阅指令难以同时完成 | 战术视图使用单侧详情区或紧凑底部区域；点击指令可定位编队/目标，避免同时摊开所有细节 |
| 中 | 飞机详情同样显示“进水 0%”，舰艇弹药为所有口径合计的大整数 | 信息占位多，不能帮助理解当前动作和能力 | 按舰艇/飞机/固定阵地显示适用字段；详细弹药按武器家族展开，不把不同弹种混成主指标 |
| 中 | 两秒时的指令历史为空，但右侧仍保留大块空间与泛化提示 | 难以区分没有变更与没有数据 | 有明确空状态；当前任务与历史变更分开；不虚构日志填满面板 |
| 中 | 标题、任务卡、地图、单位统计和底栏缺少明确主次 | 视线在四角和底边反复跳转 | 先定信息层级、布局和状态，再统一字体、留白、色彩及组件 |

上述面积是对本次截图中面板边界的近似测量，不是运行性能指标。未根据截图断言键盘导航、对比度全部达标或其他分辨率布局正常。

## 必须保留的能力

双方程序指挥官下达的真实命令、接收对象和执行状态；命令时间线与定位；自动电影/自由观察/单位跟随；暂停与倍率；单位实际状态；声音入口；战报、结束与重开；地图与岸防单位的后续扩展。

观众能看双方不代表 AI 获得对方全知数据。V1 仍为观战，改版不新增玩家下达战术命令的按钮。默认界面应保留双方简短摘要；完全隐藏 HUD 是用户主动进入的纯净观战状态。
