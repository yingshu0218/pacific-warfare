# Ki-21-IIa 九七式重爆击机 · 独立展示重建候选

本次是参考公开档案重新制作的 Ki-21-IIa 展翼静态外观，**不是先前版本源文件的精确恢复**，亦非游戏正式单位。采用收轮展示姿态。以低矮连续的背部玻璃舱区分后续 IIb 的凸起圆塔；本展示不使用仓库旧参考页中的 Ki-21-Ib 手办图来确定 IIa 外形。

- 澳洲战争纪念馆 [P03033.004](https://www.awm.gov.au/collection/C385001) 和 [P02270.024](https://www.awm.gov.au/collection/C304061) 机鼻近照支持两排下视窗、圆鼻玻璃格和轮廓明确的凹形发动机入口；[VIC1938](https://www.awm.gov.au/collection/C293276) 低斜角和 [VIC1929](https://www.awm.gov.au/collection/C293268) 垂尾近照分别约束收轮整流罩相邻体量和尾部、细天线位置。根部罩、弧形翼尖、单垂尾、阶梯驾驶舱和连续背部玻璃舱均手工简化重建。被俘后照片不作为战时颜色或标记依据，展品橄榄绿和灰底为游戏参考色。
- [P02270.025 的 1955 年说明板](https://collection.awm.gov.au/C304062)尺寸为约数，外廓参考与 [IIa 三视再绘图](https://www.armedconflicts.com/files/ki-21-iia.jpg)交叉判断。模型锁定翼展 22.500 m，机长 16.020 m，属于米制展示目标而非工程复测。原始资料只作为形体参考，没有打包到游戏。
- 静态展翼、三叶桨每侧、闭合轮罩。无任何可工作部件、武器、飞行动态或正式观战入口；也未修改共享体积生成器。
