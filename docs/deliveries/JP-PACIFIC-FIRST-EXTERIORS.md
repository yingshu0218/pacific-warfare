# 日军首批四机四舰外观

本批加入 Godot 外观展厅（`showcase/archive_gallery/viewer.tscn`），不是对局增援，不改武器或飞行规则。

| 类别 | 外观 | 档案对照 |
| --- | --- | --- |
| 陆航 | Ki-43-II 隼、Ki-61-I 飞燕 | [陆航照片与外形验收](JP-LAND-ARCHIVE.md) |
| 海航 | D3A1 九九舰爆、B5N2 九七舰攻 | [海航照片与外形验收](../../aircraft/jp_naval_archive/README.md) |
| 航母 | 加贺、飞龙 | [航母照片与外形验收](JP-FLEET-CARRIERS-VISUAL.md) |
| 巡洋舰与驱逐舰 | 利根、秋月 | [舰形与炮位验收](JP-FLEET-ESCORT-EXTERIORS.md) |

四舰共安装 40 组外观用独立炮位。按 **G** 可逐座检视、水平旋转、俯仰、复位，不影响相邻炮位或船身。数量是本批外观网格的计数，不是原舰军械表；都没有接入战斗逻辑。战斗机没有虚构炮塔；两架海航飞机闭舱展示，没有添加后席动力炮塔。

展厅回归：37 舰、17 机可加载；炮位测试 1,293 项零失败。新增模型只验证展厅所见外形与运动。
