# 舰炮：独立炮位和游戏边界

- 展厅入口：运行 `showcase/archive_gallery/viewer.tscn`，选舰按 **G**，在面板逐个选择炮位。可试水平旋转、炮管俯仰和单炮位复位；切换选择会保留其它炮位姿态。
- 16 艘独立外观新接 105 个已有炮位的真实网格。每个炮位有自己的回转节点和俯仰节点，炮座不被拖动；旋转以原始对齐姿态为基准，归零不改原外观。
- 6 艘原有带炮战斗舰也在同一展厅检视。11 艘只有空舷台或轮廓道具的展厅航母提示无可用火炮网格；本轮不凭空添加炮管。
- 展厅射程是无单位的玩法档位，角度是检视限制，不是实装军械数据。独立外观模型依旧不加入战斗。
- 在已有游戏战斗中，每座炮位保持自己的角度、冷却和独立状态。虚构场景的同类型默认配置可以按炮位再缩窄；可用字段为 `range_scale`、`train_window_deg`、`minimum_elevation_deg`、`maximum_elevation_deg`。指派与实际游戏开火同读此限制，而不是只把面板上的滑块改窄。未扩大既有配置或新增火力数据。

## 验证

- `tests/model_audit/test_archive_gun_rigs.gd`：全展厅 33 个舰艇，其中 22 艘有独立可检视炮位；含 105 个新增炮位的独立性、复位、边界和非有限输入检查。
- `tests/test_mount_game_envelope.gd`：炮位级范围与角度约束、相邻炮位不受影响、错误参数不能改写会话。
- `tests/test_naval_target_allocation.gd`：现有游戏回归通过。原有单舰外观数量和船体检查继续保留。
