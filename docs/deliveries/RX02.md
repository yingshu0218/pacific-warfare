# RX02 自由观战、同帧跟随与远景修复

2026-11-12。公共源码修复及机制／必要原生取证完成；普通白名单更新、最终构建和Chrome复验由统筹执行。本任务没有启动Chrome、HTTP或后续长期性能测试，没有替换已交付普通包。

## 实际原因与修复

自由移动原本被Shift门控，未映射方向键；菜单未消费的按键还能从第二条无保护的`_unhandled_input`路径进入相机。右拖基线已有完整水平旋转，不能说原来完全没有旋转实现，但俯仰受限、接管/焦点与提示不足。

现在画布右拖可原地环视，WASD/方向键在水平面平移，QE升降，Shift为4倍加速；滚轮前后缩放并按距离调节移速。跟随中右拖绕主体，移动键接管自由视角。失焦、切模式、重开释放按键/拖动；菜单和文本焦点、弹出菜单仍保留自己的输入。自由相机不再被导演视线抬升或整舰粗包围球突然推远；眼点保持真实地形/海面以上8米。底部有常驻操作提示，按钮有详细提示。正常操作先点击画布，或点击“自由观察”；C恢复自动。

跟随抖动来自模型直接使用60Hz末tick快照，而相机另对世界位置做滞后平滑。新增唯一只读尾部采样器`pose_history.gd`，保存相邻两tick姿态，按实际累积器alpha做位置与四元数插值，同帧供模型、焦点、后坐、尾流、碎片和效果使用。相机只平滑相对环绕量，不滞后追赶主体世界位置。真实UnitState、60Hz、油弹、RNG、指挥与损伤未改。暂停保持已显示的分数tick姿态，倍速/积压不外推，重开与切场清空历史。

显示通常落后真实状态最多一个固定tick。挂弹槽在实际END-tick出生前保留，离架体到该时刻才出现；新碎片和断翼掩码同样延迟到实际显示出生。FirstPlayable后坐/效果/相机的事件队列只显示已到达同一表现时刻的事件，Session/HUD/统计仍读取真实事件。RX01/统筹已把既有炸弹视图接到`presentation_bombs`；RX02未覆盖其效果、弹丸或损伤模块。接口见[表现时钟交接](../showcase/RX02-presentation-contract.md)。

远景缺岛来自实际CloudSea的连续y=0海面与低海拔地形争深度，关闭海面或提高近裁面后恢复；不是波浪顶点位移、岛体AABB消失或旧assets/ocean shader。保留真实地形/碰撞/海平面，按同源海岸多边形从海面网格裁除陆地区域，递归拆分仅用于处理多边形孔洞；不造陆地偏移、不用粗栅格遮罩、不增第二遍渲染。最终417个水面三角形、85个叶单元；低于2毫米高度的浮点共线薄片不栅格化。近裁0.06米下七岛也不再被海面覆盖。Godot关于[深度精度](https://docs.godotengine.org/en/stable/tutorials/3d/3d_rendering_limitations.html#depth-buffer-precision)与[多边形裁切孔洞](https://docs.godotengine.org/en/stable/classes/class_geometry2d.html#class-geometry2d-method-clip-polygons)的说明与实际对照一致。

## 实际交战与新增舰损界面

原港湾固定路线常把实际火力放在20–23公里外，甚至不在视锥内。普通expanded现默认“港湾实战观战”，复用只读事件相机，增加舰炮实际发弹响应，大口径主炮可打断较低优先级镜头，同优先级齐射保持停留。“实际交战”按钮恢复事件镜头，“港湾导览”显式进入地图路线；右拖、移动和手动跟随随时接管。没有改变场景态势或安排射击/命中。

按RX01交接的真实字段，单位详情显示浮力、动力、操舵、火控及炮位降效/失效数量；失能漂浮、沉没中、已沉没分开。战报新增默认0的`sinking`，旧`sunk`键保留：sinking事件只计沉没中，船体达到RX01实际下沉门槛并进入wreck终态才计已沉没。飞机接触结果沿原DM消费。

- 地图原生：同视角近裁0.06/0.8/4/16米、海面开关、远/近/总览及16帧小幅移动，见 `map-before` / `map-after-r1`。未改地形顶点、轮廓或承载。最终网格陆地内部质心0，数值交叠总面积0.0264平方米（沿毫米级边界，低于1平方米容差）。地图对照实际渲染图1152×720，保留根项目原16:10逻辑尺寸与窗口缩放，不能误写成1280×720内部画布。
