# B25G01 · B-25J 背部双联炮塔

2026-11-19。B-25J 炮塔已在港湾、舰艇轰炸和零战截击三个普通 Showcase 段落接入。Godot 4.7.2 原生画面与机制已验证。统筹已在 Ego Lite 复核正式 Web 包中的双向交火。[合并验收](2026-11-19-bomber-review.md)

## 运行行为

- AV04 模型原有独立塔座方位轴、枪管俯仰轴和两个枪口标记。此前 B-25J 战斗编目没有武器，观战适配器只应用飞行和炸弹舱姿态。本次为背部枪塔登记一座双管挂点，每架飞机有独立的炮位状态和逐管库存。观战适配器把模拟角度传给原模型。
- 空中防御从美军自己的有效、新鲜接触中选取可用空中目标。现有武器执行器负责转动、射界和遮挡检查、冷却、扣弹、发射、碰撞与伤害。无接触、接触过时、超出游戏范围或角度、停火、弹尽、枪位或飞机失能、地面接触时，炮塔停止发射并保留上次姿态。机场检视使用原有静态停放模型。
- 现有 `fired` 事件分别携带两管的真实枪口位置、角度及弹道，并驱动闪光和既有频率的曳光。空中交战镜头可根据该事件跟随开火的轰炸机。单位详情可查看枪位状态和目标，原有弹药统计计入该枪位。
- 单独轰炸段的两架 B-25J 投下 12 枚炸弹并产生 12 次爆炸事件，完成投弹后的拉起动作，背部炮塔发射 0 次。该段实际有舰上防空，进攻与退出仍经过原有任务及受损规则。
- 港湾只调整 B-25J 长机的初始高度（1800 → 1640 m）。僚机以原高度入场，两架都在正常接敌中取得新鲜接触。专项截击保留长机 1800 m，僚机以 1720 m 入场，零战在 1950 m、离原位置更远处开始接近。首轮候选过早开火，重放中零战未及还击。修订后开场留出选机和跟随时间，随后双方依实际接触和指挥交火。
