## 本轮结果

- 舰船分开作战结构与浮力。上层建筑、火控与炮位受损可降效、失能并继续漂浮；真实水线破口及进水才消耗浮力。动力、操舵、火控及独立炮位消费各自实际状态。失能、沉没中、完全入水后的损失分别统计。炮塔部分损伤会减慢实际转动/装填，火控受损影响真实解算，不是仅改文字。
- 旧港湾大和33.65秒因水线上伤害耗尽结构就沉没；同初态修复后148.567秒作战失能，300秒仍有浮力4125.33。另一受控重舰对抗持续到衣阿华191.033秒失能且漂浮；重炮对驱逐舰仍可能一轮造成致命舰体破口。它们是特定条件样本，不是保底生存时间。完整20–40分钟场次仍为后续目标。
- 默认观察真实交战，显式“港湾导览”保留地图路线。实际主炮弹体按物理发弹和终止事件显示，真实防空射击产生曳光/空爆；没有安排命中、损失或定时火网。仍有384实例上限，压力下回收旧烟，极远的小口径弹迹不保证清晰。
- 自由观察右拖原地360环视，WASD/方向键平移，QE升降，Shift四倍加速，滚轮缩放/调速。跟随右拖可环绕，移动键接管；先点画布或“自由观察”，C恢复自动。菜单和失焦不再泄漏移动输入。
- 末tick只读插值统一模型、镜头、挂弹/离架体、残片及效果时钟，修复跟随主体跳步。海面按同源海岸线裁除陆地覆盖，修复低岛被连续海平面遮盖；未改地形高度或碰撞。

具体模块参数、功能试验及相对角色样本见[RX01](RX01.md)，相机/海面/表现时钟见[RX02](RX02.md)，产品约束见[交战节奏与单位作用](../showcase/combat-pacing.md)。本轮不扩展逐舱、供电网络、损管、延时穿甲或航母独立飞行甲板毁伤。
