# FLIGHT01 · 自由飞行的机头推力与速度惯性

原来机身纵轴每帧直接对齐速度方向，推进只改变沿航迹的速度。这次保留原有配平、转弯、升力、阻力、重力、载荷和地形保护逻辑，把自由飞行的机体姿态和速度分开：发动机沿机头施力，四项合力更新原有速度，再从速度得到航迹。机身保留小幅配平差和有限姿态变化，不直接跟随导航目标转向。该模型服务于游戏动作，不是按真实飞机空气动力学完整标定。

航母起飞、正常出动回收链和近甲板进近保留原来的验证包线；不把自由飞行的改动混入轮胎接触、拦阻或甲板复位。未改射击、命中、任务决策、原有模型和观战镜头。

## 验证口径

- 同姿态与速度只改油门，直接比较下一步世界速度，隔离发动机贡献。另测拉升、俯冲、斜向拉起、失速、低空保护、接近竖直及无油滑翔。
- 以独立原生对照场景录同输入的旧版和新版。画面固定观察方向；叠字来自真实姿态和速度，不修改飞机运动。
- 原生测试不代表 Web/Ego Lite 或 Mac 性能。
