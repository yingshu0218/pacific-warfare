# 青岬 QJ03：三维云层

青岬新增独立的世界空间云层。远景天空仍负责天穹，近处积云有固定的高度范围和实际厚度，地面能仰望云底，低空能从云层下方掠过，高空能看见云顶与下方海岛重叠。使用同一套世界坐标和确定性云纹；相机移动不会带着云走。

云层只在表现层。关卡按绝对表现时间驱动风移，暂停与重开可沿用同一个时钟。兼容渲染用深度缓冲约束采样距离，近处岛体、场景物件不会被错误盖住。不为云层创建碰撞、天气玩法、探测或伤害参数，不投实时云影。

验证组件参数、时间重置与场景实例隔离：

```bash
godot --headless --path . --audio-driver Dummy --script tests/qingjia/test_cloud_volume.gd
```

兼容渲染器的实机检查使用同一场景、同一镜头对云层做开／关对照，覆盖机场跑道、低于云层、云层内部和云层上方四个高度。近地画面的跑道没有被本层误覆盖，俯视时还能看清云与海岛之间的层次。组件回归 10 项通过。
