# SB2C-4 首轮造型验收

结论：不通过；修订 SB2C 后再验收，暂不进入 G4M。

检查依据：交付的前斜视、侧视、俯视、腹视截图，与 `docs/references/bombers/sb2c/extra_09.jpg` 实际对照，并读取模型尾翼/座舱生成代码。

1. 垂尾为弯钩状多边形，缺少参考中的圆弧轮廓；尾部组件存在可见分离。核对坐标约定、点序与三角化，修复真实连接。
2. 温室座舱被拆成间断泡罩，缺少连续舱口与背部过渡。明确开闭状态，修正网格与框架。
3. 主翼和平尾俯视近椭圆叶片，应重采样参考中的前后缘、外翼收尖和翼尖轮廓。
4. 后机身过于细薄，座舱下方与尾部高度过渡需重校。
5. 腹部炸弹缺少可辨的舱口与可信托架连接；尾轮支柱、尾钩比例需参考核对。
6. 截图过暗。重拍中性补光下的干净轮廓，以及挂载、弹舱、减速板细节。附参考与模型同角度对照。

先修整体大形，再修细节。浏览器实测当前暂缓，不作为本轮拒收原因。
