# PORT04 · 民港与军港码头精修

- 将民港、军港的 10 段旧码头与防波堤按区域和标高合并为无重复顶面的网格；阶面、外侧墙和分层水线使用同一份布局。民港用较暖的旧混凝土色，军港用偏冷的灰色；远处淡出板缝。
- 在临水边沿放置护舷和系缆桩，不向内陆边沿重复摆放。拖船增加前舷墙、窗框、护胎吊点和前甲板细节；驳船增加护条、系带及甲板装卸细节。
- 解决民港平台与地表争抢显示：只在两港码头包络内、接近或低于平台高度的地表片元作裁切，较高坡面保留；港区的两条贴地道路单独绘制，不投射或接收会造成条纹的级联阴影。机场、旧地图和其他道路不进这条绘制分支。
- 不修改地图源数据，不改航路、碰撞、安装点、地面战斗、机场资产或船只行为。仍然只有外观。

## 复核

Godot 4.7.2 Compatibility 原生：民港两处接近机位、军港、两艘工作船原生前后图。机制检查 `godot --headless --script res://tests/test_refined_quays.gd` 共 250 项，核对联合覆盖面积、顶面唯一性、朝向、使用范围、道路和原图 245 个固体/7 处部署点；`godot --headless --script res://tests/test_harbor_support_props.gd` 核对 15 个道具及 4 个展示机位。码头本批 14,788 三角面、197 处临水细节组，批成一个网格；港区道路漆面另一个网格。未测 Web 或 Mac 的实时帧率。
