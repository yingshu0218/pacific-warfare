# TRACER08 · 空战曳光可读性

- 旧效果对已经由模拟标记的空中曳光又按事件序号筛选，可能抹掉整段短点射。取消飞机来源的二次筛选，仍只显示模拟标记的曳光，不让普通弹发光；地面防空筛选和舰炮外观不变。
- 飞机曳光为亮芯、暖边和渐隐短尾。按观察距离补偿屏幕宽度，设世界尺寸上限。只画当前弹头后最近 33 毫秒的轨迹；弹丸结束马上撤掉。不修改火控、弹道、伤害或碰撞。
- Godot 4.7.2 Compatibility 原生固定机位 A/B：原有 F6F 截击 G4M 场景，11.50 到 14.65 游戏秒，64 帧；前后捕获的 82 条开火和 13 条命中事件逐条一致。画面对比确认飞机之间的短曳光可读。FX01 36 项、FX02 30 项、防空 51 项通过。未进行 Web 渲染验收。
