# QJ03 · 青岬群岛重做

用全新四岛海岸和山体曲线替代旧构图；QJ02 文件保留为回退。这里是虚构的港城岛屿，建筑风格按时代氛围设计，不复制现实地点。

- **主岛**：北侧错落山脊、南侧连续海岸平原；机场、镇区、码头均由同一地形和道路连接。
- **港口**：东湾两座明显分开的码头，北侧为驻泊摆设，中央为货物码头，设成组的货栈仓库、工棚、吊设施、木箱和小船。民用小渔船另有轻型木栈桥。
- **机场**：同一沿海平原有跑道、道肩、机坪、机库、人员/维修建筑和有木箱的独立货运小区。
- **居民区与山腰**：街区内有 28 座住宅与店面，采用木柱、灰瓦、外檐和临街铺面，另有诊疗所、消防所、民用物资仓；山腰神社由步道、石阶、鸟居和石灯笼构成。
- **外海**：三座不同高度、尺寸和轮廓的小岛；沙滩、窄礁池、树林和近空有高度的云层是同一 Godot 场景。

## 入口

运行 `scenes/qingjia/qj03_archipelago.tscn`。通过下拉选择群岛、机场、港口、双码头、镇区、神社、高空和三处民用公共设施；1–9、0 可跳到前十个机位。右键拖动，WASD 移动，Q/E 升降，H 隐藏控件。

```sh
python tools/build_qj03_archipelago.py
godot --headless --path . --script tests/qingjia/test_qj03_archipelago.gd
```

岸线、三角形地表、港区/建筑实体和观察机位都来自 QJ03 自己的数据文件。相机碰撞避让和高度检查用同一地形。本交付是独立地图检视，不更动旧战局、武器规则或自动敌我路线；未接入 QJ03 独立实战挑战。海岸旧构件仅作静态装饰。
