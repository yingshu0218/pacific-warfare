# 双舰指挥链原型

Godot 入口 `showcase/command_lab/deck_lab.tscn`，独立于地图和对局。它操作虚构演练票据，不操作单位、航路、武器或实船设备。步数是 UI 演示而非实际作业时间。

舰队指挥官签发，航空指挥官分配，编队长提交回收请求，舰长控制甲板可用性，每艘舰的调度岗只执行本舰队列。记录中能区分签发、分配、接管、等待、放行、完成、过期。每舰同一时间最多一个活动事项；玩家接管保留现有队列，交还或切换销毁旧权限，不影响另一艘。关闭甲板拒绝新事项；若另一舰可用，航空指挥官可以改派尚未执行的票据，已开始事项不会强行中断。首版只允许一张舰队示例任务；重置可再次演练。

测试：`godot --headless --path . --script tests/command/test_deck_board.gd`。覆盖队列、单舰隔离、重复请求保护、旧权限拒绝、关闭甲板、等待事项改派、优先回收、超时。实际飞行、自动编队、战斗接入均不属于此原型。
