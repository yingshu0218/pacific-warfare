# PORT09 · 青岬军港高地三联装

青岬港湾和「青岬空袭」的军港高地既有阵地替换为海军九六式 25 毫米三联装。勤务区保留九六式单装，陆军机场仍使用九八式。没有增加阵地数量或改变阵地位置。三联装采用共用支架和原有低多边形炮身，参考 [Australian War Memorial 馆藏 C238576](https://www.awm.gov.au/collection/C238576) 的总体外观。为架空港口的游戏表现，不是史实原址复原，也未新增现实武器性能参数。

Godot 4.7.2 Compatibility 原生验收：青岬正式入口成功；三管模型接口分别与各自的模拟枪口对齐；三个模拟枪口均在受控场景内实际开火。地面模块 48 项通过，正式青岬空袭仍有护航、拦截、12 次投弹和 9 次机场区爆炸。Web 运行清单登记了两个新增资产，未实测浏览器。
