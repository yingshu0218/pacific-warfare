# PORT05 · 青岬港城灰模

第一阶段规划预览。启动 `res://scenes/map02/harbor_town_review.tscn`，用下拉菜单或 **1–4** 切换总览、海面、坡上、主街，**H** 隐藏面板。

- 保留现状岸线、军港两突堤、PORT04 岸壁和临水道具。在旧修理棚旁用两处灰模货场把船厂工作带的关系表达清楚。
- 港镇在同岛西坡脚。低处主街保留可走通的转弯，用两排店屋围出小市场；支路下行到独立的小渡口，不借用现有码头泊位。
- 坡地住宅按山地采样落脚。路面跟随原地表，过陡、压街或相交的候选建筑不建；单体用小基座补齐落差，不整片削山。最上层步道继续向上，不把房子堆到山脊。
- 灰模是独立检视场景。没有接入默认战场，没有新增碰撞、导航或作战设施。未改原地形、机场、现有民港。现阶段屋顶和色块仅用于辨识体量，不是最终材质。

## 原生验证

Godot 4.7.2 Compatibility。`godot --headless --script res://tests/test_harbor_town_review.gd` 校验住宅/店屋/货场数量、落地、主街坡度和四个视角；原地图保持 245 个固体和 7 个部署点。另从该正式检视入口截取四张原生图。主街构造按地表采样，较陡的连接段仍需在工程化阶段单独验坡，不作为无障碍、机动车或模拟通行验收。未测 Web。
