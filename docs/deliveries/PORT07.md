# PORT07 · 青岬港湾日方地面防空

正式 `showcase/carrier_harbor.tscn` 新增三个实装单位：军港勤务区、军港高地、野战机场外围。使用地图原有预留点，机场跑道、民用渡口、城镇、旧岸炮预留位置均不改。每组有自己的模型、任务、弹药与战损状态，直接复用项目既有地面控制和模拟事件。美方原有三组及其他舰机不变。正式港湾从 27 增至 30 个模拟单位。

地面阵地底座为游戏用外观，不是历史复原；编目日期代表游戏剧本时点。武器用项目现有轻防空定义，未重写武器参数、弹道、舰艇设置或地图路网。绝不把测试机装进正式场景。

## 原生核验

Godot 4.7.2 Compatibility。`godot --headless --script res://tests/test_jp_harbor_ground_defence.gd` 验证正式入口启动、三处原有站点对齐、模型和各自任务。在三个独立的 QA 战局中，每组都自行进入任务并发出实际的 `fired` 事件；未保证默认战局每局都会有敌机接近所有阵地。正式场景原生截屏用于确认装配位置。未测 Web/Mac 表现。
