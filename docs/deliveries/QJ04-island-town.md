# QJ04 · 青岬岛镇与东港

QJ03 海岸轮廓、四岛、云层和机场保留为底图；QJ04 重做道路、城镇地块、东港混凝土扩建和山上设施。QJ03 的入口与数据不变。

- 从机场到东港的主路沿地形走，集市弯街、沿海住区、内街、坡道和小径在真实交点连通。84 座临街房屋按所在街道布置朝向与退距，院口可连到街路，不再排成平行四排。医院、消防所、民用货栈辨识与进出路保留。
- 东侧深水湾增加连续混凝土作业区、岸壁、标线、货栈和堆场；独立的渔船木栈桥留在小镇一侧。
- 山路经过邻里、供水小屋与山间气象站；神社有单独的参道、石阶、鸟居、拜殿、院落和附房。两处外围展品分别采用压叠圆沙袋和混凝土外观，不是功能性防御设施。

运行 `scenes/qingjia/qj04_island.tscn`。下拉菜单浏览 13 个视点。WASD 移动、Q/E 升降、右键拖动，H 隐藏菜单。模型外观和路网可检查，但未迁移模拟战局或接道路车辆 AI。

复验：`python tools/build_qj04_island.py` 重新生成场景数据；`godot --headless --path . --script tests/qingjia/test_qj04_island.gd` 验证全网相连、街屋朝向、山地设施、港区及视点。
