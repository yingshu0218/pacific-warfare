# FX02 舰炮、命中与空爆烟效

2026-11-19。默认港湾已接入并完成原生画面和机制复核。浏览器集成由统筹在普通 Showcase 上用 Ego Lite 复验。

## 实现

- 舰炮逐管读取实际 `fired` 事件。位置是炮管世界坐标炮口，`muzzle_direction` 是含散布的世界发射方向，弹道速度另含射手运动。短焰与烟独立，主炮有两层炮烟，副炮与较大防空炮一层。炮烟在炮口前方涌出，随后留在世界坐标中缓慢抬升、扩张和淡出。
- 重炮打中舰体时显示亮芯、短碎火和深灰留烟。岛面与建筑撞击使用贴地混尘，较大撞击带上层烟。实际落水继续生成水柱、水雾和泡沫。普通子弹命中使用小火花，弹丸寿命终止清理弹迹。
- 防空定时引信在真实空爆点形成三团深灰黑烟。各烟团从同一点沿不同方向膨胀并淡出。40 mm 自毁为短闪和单个小烟团。炮烟、撞击烟尘和空爆共用海云的 XZ 风向 `(0.84, 0.54)`，常规烟的平流系数为 2.7 m/s。起始喷发、浮升与寿命为表现参数。
- 特效使用仿真时间。暂停和切换镜头保持烟的位置和透明度，重开清空效果并复用网格与材质，迟到事件按原始时间戳补龄。事件按场次和序号消费，实际弹丸结束时按弹丸 ID 消除弹迹。武装炸弹的接触与爆炸由后者统一触发一套效果，未武装接触走普通弹着路径。
- 复用既有 384 格运行池。饱和时炮烟／短焰、重炮弹迹、小型曳光在有需求时分别可保有约 18%、8%、12% 的容量，其余实例共享。主炮与烟团使用现有网格和 Compatibility shader，未增加运行资源路径。模拟状态和弹丸事件由原系统产生。
