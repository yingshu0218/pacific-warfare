# QJ02 · 青岬群岛：峡湾港城

青岬是本项目原有的虚构太平洋群岛。此次把群岛地形、峡湾军港、东岬机场和居民小镇放在同一张 Godot 地图里，不改原有青岬归航和港湾入口。项目内沿用已有写法「青岬」。

## 打开成品

- 海陆空测试：在 Godot 运行 `showcase/qingjia_geography.tscn`，测试配置沿用既有港湾场景。导览菜单里的「青岬群岛 · 海陆空试玩」可以重新载入此地图。
- 纯地图检视：运行 `scenes/qingjia/geography_review.tscn`。按 **1–7**，或从落地视角菜单选择：群岛全景、峡湾入口、军港泊位、东岬机场、小镇与渡口、主街与居民、驻泊舰近景。**WASD** 移动，**Q/E** 升降，右键拖动观察，**H** 隐藏面板。

## 此次增加

- 在北面的军港岛上延展连体西岬，东面加一座形状和方向不同的双峰岛。西岬、东岛之间保持全程可通的水面，峡湾深处是军港。
- 复用原有军港岸壁、两座长泊位、吊机和维修建筑；增加高雄、阿贺野两艘驻泊舰外观作静态布景。
- 保留东岬既有跑道和机库，补上道肩、停机坪静态飞机与岸边植被。跑道仍沿用同一套地面高度。
- 保留港镇街道、坡地住宅、市场及渡口，新增 15 个居民剪影。居民、泊位静态舰和停机场景道具不会注册为作战目标。

## 复验

地图由 `python tools/build_qj02_geography.py` 根据 MAP02 和港湾测试配置生成。新版地形、模型的海岸和地面碰撞从同一地图读取；没有单独画一套仅供看的地面壳。

```sh
godot --headless --path . --audio-driver Dummy --script res://tests/qingjia/test_geography.gd
```

验收检查运行入口、海陆空单位加载和推进、连体岬和峡湾水域、地形/海面碰撞、跑道高度及环境布景。本次没有重做战斗逻辑、城市居民系统或机场起降流程，也未调整上一版港湾的测试单位配置。
