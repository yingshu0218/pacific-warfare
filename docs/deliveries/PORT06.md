# PORT06 · 港城细化并接入正式青岬场景

- 将港镇从独立灰模提升为 MAP02 地图共享的正式静态景物，覆盖 `showcase/carrier_harbor.tscn` 和同图的演示；独立港镇检视也读同一份景物，不会叠加第二份。
- 从渡口沿坡上行，补三处路旁小台地和短连接坡面，石质台基随地表调整；中上段加入店面、遮棚与窗，低处保持建筑稀疏，避免挡海面看入镇的视线。
- 保留主街、市场、坡地民居分区和两处船厂货场。建筑细化到屋檐、窗框、立面和烟囱等观战可辨的尺度；仍为哑光低面数外观。
- 「地图定位」可直接切换西侧渡口、市场与主街、坡地住区。原有九个图表视角仍在，新增面向观战的三个选项不会改写真实模拟地图数据。

## 验证与边界

Godot 4.7.2 原生 Compatibility。先检查独立检视，再在正式港湾入口核对同一份港镇、码头数据、三个菜单镜头和场景重置无重复。继续运行 PORT03/04 回归。全部新增为静态可见装饰，无新碰撞、航路、战斗或机场改动。地表坡度与建筑落脚经过游戏几何采样，不是施工或车辆通行规格。未测 Web/Mac 性能。
