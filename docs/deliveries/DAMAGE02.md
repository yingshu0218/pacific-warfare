# DAMAGE02 · 空战分区损伤与失控轨迹

- 修订当前 F6F-5、A6M5a、D4Y2、G4M1、B-25J 游戏战斗配置。座舱是独立、与机模对齐的区域，普通机腹及机尾命中并不算直接命中座舱。G4M1/B-25J 两侧发动机的损伤、烟源与螺旋桨转速独立；坏一侧仍有部分推力，并产生渐进的滚转偏置。单发机失去动力仍可滑行，不会凭空解体。
- 尾部命中先降低可用操控，普通尾部功能丧失不自动切掉尾段。普通累积结构耗尽可令飞机失控；只在现有翼段结构失效、灾难性结构损伤或高速撞击时生成对应碎片，不用一次普通命中触发全机解体。
- 进入失控时继承速度和角速度，剩余机翼仍有升力，附着尾段仍提供稳定作用。碎片从各自已装配姿态分离，初速度包含旋转造成的切向速度。入水位置按步内交点确定，入水后速度衰减。没有引入真实飞机的脆弱性或火控标定。
- 限于游戏中固定前射机炮向空中目标射击的散布，仍要求弹丸经过碰撞体才计命中；不改船炮、地面防空或轰炸机防御炮塔的射击参数。固定种子 707、45 秒的原截击场景：110 发 39 中（35.5%）→ 126 发 22 中（17.5%），为场景样本而非全局命中率。
- Godot 4.7.2：108 项损伤/惯性/碰撞检查、8 项烟源位置检查、24 项武器循环检查、68 项训练保护检查通过；四个截击高度样例与正式青岬空袭原生回归通过。受控实机画面：B-25 六次尾击后可飞；G4M 左侧失效；B-25 座舱失控后保持机体附着，实际在 26.0 游戏秒以约 89 m/s 前向速度触海，触海后生成碎片。未进行 Web 构建或完整空战影片重录。
