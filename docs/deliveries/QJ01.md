# QJ01 · 青岬归航：双机回收与战报

2026-11-22：实现完成；统筹已用 Ego Lite 验证从正式港湾进入青岬、打开战报和重开。本次界面收尾在本地 Godot 4.7.2 Stable（`4.7.2.stable.official.ed1daf0bf`）通过 headless 验证，未重新导出或替换正式包。范围见[执行卡](../showcase/briefs/2026-11-21-qingjia.md)。

## 正常游玩

打开原有 `showcase/carrier_harbor.tscn`（默认「港湾实战观战」），从左上场景下拉选「青岬归航 · 双机回收」。简报给出点名双机、窗口、东侧外海撤离区的距离（或已到区），以及已回收且仍在舰的架数。相机和单位下拉初始都选埃塞克斯，也可手动跟随任一飞机或用自动电影；不需要发令。随时点「战报」查进度，到终态会打开战报；「结束」可提前中断，「重开」从同一初态重来。打包白名单另登记了独立调试入口 `showcase/qingjia.tscn`，未替换任何默认入口。

战报开局逐机显示「在埃塞克斯甲板，尚未起飞」；后续只列实际发生的起飞、回收时刻和当前去向。复飞、已确认损失及失联前最后可知状态与时间仍保留；指令 ID 和精确舰位、撤离区坐标留在原始证据和诊断数据，不显示在玩家战报。

## 规则与边界

- 场景初始经通用命令入口下达双机巡逻与母舰撤离；双机按甲板放飞、完成集结后的值勤、回收窗口及油弹伤情执行。巡逻值勤参数不等于开局返航倒计时；窗口只用于结算。港湾其余单位仍由各自通用规则运行，未改武器、起降门限或操纵逻辑。
- 仅统计指定母舰 `us_cv` 上的 `us_deck_1` 与 `us_deck_2`；分别关联本次波次 `qj01:wave:01`、机体自己的出动序号、实际离舰及停稳入位事件。到区时仍要确认在同一母舰的甲板上、且仍是该次出动。重复事件不加计；起始停放、仅接令、仅触舰、复飞、再出动和异舰落甲板均不等于随舰撤出。
- 模拟步内先消费作业事件、读取损伤与最新状态，再结算。优先级为母舰进入不可逆沉没／已沉没 → 母舰实际进入撤离圆（含圆周、含截止步）→ 截止仍未到区。失能但尚浮的舰若确实漂入，仍按实际到区检查。到区 2/2 完成，0 或 1/2 为部分达成；沉没、超时未达成；手动提前结束只记录中断。结算冻结在该步，不继续推进，去向未明保留最后可知状态与时间，不臆断为损失。

## 自然样本与验证

种子 `707` 使用与菜单相同的场景和 `FirstPlayableSession.load_battle()`，不注入位置、指令或战损。两条初始命令都在第 1 步接收。青岬一号于 **00:22.750** 离舰、**06:43.567** 回收停稳；二号于 **00:52.217** 离舰、**11:42.550** 回收停稳。埃塞克斯在 **11:56.667**（第 `43000` 步，截止 `43200` 步）仍可战，实际到达 `(21250, 9500)` 米的撤离区圆周，双机仍在舰，结算 **2/2 随舰撤出**。此时舰队撤离令仍在执行：任务按首次实际到区结算，不等舰队系统减速停船，也不等二号完成整备。[原始自然事件与终态](../showcase/evidence/QJ01/natural-707.json)

- 受控案例覆盖重复及失联、无真实出动、非点名、再出动、异舰、截止步同帧回收、晚一帧、沉没优先、手动中断及重开；这些分支不是该发布配置自然样本的结果。调参时另一次自然到区只回收一架，二号因舰减速造成甲板风不足而复飞；最终只调整了场景撤离区和窗口，未放宽甲板规则。
- 原生 headless 菜单测试实际实例化默认港湾，验证 27 单位、进入青岬及其 12 单位、打开战报和双机点名、结束和重开、返回港湾、训练及单机自主空战入口。
- 界面收尾验证 `20261121T162315-5223ca54`：青岬首次进入／重开时下拉与母舰跟随一致，手动选机不被刷新覆盖，返回港湾仍用原默认单位；检查初始双机文案、撤离区距离／到区状态及后续时刻、复飞和损失提示。既有 S07 观战 UI 回归也通过。
- 固定步时钟、命令校验与生命周期、既有 S07 观战 UI 的回归也通过。验证记录 ID：`20261121T161042-1160105c`（受控）、`20261121T161254-8a040b6e`（菜单）、`20261121T161416-1167b8a5`（自然样本）、`20261121T161510-ebddfe9c`（既有回归）；运行记录用 UTC，因此 ID 日期与本地验证日期不同。
- 验证通过项目的 `tools/verify.py` 串行锁与超时执行，使用只在临时验证工程生效的系统证书覆盖和独立日志，避开本机沙箱对系统钥匙串及用户日志目录的限制。测试脚本在 `tests/qingjia/`；自然样本复验通过 `godot -- --script res://tests/qingjia/test_natural.gd -- <输出路径> complete` 传入期望终态。
- 本轮未启动浏览器、未更新正式包；正式页面实际排版、实时表现、声音和性能不在本地 headless 结论内。PF01 的性能基线仍是原有 27 单位普通港湾，不使用青岬样本代替。
