# PORT03 · 港口和机场勤务道具

在青岬扩展地图增加四组原创简化景物。延续游戏的低光泽、克制配色和可辨剪影，不是历史船名考证或可操控单位。

| 道具 | 细节与布置 |
| --- | --- |
| 港勤拖船 | 圆尾、抬高的驾驶室、烟囱、沿舷护胎和尾部拖缆绞盘。民港、军港各一艘。 |
| 载货驳船 | 低舷宽甲板、货围、木箱、帆布盖货和缆桩。民港、军港各一艘。 |
| 航道浮标 | 红、绿两种色面与顶标轮廓，入口两组，共四座。 |
| 地勤维修组 | 牵引车、便携维修梯、工具推车、油桶与工具箱。两座机库前共七件，不占跑道和滑行道。 |

共 15 个实例、8 个复用模型；每个模型一个材质面，约 9,260 个三角面（按实例累计）。小件不单独投影，工作船保留投影。只接入绘制层：无新碰撞体、指挥单位、火力、活动船只或导航修改。原地图地形、码头和跑道未修改。

## 查看和验证

- 实战入口：`res://showcase/carrier_harbor.tscn`。独立地图：`res://scenes/map02/expanded_map.tscn`，下拉菜单最后四项是这批道具的视角。
- Godot 4.7.2 Compatibility：`godot --headless --script res://tests/test_harbor_support_props.gd`。使用实际港湾场景检查网格数量、复用、三角面预算、岸线与水线、既有设施、接地及检视菜单。另在同场景做了固定机位原生截图。
- 本轮未测浏览器表现或帧率；不将静态道具验收等同于活动船只或地勤作业。
