# OPS01 消费 S04 r10 舰载使用态

2026-11-11。原请求中的轮/钩/襟翼模型缺口已由[S04 r10验收](../../showcase/acceptance/S04-carrier-use-review.md)补齐。OPS按[正式几何契约](../S04-carrier-usage-contract.md)消费四份冻结候选，只在自己的私有stage替换。原型同高三轮、Y=-2.30接点、pitch=0停放和固定4.4m尾钩偏移已从当前运行代码撤销；旧机制归档保留为历史。

实际轮胎圆面法线、主轮两点至三点支承、9.6453°停放、1.203077m原点离甲板高度、实际钩鞋三维扫索和0–40°动态上偏均由CPU模拟处理。机体姿态也是物理状态，参与接触/DM；模型不单独旋转来遮掩低头碰撞。完整旋转桨盘、放下襟翼与机腹同时检查。宿主损伤按既有DM排除。

模拟纯状态位于`unit.module_data.carrier_ops`：`gear_down`、`hook_down`、`flaps_down`、`hook_deflection_rad`，构型请求相互独立。S04候选Adapter直接消费；OPS私有视觉类没有另一组轮/钩覆盖逻辑。每个录制样本保留实际可见模型与CPU轮/钩坐标误差，按6mm网格/浮点容差复核。

最终短段均从原始停放逐60Hz固定tick执行，预滚巡航只省略图像记录，不跳过模拟；15fps直接渲染，没有补帧。离舰22s、回收24s、复飞12s、错误低头硬触舰/重力倾转20s均使用最终r11同一S04模型与476项冻结输入。证据、来源、剩余边界见[接续交付](../../showcase/deliveries/OPS01-model-resume.md)。生产模型替换、S14/Chrome尚由统筹后续准入。
