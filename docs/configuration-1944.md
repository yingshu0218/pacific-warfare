# 选定状态：1944年4月改装后

> 2026-11-10 S02：本文件保留历次研究日志。当前39座游戏清单、修正后主副炮标高、模块宿主与真实炮口以 [S02交付](showcase/deliveries/S02.md) / [dated参考包](references/ships/yamato_1944_04/modeling-brief.md) 为准；旧69/75座说明、旧坐标与旧测试结论不作为当前状态。历史编制与专用AA游戏配置继续分开。

2026-11-10 制作规则：本文件保留历史编制及既有研究，不因游戏简化覆写。三座三联 460 毫米主炮和两座中线三联 155 毫米副炮的编制及位置固定，所有现有估位仍待核实。专用防空炮数量可按游戏需求单独配置并记录差异，当前尚未选定新数量，也未修改武器数据。舰体、上层建筑外形和主副炮位置须按[军舰规范](standards/ship-modeling.md)验收。

依据：Janusz Skulski, Battleships Yamato and Musashi，预览PDF印刷页23–24（PDF25–26页）。https://api.pageplace.de/preview/DT0400.9781472832221_A35506816/preview-9781472832221_A35506816.pdf

本轮采用：三座三联460毫米、两座三联155毫米、十二座双联127毫米、24座三联25毫米、26座单装25毫米，共67座。该专著记录春季25毫米合计98管，7月增加五座三联。此前百科来源的32座三联不再作为模型基准。13毫米机枪是否在选定状态保留、确切阵位仍需复核，不计入已完成范围。

六座有防爆炮盾、六座开放式127毫米炮座需要区分。当前已区分几何，但哪座对应哪种以及所有临时位置仍待带日期图纸核对，不能将当前分配视为历史坐标。

主炮几何以美国海军技术调查 O-45(N)《Japanese 18-inch Guns and Mounts》印刷页17为准：[报告PDF](https://www.fischer-tropsch.org/primary_documents/gvt_reports/USNAVY/USNTMJ%20Reports/USNTMJ-200F-0384-0445%20Report%20O-45%20N.pdf)。该页给出炮管中心距3.50米、炮轴前移3.250米、炮轴至滚道4.40米、测距仪基线15米；滚道内/外径分别为11.500/13.050米。13.050米只作为可见座圈的尺寸代理，不代表炮塔装甲外壳或甲板开口外径；此前13.5米近似值已撤销。副炮测距仪采用Skulski印刷页23的8米。外露炮管长度仍为估值，不能把全炮长度直接当作炮轴至炮口距离。相关值已移入weapon_profiles.json，供后续按剖面图校正。

双联127毫米炮两排布局参考：https://diamond.jp/articles/-/140187 所载松本喜太郎资料改装图。图注纠正了上排六座无炮盾的实际情况。模型12点按图像比例定位，平台高度仍估计；该图未明确到4月某日，尚需同期照片交叉核对。

检查方式：N切换炮位编号，编号与data/yamato_1944_mounts.json的id对应；Tab逐座选择。未校准的25毫米临时点位仍保留provisional标记，不因可显示编号而获得历史精度背书。公开改装图的小口径符号分辨率不足，不能据其盲目逐点描摹。

补入舰桥两侧双联13毫米机枪，两座独立炮座；总炮座现69。依据同书印刷页24及松本改装图的图注（13毫米四联标注应更正为双联）。精确日期、安装高度与坐标仍待同期照片确认；运动速率为展示估值，数据明确标注，不能视为历史性能。

Model Art公开样页（IPMS/USA评论所附第45页）：https://reviews.ipmsusa.org/review/imperial-japanese-navy-battleship-yamato 。完整图题是大和1944年6月至11月、武藏1944年6月至10月，不能当作大和4月全套点位图。图注对前主炮周围部分单装炮位的实际存在提出不确定性。仅用于共有结构交叉检查，后期新增点不得无条件移植。研究图片不作为项目美术资产分发。

127毫米炮座进一步按Model Art第45页共有平台俯视关系修正为错列两排，非横向整齐对齐。上排约x=±7.8m，下排约x=±11.5m；纵向坐标从整体图比例换算，不是原厂站位。图示日期晚于4月，故只提升共有平台关系可信度，仍待春季照片验证。

Model Art公开样页提供了O-45(N)调查图示线索；尺寸核对改以调查报告印刷页17为准。报告给出滚道外径13.050米、内径11.500米。程序将外径用于固定支承筒和转动下圈的可见比例代理；真实滚道剖面、炮塔装甲外轮廓和甲板开口仍未建模测绘。副炮支承延伸至甲板，保持固定基座与转动炮塔分离。

未定位的第26座单装炮默认隐藏几何，可按U查看临时复原假设。该节点保留运动接口和未定位标记；默认画面只展示25个从同期图辨认出的单装炮点位。文字编制与图示之间的差额仍未解决。模型不再把旧等距坐标当作可见确定炮位。

垂向基准按Skulski印刷页18的干舷值：艏10m、舯8.6m、艉6.4m；甲板在这三处之间仍用近似曲线。10.4m是试航吃水，满载吃水另为10.86m（印刷页11），不可混称满载吃水。当前水线采用10.4m几何检查基准，非复原某次出航载荷。

横剖面改为分层近似，区分36.9米水线宽与38.9米水下最大宽；底部采用较平的截面。它不是船厂型线，鼓包高度、甲板宽与艏艉过渡仍是估计。栏杆沿实际生成的甲板边缘布置；艉部航空轨道、弹射器、飞机与吊机随当地甲板高度校正，避免干舷修正后埋入甲板。

侧视检查修正艏部过早收底造成的球鼻艏断开：艏部与艉部采用不同的收底过渡。球鼻艏外形与连接仍为程序近似，尚不具船厂型线精度。

舰桥主体轮廓参考Tamiya 78030说明书印刷页12的步骤19/20共有结构，改为四层折角截面，前缘随高度后退；外伸平台采用削角轮廓。仅借用共有建筑外形，不移植该1945套件的武器编制。截面高度、宽度尚无原厂尺寸支撑，均保留估计状态。原始说明书链接见visual-study.md。

主炮前板增加三处几何炮口槽，前缘顶板留出俯仰缺口，内部补深色隔板，避免空壳透见海面。参考Tamiya说明书印刷页13步骤27的共同炮塔结构；开口尺寸和炮衣形状仍为估值。新增--capture --elevated用于45度仰角检查，不以该截图证明全部遮挡限位完成。

开放防空炮座补入随水平轴转动的叉形支架、炮轴端盖及操作座；枪身仍单独随俯仰轴运动。此轮仅补齐机械连接关系，支架与座椅尺寸为比例估计，尚待对应炮座图纸校正，不作为历史尺寸依据。

烟囱顶部补椭圆排烟口格栅，随烟囱倾角、椭圆截面和整体位置变换。参考Tamiya说明书印刷页13步骤24共有结构；格栅间距、杆径为比例估计，黑色内面仍简化表示内部深度。

复核Skulski/Draminski印刷页23，将127毫米最大俯角从展示值-7度校正为-8度。其他炮型速度及水平范围加入来源/估计状态；25毫米通用炮数据表的+90度与现有+85度安装限位尚未解决，暂不以通用表替代具体炮座限位。按印刷页25的两侧天线说明，将主桅单个梯形阵列改为左右两套，尺寸仍估计。

依据Skulski/Draminski印刷页25，将两座弹射器纵梁长度从18米校正为19.5米，补横向联系梁。桁架宽、高、节间分布及安装朝向仍是估计；19.5米不能为其余细节提供精度背书。新增--capture --stern检查艉部航空设施。

依据同期Modelkasten印刷页5图3（既有数字化裁图）修正弹射器：图中枢轴约像素(174,112)/(174,276)，换算约x=±10.125m、z=114.7m；纵梁基本沿舰体纵向，略向外偏约3.2度，而非此前错误的横向贯穿姿态。总长仍取专著19.5m；枢轴相对梁中点的偏置、精确角度和安装高度待进一步校正。

舰体平面宽度站位改用同期Modelkasten印刷页5图3，与武器点位共享同一裁图，取17个上缘像素点镜像。长向按263米、横向按38.9米分别归一化，像素读数及尺度记录在hull_stations.json。该外包络仍非水线图或船厂型线，横剖面和甲板边缘比例仍估计；不能据此宣称舰体精确还原。

带遮挡审计新增最后命中坐标。light_aa_07命中约(-4.696,15.900,-2.285)，light_aa_23命中约(4.696,15.938,-1.450)，与当前桥体截面在相同高度的半宽吻合，定位为估计舰桥侧壁与前部机炮台布局冲突。优先复核桥体前部收窄/炮台凹位，不以挪动同期图描点坐标或关闭遮挡来掩盖。该处仍未修复。

舰桥核心前部按同期俯视的窄前缘关系调整：前缘半宽约为后部的0.6，肩部位于截面纵深0.55处。具体截面高度和过渡仍估计，平台不随核心一起缩窄。保持机炮描点坐标不变后，light_aa_07/23的60秒水平活动范围由约±23度扩至约±81–85度，阻挡步数降为320/307；剩余命中在y=16.75米平台边缘，仍需核对低层平台而非宣布完成。

按Tamiya印刷页12步骤19/20的低层外伸开放平台关系，移除y=15米层上方横贯平台的旧近似舱体及其窗排，保留核心、平台板、撑杆和栏杆。该舱体顶面y=16.75米正是机炮抬高时的主要错误遮挡。平台高度和轮廓仍须更精细资料核实，不能把消除冲突本身当作历史依据。

艉部6吨航空吊机吊臂按Skulski/Draminski印刷页25的20米长度重建，三角截面桁架逐段收窄，补吊索、滑轮及变幅索。吊臂安装角、截面宽度、节间及枢轴高度仍为估值；20米不代表整套吊机外形已精确复原。

修复艏艉端面封口算法：封口扇心改为实际倾斜截面的平均点，消除旧垂直端面中心拉出的额外尖片；补齐扇心与甲板端边之间的闭合三角形。属于网格拓扑修正，不增加历史型线精度。

封闭防空炮盾移除贴在前表面的黑矩形，改为按炮管间距切出的曲面炮口槽及顶部缺口，保留下缘并补内部暗面。开口曲线、宽度及炮盾整体尺寸仍为估值；自身炮盾的完整扫掠碰撞尚未验收。

小型武器细化：25/13毫米增加独立机匣、上置弹匣、后部双握把，127毫米增加炮尾、上方复进机构及下方摇架；开放多管炮座增加带辐条手轮，单装炮补叉架并取消双座椅。部件尺寸仍为比例估计，供弹与操作机构尚未达到图纸测绘精度。

按用户指出并复核Tamiya共有结构装配视图，删除所有防空平台下通用生成的1.5米悬垂圆柱。它不是炮座必需构件，也未与甲板/建筑连续连接；保留平台板与现有斜撑。各点斜撑落点和悬臂结构仍需逐座核对，不将删除错误柱体视为全部连接复原完成。
