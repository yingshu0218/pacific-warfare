# 首版单位名单与制作顺序

更新：2026-11-11。配合[总体规划](project-plan.md)和[资产任务 A01–A08](development-tasks.md)执行。首版按 **8 个舰级、8 个机型**收敛内容；同型单位复用模型，分别保存行为、弹药和损伤。下列新增子型是本次建议，不表示相关模型或配置考证已经完成。

每方 20–30 艘军舰、100 架飞机是场景编制规模，不是需要制作同等数量的不同模型。军舰武器作为可复用模块，机场设施作为场景对象，分别管理。

所有舰型执行[军舰规范](standards/ship-modeling.md)：舰体和上层建筑外形一致，主副炮编制与位置完全符合所选历史配置。专用防空数量按游戏需求规划并另记差异；兼任防空的主副炮仍固定。下表的大形重点不能代替完整外形及逐座主副炮验收。

当前Showcase新增要求是所有已搭建单位出场，并提供编队/机动演示；具体实施见[S14执行卡](showcase/briefs/S14-showcase-scene.md)。下表同时包含已建资产与后续首版计划，不能将后续八舰级/八机型全称为已经完成。

2026-11-11 用户已授权继续实施两军航母与舰载机、各一款大小轰炸机，以及港口/军港/小镇和防空阵地。按[扩展计划](showcase/expansion-plan.md)排队：美国 Essex＋F6F/SB2C，日本翔鹤＋A6M/D4Y2；陆基较大机默认 B-25J／G4M1。具体日期/子型资料仍需对应任务核准，未开工不改为已完成；“大”是本项目尺寸分组，B-25不改称历史重轰。

当前全单位基线为19个模拟实例、9种型号，另有5类独立兵器检视，S14已通过统筹验收，S08普通入口与1倍Chrome长测已独立通过，4倍画面性能保留限制。扩展优先航母作业、D4Y2和两款陆基双发机；下列巡洋舰与鱼雷攻击机仍是后续首版名单，不插入本轮扩展前面。

## 2026-11-27 盘点补记

Godot 实际可加载正式定义里的 **6 舰、6 机**，另有 2 类正式地面单位；独立样件与场景摆放实例不混算。按首版 8 舰、8 机，原有 4 型空缺：TBM-1C、B6N2、克利夫兰和高雄。TBM-1C 与 B6N2 已有独立静态外观初版，尚未登记为正式单位；克利夫兰号和高雄号也已完成独立整舰静态外观。首版 8 舰、8 机均有模型；这四型仍未加入正式观战。下表内旧 Showcase 和系统接入结论是历史里程碑，不等同今天的整体运行状态。

## 3. 共用武器与场景对象

| 资产组 | 首版范围 | 制作规则 |
| --- | --- | --- |
| 舰炮 | 上述八型舰的主炮、副炮与高平两用炮 | 按实际炮架变型复用；单装／双联、开放／封闭炮盾分开；炮座与宿主舰体分开 |
| 轻型防空 | 美制 40 毫米、20 毫米体系；日制九六式 25 毫米及日期清单中需要的其他炮位 | 先复用现有样件，再补宿主舰确实需要的炮架；不为丰富目录把所有联装形式做一遍 |
| 舰载鱼雷 | 弗莱彻、阳炎、高雄等所需的发射器与简化鱼雷 | 保留真实安装、转动、发射口与补装限制；不做内部装填机构 |
| 机载武器／挂载 | 各子型炮口、后座或防御枪位、炸弹、航空鱼雷 | 枪型、挂点与挂载清单对应子型；现有 M2HB、M1917A1 不能直接冒充航空机枪 |
| 岛屿与机场 | 现有机场原型、跑道、机库、少量设施与防空阵地 | 先满足起降、目标和命中反馈；不加精细机场生活场景 |

现有独立武器样件与衣阿华内的武器资源尚未全部统一；由 A01 登记复用范围，不把“文件存在”写成“共用库完成”。九六式双联样件不能因此自动装上当前大和配置。

## 4. 首版后的内容库

| 类别 | 保留候选 | 进入条件 |
| --- | --- | --- |
| 战列舰 | 南达科他、金刚 | 首版完成后，复用成熟舰炮、运动与损伤系统 |
| 巡洋舰 | 巴尔的摩、阿贺野 | 需要增加不同巡洋舰职责或场景变化时 |
| 大型飞机 | B-24；Ki-21 按既有顺序排在 G4M 之后 | 已有行为适配且有足够合格参考图 |
| 其他飞机 | B-17、B-29、水上侦察机 | 内容候选；当前参考目录存在不等于进入首版 |

潜艇、登陆舰艇、步兵和地面装甲单位不加入这次首版名单。水上飞机沿用此前暂缓安排。新增型号的理由应是增加可观看的行为或场景，而非单纯填满军械库。

## 5. 制作与配图顺序

1. **校正已有资产的参考输入。** 大和、衣阿华、A6M5a、F6F-5、SB2C 各明确目标配置、可用整机图和剩余轮廓问题；不因新规范重做全部细节。
2. **配好并制作驱逐舰。** 弗莱彻、阳炎分别完成参考包与简化模型，支持护航队形和鱼雷战。
3. **配好航母与舰载攻击机。** 埃塞克斯、翔鹤；SB2C 复核后 D4Y2；TBM-1C、B6N2。按系统任务接入航空作业。
4. **补巡洋舰与陆基飞机。** 克利夫兰、高雄；G4M1、B-25J。已有 SB2C → G4M → Ki-21 的验收先后约束继续适用。
5. **首版通过后再扩型。** 后置列表不阻塞首场海空战。

每次只为即将制作的一到两个型号整理完整参考包，避免先积累上百张无人筛选的图片。资料工作可以先于模型接口集成，但不改变系统任务依赖或自动启动其他对话。

## 6. 单位登记字段

每个型号最终登记：稳定 ID、阵营、角色、具体子型／舰别、服役年代及来源、目标配置日期、模型入口、参考包入口、历史确定项／估值／缺口、主要装备、必要活动部件与安装接口、模型验收状态、系统集成状态。

服役年代与所选外观日期分开；博物馆拍摄日期、照片日期也另行记录。跨年代组合属于架空场景选择，不改写这些属性。先用小规模战斗验证行为，再通过实例数量达到每方目标规模；飞机总数包含在空、甲板／机场停放及整备中的飞机，陆基飞机是否占用总编制在场景定义中明确。

配图和建模交接统一采用[建模参考图规范](standards/modeling-references.md)。
